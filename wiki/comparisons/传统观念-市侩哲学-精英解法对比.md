# 传统观念-市侩哲学-精英解法对比

## 框架性质

这是课程贯穿始终的三分类对比框架，作者在发刊词中即明确建立。**三类解法的根本区别在于头脑中的"思维模型"**。

## 顶层差异

| 维度 | 传统观念 | 市侩哲学 | 精英解法 |
|------|----------|----------|----------|
| 思维模型 | 默认线性因果，无明确模型 | 单一指标，盯眼前成本收益 | 自我纠错的复杂世界模型（见 [[世界模型]]） |
| 对信任的隐含假设 | 高信任（德行可被识别与回报） | 低信任（合作易被剥削） | 灵活——以系统设计应对信任水平 |
| 行动倾向 | 押注勤奋与德行 | 局部最优，确保少付出 | 借助系统做长线、可积累 |
| 作者隐含评价 | "并不是那么好使" | "没啥意思" | "这就是精英"——褒义 |

作者对市侩哲学的精确定位："**低信任环境里的局部最优策略**。"

## 四个领域逐一对比

### 1. 个人理财

| 解法 | 主张 |
|------|------|
| 传统观念 | 攒钱，财富靠诚实劳动慢慢积累 |
| 市侩哲学 | 钱不是攒出来的是赚出来的，必须买房炒股，一般手段不行必须内部关系 |
| 精英解法 | 靠科学对待风险和收益、可扩展技能、分发渠道与所有权、某种 [[058_阿尔法]] |

### 2. 学习

| 解法 | 主张 |
|------|------|
| 传统观念 | 死记硬背 + 题海战术 |
| 市侩哲学 | 实用主义，最好抄捷径 |
| 精英解法 | 学习即神经网络训练，结合大脑认知规律，让认知模型迅速精确化 |

### 3. 工作

| 解法 | 主张 |
|------|------|
| 传统观念 | 努力奋斗多加班就有回报 |
| 市侩哲学 | 别听老板 PUA，成事靠跟风做概念 |
| 精英解法 | 跃层考虑问题，想想事业本质，用对照实验找关键因果 |

### 4. 人情世故

| 解法 | 主张 |
|------|------|
| 传统观念 | 克己复礼，用道德和权威压人 |
| 市侩哲学 | 关系当筹码，无用的冷处理、有用的纳入"人脉" |
| 精英解法 | 心理安全、情绪调节、非零和博弈乃至"无我" |

## 作者总结

> "世界的确不怎么奖赏更用力的人，但世界很喜欢奖赏用对工具的人。勤奋只是底座，犬儒不过是借口，方法论才是倍增器。"
