# 可取困难与不可取困难（Desirable vs Undesirable Difficulties）

本对比表整合 [[052 可取（以及不可取）的困难：把身心调到最适合学习的状态]] 中对两类困难的区分。

## 维度对比

| 维度 | 可取困难 | 不可取困难 |
|------|----------|------------|
| 来源 | 学生与所学内容较劲 | 外部施压 |
| 负荷类型 | 内禀负荷（[[045_认知负荷理论]] 范围内） | 外在负荷（无价值） |
| 阻力对象 | 知识点本身的难度 | 疲劳、干扰、威胁 |
| 短期表现 | 变差 | 变差 |
| 长期效果 | 增强记忆与迁移 | 损害前额叶、削弱工作记忆 |
| 焦虑水平 | 不增加（72% 学生报告提取练习降低考试紧张） | 显著增加 |
| 情绪配方 | 安全感打底 + 好奇心点火 + 适度压力提速 | 恐惧制造服从 |
| 典型例 | [[提取练习-retrieval-practice]]、[[时间间隔-spacing]]、[[交错学习-interleaving]]、手写笔记 | 睡眠不足、当众羞辱、头悬梁锥刺股 |

## 判断启发式

> 简单说，可取困难是让学生跟所学的内容较劲，是在内在负荷的范围内折腾；不可取的困难则是从外部施压，给学生增加毫无价值的外在负荷，让他们跟疲劳、干扰和威胁较劲。

## 与传统"吃苦"教育观的关系

可取困难与"吃得苦中苦"的民间哲学在表面上相似（都强调克服困难），但在以下三处根本对立：

1. **主体性**：可取困难由学习者主动与内容较劲；"吃苦"由外部施加。
2. **负荷性质**：可取困难属于内在负荷；"吃苦"制造外在负荷。
3. **长期效果**：可取困难增强记忆与迁移；"吃苦"损害 [[唤醒度-arousal]] 与前额叶功能，反而损害学习。

作者认为"没苦硬吃是愚蠢的自我感动，是拿神经系统的磨损冒充认知能力的增长"。
