# 内部叙事与外部视角（Narrative Inside View vs Statistical Outside View）

本对比聚焦一对核心张力：人到底应该用「我是谁」的故事思考，还是用「我属于哪个统计群体」的方式思考？

源文金句：「具体做事，不妨用内部叙事给自己打气；决策，却必须用外部参考类给自己泼冷水。」

## 核心对照

| | 内部叙事（Inside Narrative） | 外部视角（Outside View） |
|------|------|------|
| 视角 | [[内部视角与外部视角\|内部视角]] | [[内部视角与外部视角\|外部视角]] |
| 信息类型 | 个案信息 | 分布信息 |
| 思维底色 | [[叙事谬误]] | 统计基线 |
| 主体身份 | 主角 | 样本 |
| 认识论角色 | 给意义 | 给预测 |
| 典型工具 | 故事、隐喻、剧本 | [[参考类预测]]、分布、概率 |
| 情绪基调 | 热血、有动力 | 冷静、保守、像泼冷水 |
| 适合场景 | 启动项目、激励自己、坚持到底 | 决策、计划、风险评估 |
| 风险 | 落入 [[规划谬误]] | 缺乏行动力 |

## 关键差异

### 1. 认识论基础

- **内部叙事**：把人当作有能动性的主体，意义来自故事连贯性。
- **外部视角**：把人当作统计意义上的样本，意义来自基线分布。

两者对应不同的真理观。叙事真理靠连贯性，统计真理靠可重复性。

### 2. 偏差来源

| 内部叙事的偏差 | 外部视角的偏差 |
|------|------|
| [[乐观偏差]] | 忽视个体差异 |
| [[控制错觉]] | 过度保守 |
| [[自利归因]] | 「均值回归」抹杀特殊价值 |
| [[幸存者偏差]] | 忽视赢家通吃型分布的尾部 |
| [[可得性偏差]] | 参考类选择偏差 |
| [[叙事谬误]] | 缺乏叙事导致行动力不足 |

### 3. 应用场景

| 场景 | 推荐视角 |
|------|------|
| 启动新项目 / 制定愿景 | 内部叙事 |
| 给新成员激励 | 内部叙事 |
| 估算项目工期/成本 | 外部视角 |
| 评估并购合理性 | 外部视角 |
| 评估核聚变商业化时间表 | 外部视角 |
| 求职薪资谈判 | 外部视角（参考类中位数） |
| 婚恋匹配 | 外部视角（靠谱婚介即 RCF） |
| 学习新技能预期 | 外部视角（参考类失败率） |

## 内在张力

源文承认两者**并不和谐**：

- 内部叙事强化自我效能感，外部视角系统性泼冷水。
- 启动需要前者，决策需要后者。
- 二者来自大脑不同系统，难以同时启用。

## 与已有概念的关系

- 与 [[叙事]] 形成镜像：叙事对应内部视角。
- 与 [[参考类预测]] 一一对应：参考类预测是外部视角的工具化。
- 与 [[WOOP]] 互补：WOOP 给动机（内部叙事），参考类预测给基线（外部视角）。
- 与 [[反脆弱]] / [[非对称风险]] 在大型项目决策上有潜在张力：RCF 给中位数，反脆弱要求做凸性组合。
