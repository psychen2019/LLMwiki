# 频率主义与贝叶斯主义（Frequentism vs Bayesianism）

## 对照表

| 维度 | 贝叶斯主义（Bayesianism） | 频率主义（Frequentism） |
|------|--------------------------|------------------------|
| 概率本体 | 信念的度量（主观） | 客观属性，是世界的真值（True Value） |
| 推理主体 | 参与者，通过行动刺探证据 | 旁观者，通过大量重复逼近频率 |
| 单次事件概率 | 可谈且必要 | 难以谈（无无限重复） |
| 核心工具 | 贝叶斯公式（含先验） | 长期频率、最大似然估计、显著性检验、置信区间 |
| 对先验的态度 | 显式设定、量化、更新、审计 | 不显式使用先验（或仅隐含于统计模型） |
| 极端概率 | 永远不设 0 或 1（[[concepts/克伦威尔法则]]） | 0/1 事件在数学上自然存在 |
| 优势场景 | 单次/低重复决策、主观判断、序贯更新 | 大样本、可重复实验、客观假设检验 |

## 本讲给出的核心诘问

- **贝叶斯主义对频率主义的诘问**：谁会抛无限次硬币？单次事件如何谈频率？
- **频率主义对贝叶斯主义的诘问**：先验若完全主观，如何避免任意性？

## 本讲倾向的解决方案

> 使用贝叶斯预测最好的办法是：把这个事儿已知的频率、或者说世人普遍的信念或者科学知识，当成你的先验，作为出发点。

这是一种**实务性的折中**：把频率主义的数据基础嵌入贝叶斯主义的先验设定，让两种范式在操作层面互补而非对立。

## 边界

- 本讲的对比为教学性简化，未涵盖频率主义在有限样本下的复杂性（如 Neyman-Pearson 框架、置信区间的频率解释）。
- 学界对「概率究竟是什么」长期存在分歧，参见 [[queries/贝叶斯主义中的概率解释争议]]。
