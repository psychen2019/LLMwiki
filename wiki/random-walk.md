# 随机游走模型

## 核心定义

简单随机游走：从 0 出发，每周期以等概率 +1 或 −1。状态值 = 历史结果的累积和。

**关键性质**：
- 期望值始终为 0
- t 步后标准差 = √t
- **无界性**：等待足够长时间，游走会超过任何阈值（正或负）
- **递归性（一维/二维）**：一维和二维随机游走会**无限次**返回起点
- **不递归（三维）**：三维随机游走只有限次返回起点——"永恒在外游荡"

> 角谷静夫（Shizuo Kakutani）的名言："一只在二维平面行走的醉汉可以最终回到家，但一只在三维空间中飞行的醉蝇会永远迷失。"

## 伯努利瓮模型（基础）

随机游走的基石：瓮中 G 个灰球、W 个白球，每次抽取后放回。
- 大数定律：N 次抽取后，灰球比例 → G/(G+W)
- 条纹分析：连续 N 个白球概率 = P^N；连续 9 次三分球在 10 年职业生涯中几乎不可能（排除"热手效应"）

## 幂律结果：返回次数分布

一维随机游走中，**返回零点的时间间隔**满足幂律分布：
- 一半的游走只需 2 步返回
- 极少数需要极长时间（无界性保证）
- **企业生命周期**：销售强劲 → 招聘，销售不佳 → 解雇，员工数归零 → 企业"死亡"。返回次数 = 生命周期 → 幂律分布
- **物种寿命**：属中物种数随机游走，分类单元寿命 → 幂律
- **冰川湖泊**：冰川"返回"时间 = 湖泊直径 → 幂律

## 有偏差的随机游走

当 +1 和 −1 概率不等时（p > 1/2），游走有正漂移，长期趋势向上。

**轮盘赌策略**：
- 红色胜率 9/19 ≈ 47.4%，每 100 次下注预期损失 5 美元
- 下注 1 万次后，赢得任何正收益的概率 < 百万分之一
- **策略启示**：要想赢，应下一个大赌注（增加方差），而非下很多小赌注（确定性负期望）

## 高维随机游走

| 维度 | 递归性 | 直觉 |
|---|---|---|
| 1D | 递归（无限次返回）| 一维搜索耳环 |
| 2D | 递归 | 纸面上弯曲的线 |
| 3D | **不递归** | 苍蝇飞行、分子弹跳 |

一维/二维递归性解释了**随机觅食**策略的有效性：蚂蚁在二维地面随机搜索食物即可保证最终找到；苍蝇在三维空间则不行。

## 应用：用随机游走估计网络规模

方法：从随机节点出发沿边随机游走，记录返回初始节点的平均时间。
- 平均返回时间 ∝ 网络规模
- 实操示例：要求某人说出朋友，该朋友再说出朋友，看多久回到起点 → 可估计社交网络大小

## 与有效市场假说的关系

股价建模为随机游走 → 短期内股价变化不可预测（塔勒布"随机漫步的傻瓜"）；但长期有漂移（正增长率）。
