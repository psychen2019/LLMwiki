# 可读性悖论：标准化越彻底，系统对不可读之人的依赖是否反而越大？

## 问题

万维钢在 078 讲中点出一个结构性洞见但未深挖：

> "历史证明，越是想把人读齐、读薄的体制，反而越离不开那些读不清的人。"

这构成一个未被正式论证的悖论：

1. 大明/大清流官制 → 绍兴师爷掌实权
2. 弱法律环境 → 山西票号靠宗族信用网络
3. 苏联计划经济 → 万能修理工 + *tolkach* + *blat*
4. 中国计划经济 → "白专"能人

**这是偶然，还是结构必然？**

## 已有证据

- 所有四个案例都符合"标准化体制 + 不可读补丁"的模式
- 讲义中朱家王朝"账本誊清即失真"的判断暗示这是动态规律而非静态巧合

## 待考察

- 这个悖论是否可量化？是否在所有高度可读性系统中都成立？
- 它与 [[goodharts-law]]（指标让治理变蠢）是什么关系？古德哈特定律是它的特例？
- 它与 [[entrustability]]（可托付性）的关系——师爷、票号掌柜、tolkach 都是高可托付但低可读的角色，可读性是否天然排挤可托付性？
- 现代组织（公司、平台、AI 系统）是否正在经历同一悖论？
