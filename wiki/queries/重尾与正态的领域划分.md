# 重尾与正态的领域划分

## 核心疑问

哪些领域服从[[重尾分布]]、哪些领域服从[[正态分布]]？是否存在可识别的判别标准？

## 源文档给出的分类

|---|---|
| 身高 | 财富 |
| 智商 | 名气 |

|  | 公司规模 |

## 待研究的问题

1. **是否存在结构性判别标准？** 是"涉及人类主观评价的领域倾向于重尾"还是"涉及网络效应的领域倾向于重尾"？
2. **同一领域内部是否混合？** 如个人收入（年薪可能正态，但财富存量重尾）
3. **随时间会否转换？** 某些领域是否会从正态变为重尾（或反之）？
4. **过渡态分布**：是否存在既非严格正态也非严格幂律的中间形式（如对数正态分布）？
