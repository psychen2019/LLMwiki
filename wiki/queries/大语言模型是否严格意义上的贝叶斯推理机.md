# 大语言模型是否严格意义上的贝叶斯推理机？

## 问题的提出

本讲将 AI 大语言模型（LLM）刻画为「巨型的贝叶斯预测机」：

- **训练**：把世界的先验嵌入参数——一种很强的先验；
- **Prompt**：提供观测证据，强迫模型更新后验概率，坍缩出具体回答；
- **对齐（Alignment）**：让模型持有不可轻易被 Prompt 推翻的强先验，以维持底线；
- **越狱（Jailbreak）**：试图用对抗性 Prompt 让那个「理论上可以改变」的先验失效。

这一叙述是**类比性的**——原文也明确说「在这个视角下」。问题是：现代 LLM 是否在严格意义上构成贝叶斯推理机？

## 需考察的事实

| 维度 | 严格贝叶斯推理机的特征 | 现代 LLM 的实际机制 |
|------|----------------------|--------------------|
| 训练目标 | 显式最大化后验/边缘似然 | 经验风险最小化（语言建模 + RLHF/DPO 等） |
| 先验表示 | 显式概率分布 | 隐式分布于参数之中 |
| 推理方式 | 按贝叶斯公式计算后验 | 自回归采样/束搜索等解码策略 |
| 证据引入 | 按 P(E) 归一化更新 | 通过上下文窗口条件化 |
| 对齐 | 一个强先验 | 多层规则 + 微调 + 系统提示 + 工具过滤 |
| 越狱可能性 | 先验理论上可改变 | 实践中存在（提示注入、对抗样本） |

## 未决问题

1. **类比是否过度简化？** 把训练—推理二阶段映射为「先验—证据更新」是否掩盖了优化目标与解码策略的本质差异？
2. **「对齐 = 强先验」是否足够？** 对齐并非单一参数，更像是「叠加在模型上的多层防护」；把它简化为「一个不可变的先验」可能误导关于越狱难度的直觉。
3. **LLM 是否在做「主动推断」？** 与 [[concepts/自由能原理]]、[[concepts/主动推断]] 的对接中，LLM 的回答生成能否被视为「改变环境以适应先验」，还是仅仅「按先验采样」？
4. **是否有可操作的检验？** 是否能设计实验区分「贝叶斯推理机」与「巨型模式补全器」在概率分布层面的差异？
