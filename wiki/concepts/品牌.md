# 品牌（Brand）

## 定义

通过降低交易成本、提供确定性而形成的可信任标识。本讲视为 [[网络杠杆]] 在"信任与确定性"维度的轻量特化。

## 作为杠杆的本质

> "品牌作为杠杆的本质作用，是降低交易成本。你不需要向用户解释半天，别人只要听到你的名字就自动信任。"

## 两个层次

### 1. 信任（初级）

- 降低信息搜寻成本
- 消费者无须自验，靠品牌决策

### 2. 确定性（高级）

> "如果你的品牌已经如此深入人心，人们买你的商品就已经不再是因为你'好'，而是因为你提供了确定性。每一瓶可口可乐的口感都是一模一样的。它卖的不是一瓶黑色糖水，甚至也不是号称有多么神秘的配方，而是口感稳定性和一百多年堆出来的消费记忆。"

- 卖的不是产品功能
- 卖的是"每次都一样的体验"
- 卖的是"一百多年堆出来的消费记忆"

## 关键引语

> "在这个意义上商业世界绝不是尔虞我诈，而是最该重视君子名节的世界。"

品牌一旦建立，需要长期诚实守信维护——这也是为什么商业世界反而更应重视"君子名节"。

## 与 [[信息模式]] 的关系

品牌是 [[信息模式]] 在"信任与确定性"维度的特化——品牌本身是可复制的无形资产。

## 与 [[平台]] 的关系

品牌是 [[平台]] 的"轻量版"——只有信任，没有交易撮合功能。

| 维度 | 品牌 | 平台 |
|------|------|------|
| 信任 | ✓ | ✓ |
| 确定性 | ✓ | ✓ |
| 撮合 | × | ✓ |
| 多边网络 | × | ✓ |

## 与 [[网络杠杆]] 的关系

品牌是网络杠杆的最小单位。网络杠杆 = 品牌 + 平台 + 标准。

## 现代案例

- 可口可乐（口感稳定性）
- 麦当劳（汉堡生产语法的标识 + 信任）
- Apple（设计与体验确定性）
- LV（奢侈品符号信任）
