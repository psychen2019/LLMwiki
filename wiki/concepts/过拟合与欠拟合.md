# 过拟合与欠拟合（Overfitting & Underfitting）

## 定义

[[concepts/颗粒度]] 的两个极端，是 [[concepts/最小描述长度]] 准则要显式惩罚的两种病态。

| 病态 | 表现 | 后果 |
|---|---|---|
| **欠拟合**（Underfitting） | 模型太简单，颗粒度过粗 | 丢失关键机制，无法干预 |
| **过拟合**（Overfitting） | 模型太复杂，颗粒度过细 | 淹没在噪音中，泛化能力差 |

## 天气描述示例

```
欠拟合：  "这地方总下雨"
          —— 一句话，但解释不了不下雨的日子

过拟合：  列举过去一年 365 天每天的天气
          —— 数据齐全，但没有压缩，没有理解

恰当：   "温带海洋性气候，受西风带控制，全年温和湿润，
          虽然阴雨天多，但多是毛毛雨，很少有暴雨。"
         —— 几十个字，有规律、有机制、能代表大量数据
```

## 在 MDL 框架下的表现

```
MDL 总和 = 模型长度 + 数据补丁长度

欠拟合：模型长度短，但数据补丁长度长（要解释大量例外）→ 总和大
过拟合：模型长度长，但数据补丁长度短（已穷举所有数据）→ 总和大
恰当：  模型长度适中，数据补丁长度短 → 总和最小
```

## 决策案例

### 公司管理

| 风格 | 颗粒度 | 后果 |
|---|---|---|
| "我只要结果，你们看着办" | 欠拟合 | 员工无所适从 |
| 各种场景事无巨细都有详细规定 | 过拟合 | 员工根本执行不了 |
| 设定几条核心价值观 + 识别一两个最关键中介 | 恰当 | 高效且有弹性 |

### 买手机

| 决策风格 | 颗粒度 | 后果 |
|---|---|---|
| "买最贵的 / 买便宜的" | 欠拟合 | 颗粒度过短 |
| 花几天研究所有参数再看评测 | 过拟合 | 决策瘫痪 |
| 先想好买来做什么，只考虑几个关键变量 | 恰当 | 快速决策 |
