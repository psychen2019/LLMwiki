# 黄宗羲定律

由[[秦晖]]总结中国两千年帝制史中赋税改革反复循环的规律。原始观察来自明清思想家黄宗羲对历代赋税的考察。

## 循环流程

```
① 王朝建立 → 吸取前朝教训 → 轻徭薄赋
   ↓
② 官僚集团自我扩张 + 皇上好大喜功
   → 财政吃紧
   ↓
③ 加税 → 正税名义上不好涨
   → 发明杂税：附加费 / 临时摊派 / 火耗 / 徭役折银…
   ↓
④ 张居正式改革者出现：把杂税并入正税 → "减负"
   ↓
⑤ 几年后财政又紧 → 发明新杂税
   ↓
⑥ 反复循环：积累莫返之害
   → 农民负担固化
   ↓
⑦ 农民种地净收益为负 → 逃亡
   → 流民 → 民变 → 王朝崩溃
   ↓
⑧ 新王朝重建 → 再来一遍
```

## 关键洞见

> 与明君清官无关。

秦制两千年下，**只要家产制（参见 [[家产制patrimonialism]]）和汲取机制不变，老百姓没有合法手段制衡政府的权力和税收扩张**，历代王朝就只能把这个循环重演。

这个论断是结构性的——它把王朝兴衰的解释从"个人品德"维度彻底转移到"制度结构"维度。

## 与其他概念的关系

- [[家产制patrimonialism]]：黄宗羲定律的制度前提。
- [[软预算约束]]：本课程下集主题——王朝财政软约束的当代版。
- [[好租与坏租]]：合法税收 → "好租"；家产制汲取 → "坏租"。
- [[剥削叙事 vs 杠杆叙事]]：黄宗羲定律是"剥削叙事"最坚实的经验支撑。
