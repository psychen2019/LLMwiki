# 具身认知（Embodied Cognition）

现代神经科学与心理学的核心学说之一：身体的动作、姿势、触觉和空间定位都会参与大脑的建模过程，"理解"并不只是发生在大脑里的符号运算。身体不只是服务大脑 CPU 的供电设备——身体是思考的一部分。很多时候不是你先想明白了才动手，而是你一动手，脑子才开始明白。

## 与 [[默会知识]] 的关系

[[051_默会知识]] 提到了具身认知作为"更有人类特色的一种认知方式"。本讲进一步将具身认知落到操作层面，给出四个学习心法。

## 四个学习心法

1. **动手做动作**：数学题可悬空比划；几何可手描方向；动词类单词可全身上阵——动作替工作记忆减负，对儿童尤其有效。
2. **手写笔记**：打字太快像速记员；手写被迫重新组织语言，"慢"反而是 [[可取困难-desirable-difficulties]]；手写激活更广泛的感觉—运动整合。
3. **读纸质书**：纸张提供稳定空间坐标；海马体最早就是用来记忆空间位置和导航的。
4. **想不出就走路**：走路稍微提高 [[唤醒度-arousal]]、打破过度聚焦、改善情绪；安静自然环境效果更佳。

## 与既有概念的关系

- 与 [[表征representation]]、[[心智模型mental-models]] 互补：具身认知是表征与心智模型的身体维度。
- 与 [[可取困难-desirable-difficulties]] 兼容：手写、纸读、走路都是把"慢""有阻力"的身体动作嵌入学习流程。
