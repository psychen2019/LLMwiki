# 比分牌之缺（No Scoreboard）

> "足球比赛有终场哨和比分牌，输了就是输了。主教练该换就得换，球队打法该变就得变。但如果你治理的是一个复杂的大系统，那就几乎没有人能宣布你输了。"

## 定义

**比分牌之缺**（no scoreboard）指复杂大系统与有明确规则的体育比赛不同，**缺乏公开承认的、不可逆的结算时刻**。这使得系统内的失败难以成为[[共同知识]]，从而难以触发对应的更换、调整或终止。

这一概念解释了为什么复杂系统中"明明很差、几乎人人都不满的局面"还能持续很久。

## 来源原文核心论点

来源原文（[[sources/079_共同知识：让众人服从的神器]]）：

> 这就是神器在手的好处。只要你不下"罪己诏"，就没有人能宣布你输了。你依然掌握着共同知识，天命就仍然在你这里。

## 典型案例

### 战争叙事

| 案例 | 来源 |
|------|------|
| 俄乌战争 | 普京：把战场损失包装为"国际地位反而提高"；经济下滑包装为"军工产业高速增长" |

### 创业叙事

来源原文列举的"创业公司四年亏损"链条：

```
第一年：战略投入期
第二年：市场教育期
第三年：组织能力沉淀期
第四年：资本寒冬暂时压住了创新
```

只要没有公开承认的失败时刻，亏损就可以不断改名为下一轮融资的理由。

### 企业/政府

- 长期亏损的国企：可通过"承担社会责任""维护就业"等叙事延期
- 政策失误：可通过"长期有益""代价必要"等叙事重新框架
- 大型科技公司失败项目：可通过"战略探索""学习投入"重新定义

## 与[[共同知识]]临界点的关系

比分牌之缺与[[共同知识]]的崩塌临界点形成对照：

| 维度 | 比分牌之缺 | 共同知识临界点 |
|------|------------|----------------|
| 失败是否发生 | 是 | 是 |
| 失败是否成为共同知识 | 否 | 是 |
| 是否触发更换 | 否 | 是 |

比分牌之缺是**让失败停留在共有知识层面**的关键机制——大家都私下知道失败，但没人能公开宣布，因此共同知识无法形成，行动也无法更新。

## 与本维基已有概念的关系

- **与 [[叙事经济学]]**（已有）：比分牌之缺是叙事经济学在政治与商业中的典型应用——通过再叙事延期结算。
- **与 [[古德哈特定律]]**（已有）：当指标长期失效但仍未被替换，正是因为没有公开的比分牌。
- **与 [[机会窗口]]**（已有）：比分牌之缺让"失败"的窗口长期敞着，反向延长了不良状态的窗口期。
- **与 [[叙事权]]**（参见 [[sources/087_叙事权]]）：掌握叙事权是制造比分牌之缺的核心能力。

## 在不同系统的差异

| 系统 | 是否有公开比分牌 | 失败能否成为共同知识 |
|------|----------------|---------------------|
| 足球比赛 | 是 | 终场哨后立即成为 |
| 上市公司股价 | 部分（季度财报） | 长期股价下跌可触发 |
| 民主选举 | 是 | 投票后立即成为 |
| 威权体制 | 否 | 几乎不可能 |
| 学术评价 | 部分（引用、奖项） | 慢但可能 |
| 创业公司 | 否 | 几乎不可能直到破产 |
| 政府政策 | 否 | 极少，仅在重大危机时 |

## 操作含义

### 对系统治理者

比分牌之缺是一把双刃剑：

- **短期**：保护系统免于单次失败造成的崩溃 → 韧性
- **长期**：让系统积累错误却无法纠正 → 慢性失能

来源原文：

> 总会有一个时刻，你会点对你来说最好的那道菜，而不再点大家都点的那道菜。

### 对系统观察者

意识到比分牌之缺意味着：

1. **不要把"没人宣布失败"误读为"事情正在成功"**
2. **关注私下共识的形成速度**——当私下共识达到某个密度，可能突然转化为公开共同知识
3. **寻找"事实被共同化"的临界信号**——比如关键人物突然公开承认、内部信函泄露、媒体调性变化

### 对创业者和组织内成员

来源原文相关：

> 一家创业公司连续四年亏损，产品没跑出来用户也没增长……但老板只要不承认失败，事情就还有另一种说法。

意识到比分牌之缺有助于更早识别真正的失败临界点——尤其是当"改名"的速度赶不上现实恶化时。
