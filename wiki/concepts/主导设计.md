# 主导设计（Dominant Design）

## 定义

主导设计指**行业对"好产品该长什么样"达成共识**——架构、界面、标准、渠道、采购规则全都固定下来，连头部玩家的位置也趋于稳定。主导设计一旦形成，后来者只能在既定规则内寻找缝隙。

## 标志信号

| 信号维度 | 主导设计尚未锁定 | 主导设计已锁定 |
|---------|----------------|--------------|
| 架构 | 各家方案不同 | 全行业同一架构 |
| 界面 | 每家一套 UX | 行业统一 UX 范式 |
| 标准 | 接口、协议、互操作未统一 | 接口标准固定，互联互通 |
| 渠道 | 各家自建 | 行业统一渠道生态 |
| 头部位置 | 仍在洗牌 | 头部基本固定 |
| 竞争方式 | 差异化创新 | 价格战、加时赛、卷 |

## 在机会窗口中的位置

主导设计锁定是 [[机会窗口]] 的**终点**：

```
类别形成前 → 主导类别出现 → [机会窗口] → 主导设计锁定 → 窗口关闭
                                                  ↑
                                          你只能在别人的规则里卷
```

## 经典例证

- **iPhone 之后**：多点触控大屏 + iOS + App Store + 开发者生态形成主导设计。安卓之所以存在，是因为苹果"卖得太贵且不自由"——这是缝隙，而非差异化主战场。
- **iPod 之后**：MP3 播放器的主导设计早已定型，Zune 的硬件设计还不错，但因差异化不足失败。
- **电动汽车当前状态**：特斯拉、蔚小理已锁定大部分设计维度；小米赌的是"软件定义汽车"和"人车家生态"这些维度尚未锁死。

## 与 [[护城河]] / [[竞争优势]] 的关系

主导设计锁定 ≈ 护城河固化。一旦主导设计被确立：
- 头部位置稳定 → 后进入者需要付出巨大成本才能挑战
- 行业规则固定 → 创新空间被压缩到"缝隙"层
- 标准锁定 → 兼容成本 + 用户迁移成本双向加高

参见 [[竞争优势]] 中"主导设计 → 护城河"的演化路径。

## 类别 vs 设计

| 概念 | 解决什么 | 时间点 |
|------|---------|--------|
| 主导类别 | "这是什么" | 更早：先有命名共识 |
| 主导设计 | "好产品该长什么样" | 更晚：后有产品形态共识 |

两者共同构成 [[机会窗口]] 的边界。
