# 中介变量（Mediator）

## 定义

因果链中的间接环节——X 不直接导致 Y，而是通过 M 这一中介变量间接导致 Y：

```
X → M → Y
└─中介─┘
```

找到中介变量，才能识别真正的干预着力点。

## 核心方法论

> **别盯终点，盯中介。**

复杂决策中，终点（Y）往往难以直接操控；但通过干预中介（M），可以间接改变 Y。

## 经典正例：Moneyball

```
（击球 + 选球眼光）→ 上垒 → 得分 → 赢球
                    └─── 中介变量 ───┘
```

- 传统球探盯"球星"，但球星是昂贵的、难以操控的输入
- 比恩盯"上垒"——一个被市场普遍忽视的中介变量，能用更低成本干预

## 经典反例：生气 → 癌症

```
生气 → 不良生活习惯 → 癌症
       └──── 中介 ────┘
```

- 直接相关性：很弱（排除中介因素后基本消失）
- 真正的中介：不良生活习惯（暴饮暴食、不运动、吸烟、酗酒）
- 干预结论：如果你情绪不佳但能坚持锻炼、控制饮食，就不会因"生气"得癌症

## 应用案例

| 领域 | 终点 | 中介变量 |
|---|---|---|
| 孩子学习成绩 | 成绩 | 记忆编码、提取（而非学习时间） |
| 公司收入 | 收入 | 留存、转化率、渠道质量、产品体验、交付速度 |
| 足球进攻 | 进球 | 倒数第二脚、第三脚传球或带球突破（xT，见 [[concepts/期望威胁]]） |

## 数学合法性

基于 [[entities/朱迪亚·珀尔]] 的 do-operator：通过干预验证因果链中各环节的因果效应，确定哪些是真正的中介变量。

## 与反脆弱的呼应

[[concepts/反脆弱]] 主张寻找"凸性"——即小干预带来大正向变化的结构。中介变量往往就是这种凸性的承载点：通过干预中介，可以用较低成本撬动最终结果。
