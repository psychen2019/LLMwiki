# 自利归因（Self-Serving Attribution）

自利归因指人**成功时归因自己能力强，失败时归因外部环境或他人**的稳定倾向。源文：「让你把上次翻车怪到天气、队友和甲方头上。」

它是 [[规划谬误]] 心理机制清单中的一环——通过把过去的失败甩出去，保留对未来的乐观与掌控感。

## 作用机制

- 成功 → 归因内部（我厉害 / 我们团队牛 / 战略对）
- 失败 → 归因外部（运气差 / 队友不给力 / 甲方多变 / 天气恶劣）

这种归因方式让人难以从失败中提取真实教训，从而在下一次规划中继续乐观。

## 与其他偏差的协同

| 偏差 | 关系 |
|------|------|
| [[乐观偏差]] | 把失败甩出去 → 保留「下次会顺」的乐观 |
| [[控制错觉]] | 把失败甩出去 → 保留「我能掌控」的错觉 |
| [[叙事谬误]] | 自利归因本身就是叙事谬误的典型形式——只讲「我是主角」的故事 |
| 确认偏误 | 只搜集符合「我厉害」的证据，回避「其实我也不灵」的信号 |

## 在企业并购中的表现

源文：每个 CEO 都喜欢收购别的公司，并给出「协同效应、战略互补」的故事。失败时归因于整合能力、对手反应、市场环境——但只要看 [[参考类预测]] 的统计基线，就知道平均而言收购方业绩并不因并购改善。

## 对抗方法

- 强制做失败归因练习：把「我们哪里做错了」写在前面，而不是「谁该背锅」。
- 用 [[参考类预测]] 看同类项目的失败率，承认基线失败率。
- 第三方视角（外部视角、旁观者）能直接打破自利归因的循环。
