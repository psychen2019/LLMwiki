# 杠铃策略（Barbell Strategy）

**杠铃策略（Barbell Strategy）** 是 [[entities/纳西姆-塔勒布|塔勒布]] 在 [[sources/033_非遍历性|上一讲]] 已提及的策略。结构上像杠铃：**绝大部分资产极度安全，只拿一小部分去冒高风险**。

## 形式化

```
[------------------极度安全 (90%)------------------][-高风险冒险 (10%)-]
```

## 收益特征

- **输了**：赔不多（因为小部分）
- **赢了**：可能大赚（因为高赔率）

这是**稳健防守又保持进攻**的策略，符合 [[concepts/非对称风险]] 中的反脆弱属性。

## 生活中的运用

不必非得投资：

- 给行业大佬发求合作邮件（最坏被拒，最好改变命运）
- 有一份安全工作时搞副业"秘密项目"（最坏没产出，最好成就）
- 阅读时 80% 经典 + 20% 随机前沿论文

## 与其他概念的关系

- 是 [[concepts/非遍历性]]（玩家怕方差、庄家爱方差）的实操工具
- 与 [[concepts/毁灭隔离]] 同构：把"全压一注"拆成"多注但各自有底"
- 与 [[concepts/凯利公式]] 在数学上是近亲（凯利公式计算最优下注比例）
