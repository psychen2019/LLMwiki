# 网络杠杆（Network Leverage）

## 定义

通过信任、标准、网络效应建立的杠杆机制。商业杠杆六类递进中最高级、也是"当今世界最赚钱的生意"。

## 在卖水故事中的位置

> "第六种办法是网络杠杆。你建了一个'可信水源认证'和地图平台。所有卖水的人都愿意贴你的认证标志，因为消费者相信你。你卖的既不是水也不是专利，而是信任、标准和网络。"

> "网络平台是当今世界最赚钱的生意。"

## 三层价值

1. **信任**——消费者无须自验，靠认证标志决策
2. **标准**——成为行业事实标准（如 Visa、ISO）
3. **网络**——网络效应使每多一个用户，所有用户价值↑

## 与 [[平台]] 的关系

网络杠杆在现代最常见的形式就是 [[平台]]：

- 用户自带生产资料加入
- 平台只需提供信任系统、评价机制、支付手段
- 卖的不是产品，是市场秩序

## 与 [[品牌]] 的关系

[[品牌]] 是网络杠杆的"轻量版"：单点信任，没有交易撮合功能。

- 网络杠杆 = 品牌 + 平台 + 标准
- 品牌 = 网络杠杆中的"信任"维度独立出来

## 关键机制：非竞争性 + 网络效应

- 内容/标准本身[[非竞争性]]（边际复制成本≈0）
- 网络效应 = 用户越多，每个用户价值越高（竞争性维度）
- 双重叠加 → 极强护城河

## 现代案例

- Visa / Mastercard（支付网络）
- Google / Baidu（搜索标准）
- Airbnb / Uber（撮合平台）
- 微信（通讯+支付+小程序生态）
- 可口可乐 / 麦当劳的全球认证体系（位于 [[品牌]] 与网络杠杆之间）

## 在六类杠杆中的位置

网络杠杆是 [[商业杠杆]] 递进的终点之一：

- 卖实物 → 卖方案 → 卖信任
- 利润来源：实物 → 授权费 → 注意力 → 标准制定权

## 与现有 wiki 的关联

- 与 [[商业杠杆]] 是父子关系
- 与 [[平台]]、[[品牌]] 共享核心机制（信任 + 标准）
- 与 [[期权]]：网络效应使平台持有未来增长期权
- 与 [[反脆弱]]：网络效应本身是一种反脆弱机制——冲击常带来更多用户
