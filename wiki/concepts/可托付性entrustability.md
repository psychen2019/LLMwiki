# 可托付性（Entrustability）

## 定义

> **可托付性**：他人是否敢把模糊、昂贵、有严重后果的问题完整交给你处理。

它是把焦虑（混沌信息、冲突目标、无人愿碰的责任）**压缩成可判断、可执行、可负责的秩序**的能力。

## 在薪酬结构中的位置

来源提出的"薪酬三段论"：

| 段位 | 购买对象 | 典型岗位 |
|---|---|---|
| **低薪** | 时间 + 体力 | 外卖、客服、流水线、基础行政 |
| **中薪** | 技能 | 程序员、设计师、律师、医生 |
| **高薪** | **可托付性** | 高端 PM、高端律师、COO、董秘、CFO |

## 高端打工人的三个动作

当老板抛出一团焦虑（而非清晰任务），可托付的人会：

1. **重新定义问题**
   - 你以为问题是 A，其实瓶颈在 B
   - 你以为是技术不行，其实是没跟上客户脚步
   - 你以为是销售不努力，其实是产品定位错了
   - 你以为是人手不够，其实是决策节奏太慢

2. **给出行动建议**
   - 先做这个
   - 验证一个小假设，再投入大资源
   - 稳住关键客户，再谈长期改造
   - 先按版本 B 推进，三周后根据指标决定是否加码

3. **提供逻辑支撑**
   - 降低下行风险
   - 争取时间
   - 保留选择权
   - 让下一步决策有证据

## 三要素：判断力 × 信任 × 杠杆

> 都能应对不确定性，拥有信任，能调动杠杆，……这样的人才应该拿高薪。

| 要素 | 含义 | 缺失后果 |
|---|---|---|
| **判断力** | 能重新定义问题、给出行动方案 | 中级天花板——只能处理已定义的任务 |
| **信任** | 此前的判断力积累出的信用 | 老板不敢授权 |
| **杠杆** | 判断能否扩散到更多人、钱、客户、流程 | 影响小，不值得高薪 |

## 文化锚点

> 可以托六尺之孤，可以寄百里之命，临大节而不可夺也。君子人与？君子人也。
> ——《论语》《孟子》

中文"托付"一词的厚度远超英文 "entrustability"——它带有**生死托孤**的重量感。

## 案例对照

| 案例 | 压缩的不确定性类型 |
|---|---|
| 蒂姆·库克的供应链管理 | 需求 / 库存 / 物流 / 现金周期 |
| 高端项目经理 | 模糊需求 → 规格，跨部门依赖 → 里程碑 |
| 高端软件开发者 | 系统不崩溃 / 尾部风险 |
| 高端财务经理 | 现金流断裂 / 预算偏差 / 资本成本 |
| 高端律师 | 法律模糊地带 → 合同边界 / 交易路径 |
| 合规负责人 | 罚款 / 诉讼 / 牌照丢失 / 上市失败 |
| A 股董秘 | 资本市场信息披露 / 投资者关系 / 监管问询 |

## 与"极端所有权"的关系

- **可托付性**是能力层（能做什么）
- **[[concepts/极端所有权-extreme-ownership]]** 是态度层（敢不敢 / 愿不愿意负责）

二者互为前提：没有极端所有权，可托付性无法释放；没有可托付性，极端所有权只是空话。

## 反面：可托付性为零的人

来源中描述的"短视频里喜笑颜开的失业员工"——他们"只会继续搞垮下一家公司"。他们把自己视为"带接口的模块"：能装这里也能装那里，项目黄了就换公司。这种人"既然不是 skin in the game，就别指望拿高薪"。
