# 期望威胁（Expected Threat, xT）

## 定义

现代足球分析的核心指标，衡量**把球从当前区域送到另一区域后，该区域进球概率的变化**。

> 真正的杀招往往不是射门也不是最后一脚传球——而是倒数第二脚、第三脚传球或者带球突破。

## 与传统统计的差异

| 指标 | 关注对象 | 问题 |
|---|---|---|
| 助攻 | 最后一脚传球 | 已被市场充分定价，没有溢价 |
| xT | 倒数第二/第三脚传球或带球突破 | **撕开防线，改变概率结构** |

## 工作原理

```
低威胁区域  ──(撕开防线的传球/突破)──>  高威胁区域
   2%                                         30%
                ↑ 这一脚提升的 = xT
```

解说员和球迷早就知道助攻的价值，但 xT 揭示的是**真正改变场上概率结构**的动作——这些动作的市场估值往往被低估。

## 与中介变量的关系

xT 是 [[concepts/中介变量]] 方法论在足球领域的具体实现：

```
（传球 / 突破）→ 期望威胁提升 → 进球
              └─── 中介 ───┘
```

## 类比

xT 在足球中的角色，相当于棒球中的 [[concepts/中介变量|"上垒"]]（见 Moneyball 案例）——都是被传统直觉忽视、但能低成本撬动最终结果的关键中介。

## 方法论价值

xT 案例说明：**找到真正改变概率结构的少数动作**比追求最终结果（进球）更有操作性。这与本课的核心方法论"别盯终点，盯中介"完全一致。
