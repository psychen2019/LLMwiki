# 强化学习（Reinforcement Learning）

强化学习是通过"试错 + 奖励信号"来学习最优策略的机器学习方法，是后训练（[[rlhf]] / [[rlvr]]）的关键机制。

## 课程中的功能定位

强化学习是后训练的核心机制：

| 阶段 | 强化学习的角色 |
|------|----------------|
| SFT | 模仿学习（还不是强化学习） |
| RLHF | 用人类偏好作奖励信号 |
| RLVR | 用客观对错作奖励信号 |

## 课程的核心抽象

> **奖励信号的作用不是提供情绪价值，而是改写权重。**

- 奖励信号 → 模型权重微调 → 行为改变
- 与 [[反馈回路]]、[[强化回路]] 的人类版本同构

## 与人类学习的对应

课程把强化学习当作人类后训练的类比：

- 真实情境演练 = 环境
- 反馈 = 奖励信号
- 反复练习 = 试错 + 权重改写
- 熟到不占脑子 = 策略收敛到稳定路径（pass@1 ≈ 1）

## 局限

- 强化学习只能让模型**更稳定**地走已有的路
- 真正的"开窍"（[[开悟]]）是 [[预训练]] 规模化的产物，不是 RL 能创造的
- 但长期 RLVR 训练 + 维持探索时，可能推高 [[pass@k与pass@1]] 中的上限
