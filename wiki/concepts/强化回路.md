# 强化回路（Reinforcing Loop / 正反馈）

正反馈的别名。反馈会加强最初的那个动作，把整体变化放大。注意：正反馈不等于正增长——股市暴跌也是正反馈，它在放大的是「恐慌」本身。

## 典型样本

- 表现好 → 鼓励 → 信心提升 → 表现更好
- 股价越涨 → 越多人买 → 股价越涨
- 恐慌 → 抛售 → 更大恐慌 → 更猛烈抛售
- 复利、病毒传播、债务滚雪球
- 吃得多 → 变沉 → 少动 → 热量盈余更大 → 继续变胖

## 文化映射

- 「人之道，损不足以奉有余」——《道德经》语境下的强化回路
- 「凡有的，还要加给他，叫他有余」——《马太福音》，即 [[马太效应]] 的语义源头

## 双面性

- 本讲作者特别强调：正反馈不稳定，会失控，预示泡沫、挤兑等危险。
- 但正反馈也是**生发机制**——调控调不出新东西，先有强化回路才值得搭建平衡回路。
