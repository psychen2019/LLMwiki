# 可信承诺（Credible Commitment）

通过实质性、不可撤销的行动使承诺变得可信，是[[自我约束]]的第一种机制。

## 来源

由 [[thomas-schelling]]（托马斯·谢林）在 1960 年《冲突的战略》中提出：约束对手的能力，有时取决于约束自己的能力。

## 核心逻辑

> 空口无凭，你必须做出一个实质性的、无法撤销的动作来约束自己，你的承诺才是可信的，别人才能跟你合作。

## 经典例证

| 领域 | 案例 |
|------|------|
| 借贷 | 房产抵押给银行 |
| 工程承包 | 履约保证金押给甲方 |
| 资金托管 | 客户资金交第三方 |
| 国家治理 | 光荣革命后英国国王受法律限制，借债能力反而增强 |
| 商业 | 台积电纯晶圆代工模式——拆掉偷来之后能用的地方 |
| 外交 | 泰国銮披汶总理送子女给周恩来（[[人质机制]]） |

## 关键判定标准

源文判别"可信承诺"vs"口头承诺"的标准：
- **能被检查**：可验证的行为轨道
- **违约时要承受损失**：声誉损失、机会损失、真金白银

> 这比什么"我一定尽力""这件事包在我身上"可强太多了。
