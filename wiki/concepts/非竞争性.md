# 非竞争性（Non-rivalrous）

## 定义

一项投入被一人使用不排斥他人同时使用的属性。[[保罗罗默]] [[内生增长理论]] 的核心概念，是"财富可无中生有"的微观机制。

> "比如一个苹果，我吃了你就不能吃，这是竞争性的。但是一个数学公式、一段代码、一个商业模式，却是非竞争性的——我看了这篇文章，并不妨碍你也看这篇文章；我用这套算法，也不影响你再用一遍。"

## 与竞争性对照

| 维度 | 竞争性（rivalrous） | 非竞争性（non-rivalrous） |
|------|---------------------|--------------------------|
| 一人使用 | 排斥他人 | 不排斥他人 |
| 复制成本 | 高（要再造一个） | ≈ 0（思想可传播） |
| 守恒定律 | 适用 | 不适用 |
| 边际成本 | 高 | ≈ 0 |
| 边际收益 | 低 | ≫ 边际成本 |
| 典型例子 | 苹果、汽车、工时 | 公式、代码、配方、商业模式 |

## 对应英文术语

non-rivalrous good / non-rival input / 非竞争性投入（non-rival input）

## 在内生增长理论中的地位

[[保罗罗默]] 1990 年提出：经济增长的引擎是"非竞争性投入"——思想、配方、知识的累积。这一性质使：

- 边际成本 ≈ 0
- 边际收益 ≫ 边际成本
- 财富能无中生有
- 不需要有人变穷

## 现代案例

```text
不能复制的 vs 可复制的
苹果（实物）        → 苹果品种、种植法
员工工时           → 培训手册、软件工具
一家店             → 开店语法
商品原子           → 原子的排列组合（信息模式）
```

## 与 [[信息模式]] 的关系

非竞争性是 [[信息模式]] 之所以能成为好杠杆的根本原因：

- 信息模式设计成本高（需要智慧）
- 但复制成本≈0（因为非竞争性）
- 因此"做一次收很多次"

## 与 [[商业杠杆]] 的关系

非竞争性是 [[商业杠杆]] 的微观机制——它解释了为什么"现代财富的秘密 = 卖什么都约等于卖软件。虚拟成分越大，规模化就越能赚钱"。
