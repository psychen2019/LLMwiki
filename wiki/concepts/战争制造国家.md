# 战争制造国家（War Makes States）

美国社会学家蒂利（[[查尔斯蒂利charles-tilly]]）1985 年论文《作为有组织犯罪的战争制造和国家制造》（War Making and State Making as Organized Crime）提出的核心命题：

> **"战争制造国家，国家制造战争。"**

## 机制

```
坐寇之间开始打仗
→ 统治者被迫建立正规军队
→ 建军队 → 多收税
→ 多收税 → 养官僚
→ "军队—税收—官僚"三件套干得好的坐寇社团 → 赢
→ 输的被吞并，胜的变得更强
→ 进一步推动机器升级
```

## 中国案例：春秋 → 战国 → 秦

- **春秋**：各国打仗还讲礼法，只有贵族上阵，作战充满仪式感，杀戮极其有限。
- **战国**：各国为战争必须加强国家机器——变法、郡县、官僚、编户齐民、统一税收。
- **秦**：五百年军备竞赛演化出来的"武装到牙齿的国家机器"。

> "其实如果只是供养统治者，让统治者能够提供基本的保安服务，老百姓也花不了多少钱。"  
> ——但国家一旦进入战争模式，百姓负担就极重。

## 与其他概念的关系

- [[谷物国家grain-state]]：低成本征税养兵 → 战争便宜 → 必然大一统。
- [[家产制patrimonialism]]：战争压力下成长出的早期国家多为家产制形态。
- [[坐寇stationary-bandit]]：战争制造国家 = 坐寇国家化的具体路径。

## 评价

蒂利的洞见不在"战争是好是坏"，而在揭示**战争作为选择压力如何驱动国家机器的演化**——这与生物进化论的逻辑高度同构：竞争压力筛选出更复杂的形态。
