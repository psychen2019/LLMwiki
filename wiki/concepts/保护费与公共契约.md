# 保护费与公共契约

本讲核心叙事框架：从"保护费"到"公共契约"的政府演化主线。

## 演化链

```
流寇抢劫
→ 坐寇收"保护费"（强制的、独占的、单边的）
→ 国家征收"税收"（制度化的、法定的、双边契约的）
→ 政府成为"受托人"（fiduciary power，参见 [[可托付性entrustability]]）
→ 公民身份建立（权利对等，而非臣民依附）
```

## 关键概念映射

| 前现代（坐寇） | 现代（公共契约） |
|---|---|
| 保护费 | 税收 |
| 统治者 | 政府（机构） |
| 子民 | 公民 |
| 私人强制 | 公共强制 |
| 复仇 | 法院 |
| 黑帮 | 警察 |
| 坐寇的独占保护 | 制度化的公共服务 |
