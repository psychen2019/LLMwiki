# 预训练（Pre-training）

预训练是大语言模型训练的第一阶段：把整个互联网规模的语料一段一段喂给模型，让它反复做"预测下一个词"的自监督任务。

## 核心机制

- 猜错 → 微调相关权重
- 猜对 → 继续把正确答案的概率往上推一点
- **校准**而非奖惩
- 重复几万亿次

## 为什么有效

> **预测逼出理解。**

要把下一个词猜准，光背字典没用，必须懂语法、懂事实、懂因果、懂人情世故。模型在一次次预测中建立世界观。

## 关键经验

| 条件 | 后果 |
|------|------|
| 语料充足 + 适当参数 | 基座模型具备广博的世界知识 |
| 语料不足 + 大参数 | 光脑袋大没用（[[chinilla缩放法则]]） |
| 规模达阈值 | 出现 [[涌现]] 与 [[开悟]] |

## 人类类比

预训练 ≈ **贯穿一生的经验积累**：

- 你读过的所有书
- 你见过的所有人
- 你经历过的所有事
- 都是你的训练语料

预训练的程度决定你脑中"有没有路"——即 [[pass@k与pass@1]] 中的 k 路。
