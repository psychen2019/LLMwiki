# 交易记忆系统 / 专长地图（Transactive Memory System）

## 定义
交易记忆系统是一套储存**知识"地址"**（而非知识本身）的体系，存在于文档与人脑的互动习惯中。
- 它的核心不是把每条知识都记下来，而是让每个人知道"谁知道什么"——遇到问题该找谁、谁的判断在哪个领域最可信。
- 它是 [[concepts/structural-capital|结构资本]] 的核心载体。

## 载体形式
- 显性载体：飞书、钉钉、知识库、项目文档、Slack 频道。
- 隐性载体：人的脑子、人与人的互动习惯、长期协作中磨出来的默契。

## 经验支撑：2005 年关节置换手术团队研究
- 把"经验"拆成三份：
  - 主刀医生**个人**做过多少台手术
  - 整个**医院**做过多少台
  - 这一组人**凑在一起**做过多少台
- 结论：哪怕医生本人是老手、医院也是大医院，只要这一组人没在一起配合够，开刀照样磕磕绊绊。
- **"一起做过"才能长出来那张专长地图**。

## 配合中的默契
- 一开始大家都在摸索谁擅长什么、谁的判断在哪一步最靠得住。
- 长到最后变成一种不用开口的默契：
  - 我知道你擅长开路、却容易忽略收尾，收尾我替你盯着。
  - 你知道我嘴上说"问题不大"、其实心里在掂量风险有多大。
  - 我手还没伸出去，你已经把下一件器械递到了我掌心。

## 与复盘的关系
- 复盘（[[concepts/after-action-review]]）是把"一起做过"沉淀进专长地图的关键机制——把一次经历变成组织的记忆。
