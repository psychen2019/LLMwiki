# 内部视角与外部视角（Inside View vs Outside View）

这一对概念由 [[丹尼尔·卡尼曼]] 与阿莫斯·特沃斯基在展望理论工作中提出，是 [[参考类预测]] 的认识论基础。源文称「当局者迷旁观者清」的现代版本就是这对视角的差别。

## 核心对照

| | 内部视角 (Inside View) | 外部视角 (Outside View) |
|------|------|------|
| 信息类型 | 个案信息 (singular information) | 分布信息 (distributional information) |
| 关注对象 | 这一件事的细节、努力、诚意、资源 | 同类已结束事件的平均水平、失败率、尾部风险 |
| 主体身份 | 主角 | 样本 |
| 思维底色 | 叙事脚本 | 统计基线 |
| 情绪状态 | 热血、自信、有动力 | 冷静、保守、易显得悲观 |
| 适合场景 | 启动项目、给自己打气 | 决策、计划、风险评估 |

## 旁观者未必更聪明

源文强调：外部观察者不一定比内部当事人更聪明，但旁观者没有那么多自恋情结——人家把你当样本。

旁观者看到的不是你的热血，而是「像你这样开局的人最后都去了哪里」。

## 与叙事谬误的关系

内部视角的思维底色是 [[叙事谬误]]——把碎片信息拼成连贯故事。这与 [[参考类预测]] 所要求的统计视角在认识论上对立：

- 叙事给意义
- 统计给预测

## 卡尼曼的教科书案例

1970 年代卡尼曼带队编决策学教材，团队预估两年。卡尼曼转向外部视角问教育专家：同类团队通常几年？回答：7–10 年，40% 团队最后放弃。结果：8 年完成，且彼时课程已被取消。

这个案例戏剧性展示了内部视角的失败：「你以为你们不一样，其实每个人都觉得自己不一样。现实是，在统计学意义上大家都一样。」

## 何时用哪个？

源文建议：

> 「具体做事，不妨用内部叙事给自己打气；决策，却必须用外部参考类给自己泼冷水。」

这是把两种视角分配到不同环节的纪律，而不是要求二选一。

## 与已有概念的关系

- 与 [[叙事]] 形成对照：叙事对应内部视角，RCF 对应外部视角。
- 与 [[贝叶斯主义]] / [[先验]] 互补：外部视角提供的同类基线本质上是一种经验先验。
- 与 [[选择偏差]] 互补：参考类必须是「已结束的案例」，避免选择偏差污染。
- 与 [[反脆弱]] / [[非对称风险]] 的潜在冲突：外部视角给中位数，反脆弱要求做凸性组合。
