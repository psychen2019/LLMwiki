# 思维工具是后训练

这是本课最核心的元命题：**学习思维工具的本质，是给自己做后训练**。

## 核心主张

> "大部分思维工具不是新知识。你把任何一个工具拆开看，每一步你都懂。思维工具的作用是把你脑子里本来就有的东西打包成一个自动化的短程序。"
>
> **思维工具是调用你庞大心智基座模型的快捷键。**

## 思维工具的两面性

| 性质 | 描述 |
|------|------|
| 不是新知识 | 每一步你都懂 |
| 是新压缩 | 把已有东西打包成自动短程序 |
| 是新调用 | 让你已有的聪明能稳定发挥 |

## 三个关键比喻

| 比喻 | 含义 |
|------|------|
| "看到'参考类'四个字 → 调用案例库 + 统计学理解 + 幸存者偏差警觉" | 工具是心智基座模型的快捷键 |
| "一个读过大量公司史的人听到'软预算约束'——词像一道闪电把经验点亮" | 工具是经验的压缩算法 |
| "思维工具的作用是把已有的东西打包成自动化的短程序" | 工具是后训练的人类版本 |

## 工具的适用边界

> **工具不是经验的替代品，工具是经验的压缩算法。**

- 一个从没摸过生意的人背"网络效应""边际成本"也不会用
- 一个读过大量公司史、亲手管过账的人，一听到"软预算约束"——这个词就像一道闪电把他的经验点亮
- → [[预训练]] 必须充分，[[后训练]] 才能发挥作用

## 后训练三原则

| 原则 | 含义 |
|------|------|
| 真实情境演练 | 遇到动人故事就查基础比率；遇到考核指标就想古德哈特——"拥抱与桥接" |
| 必须有反馈 | 没有反馈就没有奖励信号，所谓刻苦不过是给自己的错误追加权重 |
| 足够熟 | 把一个动作练到 pass@1 ≈ 1，熟到不占脑子 |

## 行为科学实证（2019）

- 三位行为科学家对 290 名研究生做"确认偏误"专项训练
- 几周后让他们面对以挑战者号航天飞机发射决策为原型的复杂商业案例
- 事先无提醒
- **受过训练的学生选中劣质方案的概率低 19 个百分点**

19% 不是脱胎换骨，但说明：思维工具可以取得行为控制权；换了场景、没人提醒，工具自己启动。

## 今天的后训练是明天的预训练

- AI 模型训练完权重一冻结、再进步就得等下一代
- **人没有版本号——人的权重永远是热的**
- 思维工具一旦用熟，会反向挑选下一批预训练数据：

| 思维工具 | 怎样挑选语料 |
|----------|--------------|
| 信息价值 | 追问什么未知值得花时间弄明白 |
| 主动高认知负荷 | 主动啃费脑子的书和问题 |
| 非预期后果 | 顺着一项政策往后追 |
| 探索与利用 | 定期离开熟悉领域 |

> 越广博 → 真的更聪明——形成正反馈循环。

## 与 [[表面对齐假说]] 的关系

| AI 概念 | 人类学习类比 |
|---------|--------------|
| 预训练 | 一生的经验积累（脑中有没有路） |
| 后训练 | 思维工具的训练（能否稳定走上对的路） |
| pass@k | 偶尔能成为谁 |
| pass@1 | 通常是谁 |

> 预训练决定你**偶尔**能成为谁；后训练决定你**通常**是谁。

> 考场无再试，岁月改权衡。
> 此身无定版，长存训练中。
