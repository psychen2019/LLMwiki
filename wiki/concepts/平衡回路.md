# 平衡回路（Balancing Loop / 负反馈）

负反馈的别名。反馈把最初的动作往反方向拉，纠正偏差、寻求稳态。

## 典型样本

- 空调：室温高于设定值 → 制冷 → 温度回到设定值附近 → 停机
- 超市补货、家庭预算控制、体温调节
- 减肥时身体的代谢补偿：少吃 → 降低基础代谢 + 放大食欲 → 体重回归

## 文化映射

- 「天之道，损有余而补不足」——《道德经》语境下的平衡回路。

## 角色与边界

- 是稳定的、理性的、懂得纠错的机制——管理者爱它，养生的人也爱它。
- 但单靠平衡回路不能创造新东西。先有 [[强化回路]] 才值得搭建平衡回路。

## 关联

- 与 [[闭环控制]] 同构——闭环控制即利用平衡回路做实时微调。
