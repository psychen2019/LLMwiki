# 杰文斯悖论（Jevons Paradox）

## 定义

**杰文斯悖论**由英国经济学家威廉·斯坦利·杰文斯在 1865 年《煤炭问题》（The Coal Question）中提出。其核心机制是：

> 当某种资源的使用效率提高时，单位资源消耗确实下降；但同时使用成本下降 → 门槛下降 → 被抑制的需求释放 → 总资源消耗不降反升。

## 原始案例

1865 年英国正值工业革命巅峰，蒸汽机效率提升几倍，各路天才相信总煤耗会下降。杰文斯指出：

> 蒸汽机越省煤 → 煤动力越便宜 → 更多行业使用煤动力 → 总煤耗反而上升。

## 通用化机制

| 步骤 | 描述 |
|------|------|
| 1. 效率提升 | 某种资源/任务单位消耗下降 |
| 2. 成本降低 | 单位价格下降 |
| 3. 门槛下降 | 原本用不起/想不到/不值得做的需求进入视野 |
| 4. 需求释放 | 新场景与新用户涌入 |
| 5. 总消耗上升 | 局部效率改进被规模扩张抵消并超越 |

## 在 AI 与就业场景的迁移（万维钢 066 讲）

把"提高效率"改为"自动化"，把"资源"改为"人的工作"，杰文斯悖论就变为：**自动化会增加人的工作**。

- **写作**：AI 调研+语音输入+AI 审稿省下时间，但文章对逻辑密度、文献、案例、插图要求更高，写一篇文章的时间往往更长
- **省钱 App**：每笔消费都返现 → 购买门槛降低 → 更想买买买 → 总花费反而增加
- **会议工具**：微信、飞书、AI 会议纪要降低沟通成本 → 发起会议门槛近零 → 会议数量反而增加

## 历史验证清单

- 1865 英国煤炭（杰文斯原始案例）
- 1996 起新疆天山滴灌（20 年用水反弹 115%）
- AI 数据中心电力（单次推理省电，但总耗电量飙升）
- 卢德分子与纺织机械（布料价格暴跌 → 普通人衣服数量暴增 → 纺织工大增）
- ATM 与银行柜员（单网点柜员减少 → 银行大开门店 → 柜员总数反升，工作升级）
- 计算机视觉与放射科医生（看片成本下降 → 扫描量激增 → 医生反而短缺）
- 电子表格与会计（未消灭会计，反而扩张财务分析、预算管理、商业建模）
- 搜索引擎与研究员（催生 SEO、内容运营、数据分析等新岗位）
- 米画师（AI 绘画 → 单价降 64% → 订单增 121% → 总收入增 56%）

## 与 [[鲍莫尔成本病]] 的关系

- **杰文斯悖论**：效率提升 → 总消费量上升（针对"被效率解放的需求"）
- **鲍莫尔成本病**：制造业效率提升 → 服务业相对成本上升（针对"无法被自动化的劳动"）
- 两者共同构成"现代化是好消息"的双重证据：提高效率是好消息；别人提高效率你没提高，对你也是好消息

## 边界与失效条件

1. **资源硬上限**：若资源存在绝对物理瓶颈（如洁净水、土地），悖论可能饱和
2. **AGI/ASI 情形**：若 AI 同时改写任务定义本身，"人类保留新任务"的假设可能失效
3. **过渡期阵痛**：复职效应有时滞；短期内可能出现局部分配失衡与摩擦性失业
4. **价格刚性**：若效率提升无法转化为价格下降（如垄断、管制），悖论无法启动

## 与 [[任务模型]] 的连接

杰文斯悖论在劳动经济学上的展开即 [[任务模型]]：自动化有 [[替代效应]]（消灭任务）也有 [[复职效应]]（创造新任务），净效应由两者共同决定。杰文斯悖论暗示：在多数情形下，复职效应占优。
