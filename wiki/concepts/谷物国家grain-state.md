# 谷物国家（Grain State）

耶鲁人类学家斯科特（[[詹姆斯斯科特james-c-scott]]）提出的国家形态理论：可征税的资产形态决定国家能否走向大一统。

## 谷物的征税优势

| 属性 | 意义 |
|---|---|
| 长在地里 | 可视可估——你家地多大、收成多少，税务官一眼八九不离十 |
| 固定收获季节 | 税务官知道何时来收 |
| 高度可量化 | 几斗就是几斗 |
| 可储存、可运输 | 经得起集中、再分配 |
| 绑定农民在土地上 | 想跑都没地方去 |

→ **管理起来太方便了**。

## 对照案例

### 农业核心区 → 大一统

- 中国华北（小麦）
- 两河流域（小麦、大麦）
- 印度（水稻）
- 埃及（小麦）

这些地区都走向了大一统帝国。

### 多元经济 → 碎片化

- **游牧民族**：今天在这明天在那 → 征税、抓壮丁都找不着人。
- **欧洲**：山脉海洋切割 + 多元经济（畜牧/葡萄/橄榄/城市贸易）→ 统一战争太贵 → 长期碎片化。

> 欧洲难以统一，更根本的原因不是地理，而是没有单一农业心脏。

## 历史动力学的计算机模拟支持

研究者用 [[历史动力学cliodynamics]] 模拟发现：只要是农业核心地区，适合低成本征税养兵，那么战争就会变得便宜而且平常——最初不管是分裂成多少小国，最终一定会有一个大国统一天下。**统一战争是可以打得起的。**

## 利玛窦的"中国震撼"

> 西方传教士最初来到中国，往往会感到文明震撼——震惊于中国是一个如此统一而富裕的国家。  
> 利玛窦赞叹："欧洲出产的东西几乎在中国这一个国家全都能找到。"

中国从秦开始就已经是完善的官僚/税收/军队/制度的真正国家——但只是前现代国家，不是现代国家。

## 理论边界

斯科特理论主要用于解释古代帝国统一。但现代财政能力已不依赖谷物——这意味着该理论有解释边界。现代财政的"谷物"是 GDP、流转税、资本利得税等可数字化的财富形态。
