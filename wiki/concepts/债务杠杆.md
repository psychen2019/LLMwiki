# 债务杠杆（Debt Leverage）

## 定义

通过借贷放大本金撬动资产的机制。商业杠杆六类递进中"最引人注目、赚钱速度最快但也是最危险"的杠杆。

## 经典玩法：开发商预售-再抵押循环

```text
本金 1 亿
  ↓ 银行贷款（关系）
拿下一块地（资产）
  ↓ 楼未盖好，土地已涨
以土地作抵押再融资
  ↓ 融更多钱
买更多地
  ↓ 楼未盖好就预售
资金回笼
  ↓ 房价继续涨
融更多钱 / 拿更多地……
  ↓ 直到房价不涨
资产变回债务
```

只要房价一直涨 → 购房者接受预售、银行愿意贷款、所有人配合。直到卖不动的那一天。

## MM 定理：债务的中性立场

**Modigliani-Miller theorem（MM 定理）**：在理想市场中，单纯改变债务/股权比例不创造企业价值，只重新分配风险与收益。

### 反直觉澄清

- 创业项目本身创造价值，不是债务创造
- 项目明确是好的 → 根本不愁钱（入股 / 借款 / 自筹都行）
- 改变的是"谁承担风险、谁分享收益、谁先拿钱谁后拿钱"

### 真实市场修正

- 交易摩擦
- 税收条款影响债权 vs 股权选择
- 信息不对称

→ 债务可正当把资源从"有钱但不会用的人"转移到"没钱但是会用的人"手中。

### 结论

> "债务是一个中性的工具：如果判断错了，债务也会忠实地放大错误。"

## 与明斯基理论的对接

经济越繁荣 → 越有信心 → 越敢借债 → 系统越脆弱 → 融资结构滑落：

1. 对冲型融资（cash flow covers principal + interest）
2. 投机型融资（cash flow covers interest only）
3. 庞氏骗局型融资（cash flow covers neither）

详 [[明斯基时刻]]、[[稳定孕育不稳定]]。

## 债务杠杆与其他杠杆的根本区别

| 维度 | 好杠杆（信息模式） | 债务杠杆 |
|------|-------------------|----------|
| 反复执行 | 是 | 否 |
| 复制成本 | ≈ 0 | 不适用（金额要还） |
| 是否创造财富 | 是 | 否（中性放大器） |
| 偿付义务 | 无 | 有（债主早晚来敲门） |
| 危险度 | 低 | 最高 |

本讲立场：债务是"放大器"而非"信息模式"，与好杠杆有本质区别。
