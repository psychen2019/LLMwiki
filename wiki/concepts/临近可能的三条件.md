# 临近可能的三条件

## 定义

[[099_临近可能]]一讲提出的**可操作框架**：要让一个行动真正打开新的临近可能，它必须同时满足三个条件——临近、留构件、可组合。这是对"临近可能"这个抽象学说的工程化拆解。

## 三个条件

### 第一条：临近（Adjacency）

- **含义**：用你现有的知识、资源、关系，再加一次够得着的伸展，就能做成的事。
- **平衡点**：足够新才能打开新门，但也必须足够近才能被实现。
- **反义**：不是一步登天，也不是原地踏步。

### 第二条：留构件（Leave an Artifact）

- **含义**：行动结束后，世界上应该多出一样真实的东西——一篇文章、一个原型、一项经过实战检验的能力、一段共同做成过事的关系、一小群真实的用户。
- **反义**：仅仅"学过""想过""认识过""计划过"，世界不会有任何变化。
- **金句**："世界不会对你的潜力作出反馈，它只对你已经做出来的东西作出反馈。而反馈，会改变你。"

### 第三条：可组合（Combinable for Next Round）

- **含义**：评价一件事的标准不是"它现在给我什么回报"，而是"它做完之后，还能长出什么"。
- **反义**：以短期回报为唯一衡量标准的项目。
- **延伸**：这是"状态杠杆"和"能耐寻求定理"的更激进版本——不只是"为下一步预留状态"，而是"这一步本身就是下一步的零件"。

## 对应阶段

| 条件 | 对应阶段 |
|------|----------|
| 临近 | 探索（Exploration） |
| 留构件 | 利用（Exploitation） |
| 可组合 | 利用 + commit |

第一条讲探索，后两条讲利用——或者直白地说：**你得 commit**。

## 经典反例：工程师甲 vs 工程师乙

| 维度 | 工程师甲 | 工程师乙 |
|------|----------|----------|
| 起点 | 收藏夹里有 100 个绝妙点子 | 只有一个不怎么样的点子 |
| 行动 | 谁也不告诉，怕被抄；迟迟不动手，因为一旦做了就等于放弃别的 | 花两个月把它做成粗糙的小工具，发布 |
| 反馈 | 无 | 工具招来一堆吐槽，但藏真需求 |
| 演化 | 抱着之前那一百个可能不变 | 照吐槽改了三版 → 第一批用户 → 用户里冒出懂行的人 → 合作 → 公司看中 |
| 三年后 | 仍是原来的自己 | 变成自己原来根本想不到的样子 |

**核心洞察**：甲守住了"可能"，却没产生任何"构件"；乙只做了一个粗糙的构件，却打开了甲永远不会有的新可能。

## 与"期权思维"的根本区别

> "临近可能不是一个关于「期权」的学问。保留所有选项不会给你带来新的选项。你必须 commit 到一个选项上去，为此不惜放弃别的选项，才能打开下一扇门。"

- **期权思维**：保留所有可能 = 降低风险 = 增加未来选择。
- **临近可能**：保留所有可能 = 没有 commit = 没有真实构件 = 没有新可能产生。

这是对金融/博弈论"期权价值"思维的根本性反驳——在创造性探索领域，**commit 才是打开新可能的前提**，保留选择权反而关闭了可能性。

## 在三个应用场景中的具体化

### 学习场景

最好的学习单位不是"一门课"，而是**一个略高于当前能力、几周内能做出作品的项目**。三层限定正好对应：
- "略高于当前能力" → 临近
- "几周内能做出" → 留构件（不是听一遍就完）
- "作品" → 可组合（作品会替自己说话，会被引用、被组合）

### 职业场景

比较 offer 时，应该多一个维度：**干满三年，我手里会多出什么？**
- 有的工作光鲜但内容高度封闭，三年下来除了工资单什么都没留下 → 缺第三条。
- 有的工作看似平平，却让你攒下几个能搬走的构件 → 三条都满足。

**中年转行**最可靠的方式不是抛弃过去重新投胎，而是把过去攒下的模块搬进一个新组合——这是"可组合"条件在职业维度上的具体化。

### AI 时代场景

正确的问题不是"AI 会不会取代我"（问过去），而是"我已有的哪样本领，加上这些新零件，能组合出一个上个月还不存在的动作？"（搜索临近可能）。AI 让所有人的临近可能**刚刚被扩了一整圈**，关注新出来的领地才对。

## 与"脚踏实地"的重新定义

| 传统认知 | 临近可能视角 |
|----------|--------------|
| 目标高 = 好高骛远 | 在你临近可能范围内、哪怕听上去高级，也是合理的 |
| 守着一亩三分地 = 脚踏实地 | 不在临近可能范围内、哪怕是搬砖，也不能叫脚踏实地 |

这是一个反直觉的重定义：**判断标准不是"事本身的高低"，而是"事在你当前临近可能圈内的位置"**。
