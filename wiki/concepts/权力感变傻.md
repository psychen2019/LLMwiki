# 权力感变傻（Power-Induced Stupidity）

拥有权力或仅是"感觉有权力"会系统性降低认知、判断与同理心，导致决策质量下降。本讲命名为"权力使人变傻，变傻使人腐败"。

## 实证支撑

| 来源 | 时间 | 关键发现 |
|------|------|----------|
| 凯尔特纳等人 | 2003 | 提出接近—抑制理论：权力感降低敏感度 |
| Kelly See 等人 | 2011 | 实验诱发出权力感的受试者更自信、更不听劝、更易犯错 |
| 经颅磁刺激实验 | 2014 | 回忆支配经历降低镜像反应（神经层面证据） |
| Detert & Edmondson | 2011 | 四项研究：职场自我审查是潜规则产物 |

## 与"权力使人腐败"传统论断的差异

源文的关键洞察：

> 也许不是权力使人腐败，而是权力使人变傻，变傻使人腐败。

这一句改写了对权力与腐败的传统解释：
- 传统解释：权力 → 道德败坏 → 腐败
- 源文解释：权力 → 认知与同理心受损 → 错误决策 → 看似腐败

## 应对方法

| 工具 | 作用 |
|------|------|
| [[约束设计书]] | 主动放弃部分自由 |
| 不在兴头上拍板 | 给反对意见正式席位 |
| 事先写下判断、事后对账 | 不许改写历史 |
| 重大讨论最后发言 | 不用职位代替理由 |
| 任命外部反馈方 | 把纠正权交给外部 |

## 波普尔类比

参见 [[karl-popper]]（卡尔·波普尔）：

> 权力干的事，就是把一个人变成这样套"万能理论"——无论发生什么，都能证明他是对的。看上去无所不能，实际上已经失去了被现实纠正的能力。
