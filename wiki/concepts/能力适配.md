# 能力适配（Capability Fit）

## 定义

**能力适配**指**个人/组织自身能力与目标机会的匹配度**。在 [[d-n-s-三曲线趋势时钟]] 中，作为第四判据 **C**，与 D（需求）/ N（叙事）/ S（供给）三曲线并列存在。

> "没有这个 C，D/N/S 再怎么样也跟你没关系。"——万维钢，第 061 讲

## 在 D/N/S 框架中的位置

```
       D/N/S 都好
           ↓
    但你能力不够？
           ↓
       失败 = 给他人抬轿
```

即使 D/N/S 都处于最佳入场窗口，如果自身能力（资金、技术、渠道、人脉、运营经验）与机会不匹配，仍无法捕获红利。窗口期到来时，新涌入的供给会瞬间抬高竞争壁垒，能力不够的玩家会很快被洗出去。

## 能力维度的具体含义

| 维度 | 典型问题 |
|------|---------|
| 资金 | 现金储备能否扛过窗口期的烧钱阶段？ |
| 技术 | 是否掌握定义主导设计所需的核心技术栈？ |
| 渠道 | 是否有现成的分销/触达用户的路径？ |
| 人脉 | 能否获得关键供应商/合作伙伴/早期用户？ |
| 运营 | 是否有将该品类从 0 到 1 跑通的执行经验？ |
| 差异化 | 是否有能力在主导设计锁定前抢到一小块未锁死的设计空间？ |

## 应用例

- **小米造车**：D/N/S 上窗口接近关闭，但小米的智能生态/软件能力与人车家生态是 C 上能打的部分——所以仍敢赌。
- **微软 Zune**：D/N/S 上早已错过窗口，且微软在消费电子的渠道/品牌运营能力也未能与苹果匹敌——C 也不够。
- **个人案例（剧本杀店）**：即使哈尔滨旅游业带来 D、剧本杀叙事合法化、本地供给未过度饱和，若无运营/剧本/营销能力，C=0，机会与你无关。

## 与 [[竞争优势]] 的关系

能力适配是[[竞争优势]]的个人版/单次决策版——它不要求"长期比对手强"，而是要求"这一轮机会与你的能力谱系匹配"。

## 易被忽略的情形

1. **"机会太好所以我也能行"**：错——窗口期涌入最快的就是供给，能力不足者反而最先被卷出去。
2. **"我比别人能力强就行"**：错——主导设计一旦锁定，强能力的边际收益也会下降，必须在窗口期内入场。
3. **"我边做边学"**：部分适用，但窗口期不会给你太多学习时间——主导设计锁定通常比预想的快。
