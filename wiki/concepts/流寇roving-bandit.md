# 流寇（Roving Bandit）

奥尔森（[[曼瑟奥尔森mancur-olson]]）政府起源模型中与 [[坐寇stationary-bandit]] 对照的概念：一次性掠夺、无长期激励的暴力组织。

## 模型

```
流寇进村 → 抢光粮食、连种子都不留
→ 村民饿死
→ 第二年再想抢 → 没得抢
→ 流寇低级的抢法 → 不可持续
→ 倒逼演化为坐寇
```

## 与坐寇的对照

| 维度 | 流寇 | 坐寇 |
|---|---|---|
| 时间偏好 | 短期 | 长期 |
| 激励 | 一次性最大化 | 持续抽租 |
| 对被统治者 | 抢光 | 留活路、抽三成 |
| 自我认知 | 寇 | 统治者 |
| 可持续性 | 不可持续 | 可持续 |

## 模型价值

流寇→坐寇的演化不是道德进步，而是**激励结构变化**。奥尔森的洞见不在道德判断，而在视野长度改变后行为模式的必然变化。
