# 默认模式网络 (Default Mode Network, DMN)

## 定义

大脑在低认知负荷、未聚焦于外部任务时自动接管活动的一组神经网络。本讲称之为**"不快乐网络"**——它倾向于反刍过去、焦虑未来、做消极的自我评价。

## 触发条件

- 任务简单，工作记忆有大量闲置空间
- 没有外部高难度任务挤占资源
- 大脑"空转"时自动激活

## 典型活动

| 类型 | 内容 |
|------|------|
| 时间向度 | 反刍过去、担忧未来 |
| 自我评价 | 消极自我对话、自我怀疑 |
| 社会认知 | 揣测他人想法、想象他人评价 |
| 叙事建构 | 把碎片经验编织成自我叙事 |

## 与认知负荷的关系

```
高负荷任务 → 工作记忆占满 → DMN 被抑制 → 专注/心流
低负荷任务 → 工作记忆闲置 → DMN 接管   → 走神/内耗
```

这就是为何**真正的专注不是靠意志力压制走神，而是用高难度任务"挤走"走神**。

## 与不快乐的关系

基于 Killingsworth & Gilbert (2010) 的 25 万样本数据：

- 清醒时 46.9% 时间在走神
- 走神时幸福感下降
- 时间滞后分析建立因果方向：**走神导致不快乐，而非相反**

DMN 提供神经机制的解释：DMN 是走神的生理基础，而 DMN 的默认活动模式是不快乐的。

- **[[心流]]**：心流状态下 DMN 处于抑制状态

## 临床/社会意义

- 与抑郁、焦虑、自我反刍倾向相关
- 冥想训练的目标之一是学会观察 DMN 而不被其裹挟
- 长期低负荷 + DMN 反复激活 → 人格重塑（尽责性下降、神经质上升）
