# 科举思维 vs 商业思维

## 来源定义

来源用一个对照框架来破除"努力就该被奖励"的幻觉：

| 科举思维 | 商业思维 |
|---|---|
| 学技能 → 考证书 → 找工作 → 升职 → 加薪 | 处理小不确定性 → 赢得小信任 → 获得小杠杆 → 循环 |
| 世界是大考场 | 市场不是考场 |
| 我优秀所以该被奖 | 我能压缩不确定性所以值钱 |
| 等别人把需求说清楚 | 主动把模糊问题想清楚 |
| "带接口的模块" | "I own this"（极端所有权） |

## 科举思维的特征

- **隐喻**：世界是大考场，对人有一系列评价指标
- **信念**：做到优秀 → 世界就该提供相应待遇
- **误区**：把市场看作分配系统，而非创造系统
- **心态**：等别人把规则说清楚，等领导派任务，等产品经理提需求
- **典型话术**："我做对了，你们就得奖励我，否则就是你们不公平"
- **来源原话**：凭什么人家要给你搭建这么一个奖励环境？要知道你能坐在这里，是因为有人在替你负责。

## 商业思维的特征

- **隐喻**：市场是"焦虑→秩序"的转化器
- **信念**：我能压缩不确定性 → 我值高薪
- **路径**：财富复利循环（小不确定性 → 小信任 → 小杠杆 → 大不确定性 → 大信任 → 大杠杆）
- **心态**：主动扛一摊子，没人愿接的我来接
- **典型话术**："这块归我管 / 相关责任我来承担 / 出问题我不甩锅"

## 财富复利公式

> 科举思维：学技能 → 考证书 → 找工作 → 升职 → 加薪
> 商业思维：**处理小不确定性 → 赢得小信任 → 获得小杠杆 → 处理更大不确定性 → 赢得更大信任 → 获得更大杠杆……**

这是来源给出的"公司里的财富复利路线图"。

## ⚠️ 与现实的张力

来源猛烈批评科举思维，但**许多大公司的 HR 系统、晋升评审依然高度依赖证书与绩效指标**。这是来源与现实制度的张力——而非来源内部矛盾。

> 来源一方面说"高素质总会有些用处"，另一方面又说"世界奖励的不是努力和优秀"。这是**语气强调 vs 严谨论证**之间的轻度张力——并非逻辑矛盾，但容易被误读为反智。

建页时应保留这个微妙之处，不要把来源读成"努力无用论"。

## ⚠️ 循环起点问题

商业思维的循环公式有一个未充分回答的问题：**初始信任从哪里来？**

如果路径是"处理小不确定性 → 赢得小信任"，那最初的"小不确定性"场景需要：
- 公司愿意把某个模糊问题交给你（即使你不资深）
- 你的判断有试错空间（错了不致命）

这需要**初始的场景与权力下放者**——可能存在结构性不平等（不是所有人都能进入这种循环）。

## 与"极端所有权"的关系

科举思维 vs 商业思维的差异，本质上是**态度层的差异**：
- 科举思维：被动执行者（"我以为"）
- 商业思维：极端所有权（"I own this"）
