# 家产制（Patrimonialism）

韦伯提出的政治支配类型之一：统治者把国家视为自己的**私产**，老百姓被视为用于汲取的资源。

> 政府不是什么公共服务公司，而是统治者的家产。

## 特征

- 统治者把国家当私产；
- 老百姓是汲取资源，而非公民；
- 安全和机会不是由制度平等提供，而是由权贵私人分配；
- 政府与百姓的关系是"我投靠你、你庇护我"的依附关系；
- 皇帝连"我是为人民服务的"漂亮话都不屑于说。

## 中国帝制下的政治话语

```
《商君书》：「民弱国强，国强民弱。有道之国，务在弱民。」
《韩非子》：「君上之于民也，有难则用其死，安平则尽其力。」
「朕即国家」「为民父母」「食君之禄，忠君之事」「皇恩浩荡」
```

作者评价：再怎么讲，也只能是"文雅的坐寇"。

## 家产制的死循环

```
权力大 + 不受外部约束
→ 所有人都想接近 / 操纵 / 替代
→ 皇帝越不安全感 → 越猜忌
→ 越依赖私人忠诚 → 制度越坏
→ 权力更不受约束
（正反馈循环）
```

张宏杰统计：中国 611 位皇帝中，**非正常死亡率 44%**（272 人自杀/被杀），平均寿命仅 39.2 岁。"世界上还有比这更危险的职业吗？"
