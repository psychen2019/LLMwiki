# 坐寇（Stationary Bandit）

奥尔森（[[曼瑟奥尔森mancur-olson]]）在分析政府起源时提出的核心隐喻：相比一次性掠夺的 [[流寇roving-bandit]]，坐寇采取长期主义，给被统治者留活路以持续抽租。

## 模型

```
流寇：抢光 → 来年无物可抢 → 不可持续
坐寇：只抽三成 → 村民继续种地 → 长期主义 → 持续收租
观念跃迁：从"寇"变成"统治者"
```

## 核心洞见

> "坐寇变成的不是好人。变的只是时间偏好。强盗一旦学会长期主义，就开始像统治者；统治者一旦忘记约束，也随时能退回成强盗。"

这一洞见的要害不在道德判断，而在**时间偏好**——改变的不是动机，是视野长度。

## 当代活体案例

- 黎巴嫩真主党武装
- 意大利西西里黑手党
- 墨西哥北部某些毒贩集团

这些组织都"一边干着杀人越货的买卖，一边给当地百姓提供基本秩序服务"，甚至管治安、管判案、修学校、红白喜事都出面。

## 演化路径

```
坐寇之间开始打仗
→ 建立正规军队（多收税、养官僚）
→ 哪家"军队—税收—官僚"三件套干得好 → 哪家赢
→ 输的吞并，胜的更强
→ 最终威震四方 → 国家机器
张作霖路径：从"赵家庙保险队队长" → "东三省保安总司令"
```

## 衍生概念

- [[保护费与公共契约]]：坐寇的收入 → 现代税收的演化。
- [[合法暴力垄断legitimate-violence-monopoly]]：坐寇的国家化最终需要合法暴力垄断。
- [[战争制造国家]]：坐寇之间战争 → 国家机器强化。

## 与现代国家的关系

> 现代化 = 哪怕你是个坐寇，也要把你工程化。

坐寇模型不仅是历史起源的解释，也是分析现代国家的隐喻——任何掌握合法暴力垄断的组织，都可以被理解为"工程化的坐寇"。
