# 规划谬误（Planning Fallacy）

规划谬误指人做计划时**系统性**低估时间/成本/风险并高估收益的认知倾向。它不是偶然失误，而是大脑内一组「幻觉生成器」共同造就的稳定模式。

源文金句：「现实往往比你最悲观的估计还要悲观。」

## 实验证据

### 罗杰·比勒毕业论文学期预测实验

- 学生平均自评完成天数：33.9 天
- 强制悲观预测：48.6 天
- 实际完成天数：**55.5 天**（连最悲观估计都不够）

### 本特·弗吕博杰尔 258 个交通基础设施项目

- 铁路项目平均超支：**45%**
- 桥梁隧道平均超支：**34%**
- 公路平均超支：**20%**
- 悉尼歌剧院：预算 700 万美元 → 1.02 亿美元，工期 4 年 → 14 年

## 心理机制清单

规划谬误是多重偏差**叠加**的产物，不是单一偏差：

| 偏差 | 作用 |
|------|------|
| [[乐观偏差]] | 「这次一定顺」 |
| 确认偏误 | 只搜集利好证据 |
| [[控制错觉]] | 高估对世界的掌控 |
| [[自利归因]] | 把失败甩给外部 |
| [[幸存者偏差]] | 只看见成功故事 |
| [[可得性偏差]] | 凭想得到多少例子估计概率 |
| [[叙事谬误]] | 把碎片拼成热血剧本 |

## 与内部视角的关系

规划谬误的根源是使用 [[内部视角与外部视角|内部视角]]：只盯着这一件事的细节、努力、诚意、资源配置——而看不见同类项目的统计分布。

使用 [[参考类预测|外部视角]] 是系统化对抗规划谬误的工具。

## 影响范围

不只是普通人——专家、大型项目、企业家同样落入规划谬误。源文给出多个高调反例：

- 卡尼曼本人编教材团队：预计 2 年，实际 8 年。
- Helion：2021 宣称 2024 发电 → 推迟到 2028 → 2026 仅宣布里程碑。
- 埃隆·马斯克：特斯拉 FSD「明年实现」持续十年；SpaceX 1 亿美元 3 次发射前 3 次全炸。

## 对抗策略

1. **强制参考类预测**：把同类已结束案例的统计基线作为预测起点。
2. **强制悲观估计**：哪怕做了悲观估计，也要再加缓冲——比勒的实验显示连悲观估计都不够。
3. **P80 控制下的上调（uplift）**：成本上调 44%、工期上调 75%（香港政府 2012 年道路工程数据，参见 [[上调]]）。
4. **审查叙事脚本**：警惕把碎片信息拼成热血剧本的 [[叙事谬误]]。
