# 接口定位（Interface Positioning）

[[自我约束]]的第二种机制：通过边界清楚的契约，把自己变成生态中的公共设施（接口 / 基础设施）。

## 接口特征

接口首先是一份**边界清楚的契约**：
- 接受什么输入
- 保证什么输出
- 哪些事情绝不擅自改变

> 两个模块能对接的前提是双方都保证在接口处不越界。

## 案例

| 主体 | 定位 |
|------|------|
| 台积电 | 只做晶圆代工不做芯片设计 → 行业公共基础设施 |
| 餐馆 | 只做几道拿手菜 → 招牌 |
| 律师 | 只接某一类案件 → 该类案件首选 |
| 投资人 | 明确只看某个阶段、某个行业 → 创业者识别信号 |

## 战略要诀

源文归结为一句话：

> **使命要窄，输入要宽**。

- 使命太宽：别人不知道去哪儿找你
- 输入太宽：避免在生态位里越来越蠢
- 输入太窄：你会在自己的生态位里越来越蠢

## 与 [[不做清单]] 的关系

不做清单是接口定位的具体操作方法：主动排除 = 缩小使命范围 = 清晰化[[社会地址]]。
