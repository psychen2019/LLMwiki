# 不确定性压缩（Uncertainty Compression）

## 定义

> **不确定性压缩**：把模糊需求、跨部门扯皮、互相冲突的目标、没人愿意碰的责任，**压缩成一个可以判断、可以执行、可以负责的局面**。

这是 [[concepts/可托付性entrustability]] 的**操作层机制**——可托付性的"怎么做"。

## 三步操作

来源给出的"高端打工人三个动作"是不确定性压缩的具体路径：

### 1. 重新定义问题
- 你以为问题是 A，其实瓶颈在 B
- 把"表面问题"转化为"真实瓶颈"

### 2. 给出行动建议
- 不是"先讨论讨论"
- 而是"先做这个，验证一个小假设，再投入大资源"
- 保留选择权，按里程碑推进

### 3. 提供逻辑支撑
- 降低下行风险
- 争取时间
- 为下一步决策留证据

## 案例对照

| 案例 | 压缩的具体类型 | 操作动作 |
|---|---|---|
| **蒂姆·库克供应链** | 全球工厂 / 库存 / 渠道 / 现金周期 | 拧成一台机器，灵活响应市场 |
| **高端项目经理** | 模糊需求 / 跨部门依赖 / 互相扯皮 | 需求转规格 / 依赖转里程碑 / 扯皮转可追责接口 |
| **高端软件开发者** | 系统崩溃 / 尾部风险 | 保证系统不崩溃 |
| **高端财务经理** | 现金流断裂 / 预算偏差 | 现金周期 + 尾部风险管理 |
| **高端律师** | 法律模糊地带 | 模糊转合同边界 / 交易路径 / 合规红线 |
| **合规负责人** | 罚款 / 诉讼 / 牌照丢失 | 提前识别风险 + 守住红线 |
| **A 股董秘** | 资本市场信息披露 / 投资者关系 / 监管问询 | 公告 + 沟通 + 监管应对 |

## 来源原文

> 你能不能把这一团混沌的信息、互相冲突的目标、没人愿意碰的责任，压缩成一个可以判断、可以执行、可以负责的局面？

> 库克把全球工厂、库存、渠道、交付、现金周期拧成一台机器，确保灵活响应市场，那可是最高级的不确定性压缩。

## 与"主动推断"的关联

来源提到"人才判断和行动本质上是企业有机体在进行「主动推断」"——这是把不确定性压缩类比为认知科学中"主动推断"（Active Inference / Free Energy Principle）框架的隐喻。
