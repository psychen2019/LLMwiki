# Doxa（本见 / 正统观念）

## 定义

**Doxa**（希腊语，本见 / 正统观念）是 [[entities/皮埃尔·布迪厄]] 提出的核心概念之一，指场域里**不言自明、理所当然以至于意识不到**的底层信念。

> "你可以说这就是『潜规则』，但它是更理所当然的潜规则：你往往甚至都意识不到它的存在，你自然地就觉得事情本来就应该是这样。"

## 关键特征

1. **不可挑战性**：在场域内被当成"物理定律"，挑战 Doxa 不是挑战某个人，而是挑战整个场域的结构
2. **意识不到**：身处场域中的人自然认为事情本来就该如此
3. **场域特异性**：每个场域有自己的 Doxa，**读书人自以为是的那套通用"常识"往往行不通**
4. **比"潜规则"更底层**：潜规则至少是"不能说"，Doxa 是"想都不会想"

## 常见场域的 Doxa

| 场域 | Doxa |
|------|------|
| 事业单位 | 领导永远是对的、团结压倒一切 |
| 学术界 | 纯理论性、艰深性、反通俗 |
| 春节家庭聚餐 | 孝顺、长辈说啥都是对的 |
| 大学辩论队 | 论证套路的合规性 |
| 科技创业公司 | 黑客精神、搞定难题 |

## 作用机制

- 识别 Doxa 是 [[concepts/场域]] 游戏攻略的第二步
- 违反 Doxa 会遭到**整个场域的排异反应**
- 掌握 Doxa 是 [[concepts/象征资本]] 积累的基础

## 与"潜规则"的区分

| 维度 | 潜规则 | Doxa |
|------|--------|------|
| 显隐性 | 不可明说 | 想都不会想 |
| 意识程度 | 大多数人隐约知道 | 绝大多数人无意识 |
| 违反后果 | 惩罚 | 排异反应 |
| 表述形式 | "大家都懂但不能挑明" | "事情本来就该这样" |

## 案例

- **事业单位案例**：新人"你"在例会上点出领导决策的风险，挑战的是"领导永远是对的"这一 Doxa。结果绩效评价为"不够成熟、急功近利、不懂协作、缺乏大局观"。
- **卡尔·萨根案例**：学术界的 Doxa 推崇纯理论性，萨根"太著名、太通俗"直接违反 Doxa。

## 与 [[concepts/稳态生存逻辑]] 的关系

Doxa 是稳态生存逻辑的**结构化版本**。稳态生存是个体策略，Doxa 是场域层面的"理所当然"。识时务者（如小许）之所以不痛苦，正是因为他的 [[concepts/惯习]] 与场域 Doxa 天然兼容，甚至他根本不觉得那叫"识时务"——那就是他理解的"世界本来如此"。
