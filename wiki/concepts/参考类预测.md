# 参考类预测（Reference Class Forecasting, RCF）

参考类预测是一种预测算法——以**同类已结束事件**的统计分布为基线预测自己。其思想起源于 [[丹尼尔·卡尼曼]] 与 [[阿莫斯·特沃斯基]] 的展望理论工作，并由 [[本特·弗吕博杰尔]] 在工程领域标准化。

源文称 RCF 不只是一种预测方法，更是一个「反自恋装置」：当你觉得自己「很特殊」、「这次一定不一样」时，最该先用这个工具。

## 一句话定义

> 看同类事情的历史分布，而不是看自己的内部故事。

## 与内部叙事的关系

| | 内部叙事 | 参考类预测 |
|------|------|------|
| 关注对象 | 这一件事的细节、努力、诚意 | 同类已结束案例的统计分布 |
| 信息类型 | singular information | distributional information |
| 主体身份 | 主角 | 样本 |
| 适合场景 | 给自己打气、启动项目 | 决策、计划、风险评估 |

源文金句：「具体做事，不妨用内部叙事给自己打气；决策，却必须用外部参考类给自己泼冷水。」

## 三步法（弗吕博杰尔标准化）

1. **找参考类**：找一组与你相似且**已结束**的案例（不是偶像，而是相似者）。
2. **看分布**：查询基线——平均、中位数、尾部风险、失败率。
3. **放回对比**：将自身项目放入对比，按客观情况微调；最简即直接取参考类中位数。

纪律：若声称「我与别人不一样」，必须出示强证据。否则只是把偏见悄悄放回来。

## 与机器学习的对应

RCF 的本质与现代 ML 算法高度同构：

- 训练集 ≈ 参考类
- 相似性度量（similarity metric）≈ 用什么特征判断「与我相似」
- 预测值 ≈ 在参考类中找到的最相似样本的结局

电影票房的「随机森林（Random Forest）」预测模型（2023 年研究）把「能否覆盖成本」预测准确度提到 90%——这是 RCF 工业化的代表案例。

## 核心应用

- **大型工程**：258 个交通项目实证显示铁路平均超支 45%、桥梁隧道 34%、公路 20%（[[本特·弗吕博杰尔]] 数据）。
- **P80 风险控制下的上调（uplift）**：香港政府 2012 年把本地 25 个道路项目与 863 个国际同类项目对比，成本上调 44%、工期上调 75%（参见 [[上调]]）。
- **企业并购**：平均来看收购方业绩并不因并购改善。
- **核聚变**：无现成参考类时用相似高复杂度项目类比，上调约 118%；用国际级大型科研基础设施做参考类可达 220%。
- **日常生活**：求职薪资、婚恋匹配、学习/搬家/装修规划。

## 关键纪律

1. **参考类必须「已结束」**：避免 [[选择偏差]] 污染样本（成功项目更容易被报道）。
2. **必须能容纳「我不一样」**：但要求硬证据，否则就是偏见回归。
3. **最简做法即中位数**：除非有强证据支持偏离中位数。
4. **个案信息不要直接进入预测**：个案信息用于微调中位数，而非替代中位数。

## 与其他概念的关系

- 与 [[规划谬误]] 直接配套：RCF 是系统化对抗规划谬误的工具。
- 与 [[内部视角与外部视角]] 是同一对偶的另一种表述。
- 与 [[贝叶斯主义]] / [[先验]] 互补：RCF 提供的基线本质上是一种经验先验，个案信息相当于更新后的似然。
- 与 [[幸存者偏差]] 互补：RCF 显式要求对抗幸存者偏差。
- 与 [[WOOP]] 的张力：RCF 给基线，WOOP 给动机；源文指出两者要分场景使用。
- 与 [[反脆弱]] / [[非对称风险]] 的潜在冲突：RCF 给中位数，反脆弱要求做凸性组合（见 [[查询：RCF 在大型项目中是否与反脆弱冲突]]）。

## 限制与开放问题

- **参考类缺失**：当领域没有相似已结束案例（如核聚变），只能勉强类比，上调数字的合法性存疑。
- **赢家通吃型分布**：电影票房 10% 吃 70%——给中位数会严重误判尾部收益。
- **过度 RCF 化**：「声称例外需硬证据」的纪律是否会筛掉真正的反常者？
