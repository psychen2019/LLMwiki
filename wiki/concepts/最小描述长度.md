# 最小描述长度（Minimum Description Length, MDL）

## 定义

信息论中把[[奥卡姆剃刀（Occam's Razor）|奥卡姆剃刀]]变成可计算准则的版本。最佳模型应当使得以下两项之和最小：

```
最佳模型 = argmin( 模型长度 + 数据补丁长度 )

其中：
  模型长度     = 描述模型本身所需的比特数（模型有多复杂）
  数据补丁长度 = 用此模型解释现实时，还要补充多少例外说明
```

## 核心思想

> 最好的模型，是那个能用最短的代码长度，解释最多数据的模型。

## 与奥卡姆剃刀的关系

奥卡姆剃刀："如无必要，勿增实体"——一个原则性指引。
MDL：把这一原则变成可计算的最优化目标。

两者本质相同，但 MDL 在模型选择问题（model selection）中提供了具体的算分函数。

## 关联格言

> 理解即压缩（Understanding is Compression）。

练成这个功夫，你就是那个传说中"花半秒钟就看透事物本质的人"。

## 应用示例

### 天气描述的 MDL 选择

| 描述 | 模型长度 | 数据补丁长度 | 总和 |
|---|---|---|---|
| 列举一年每天的天气 | 长 | 短 | 过大（过拟合） |
| "这地方总下雨" | 短 | 长（要解释不下雨的日子） | 过大（欠拟合） |
| "温带海洋性气候，受西风带控制，全年温和湿润，阴雨多但少暴雨" | 中 | 短 | **最小** |

## 与其他概念的关系

- **[[concepts/颗粒度]]**：MDL 是颗粒度的可计算判定准则
- **[[concepts/过拟合与欠拟合]]**：MDL 显式惩罚这两个极端
- **[[concepts/模型思考]]**：MDL 是好模型的硬性数学要求

## 局限

MDL 提供了算分函数，但没有规定哪些特征算"模型的一部分"、哪些算"数据补丁"。颗粒度的**主观性**（见 [[concepts/颗粒度]]）仍然存在。
