# 系列专栏·段 F part 1：089–093（人身依附+古德哈特+指挥官意图+委托代理+流程清单）

## 概念 0 — 人身依附 vs 角色责任

> 来源：089_人身依附 + 086_组织资本 + 075_保护费 + 069_地位
> **前现代管理灵魂 = 人身依附**；**现代管理 = 角色责任**。前现代四字：**恩威亲表**（恩 = 个人恩惠制造依附；威 = 恐惧压出服从；亲 = 重用亲信；表 = 表忠心——列队鼓掌/喊口号/写心得）。**现代管理**：用职位规定权限+流程传递信息+指标反馈结果+审计追索责任——**人可以流动角色还在/感情会变接口还在**。**邓巴数（Dunbar's number）150 人**：大脑新皮层硬约束——最多只能信任这么多人。**亨利·梅因（Henry Maine）"从身份到契约（from status to contract）"**：现代化本质 = 走出人身关系网走进自愿契约关系。**Bloom+Van Reenen 世界管理调查**：管理分与生产率/出口强相关；中美的差别是中国企业比美国企业更急需提高管理水平。**家族企业死循环**：不信任制度→依赖亲人→制度长不长出来→更不信任外人→长子继承制全世界管理最差。中国大陆 19% 家族企业有成文接班计划。**李新春**："做三五年靠人/机会，做三十五十年靠制度"。**诺斯（North 1993 诺奖）**：复杂分工要扩展就必须从人格化交换（personal exchange）走向匿名非人格化交换（anonymous, impersonal exchange）。

## 概念 1 — 古德哈特定律（Goodhart's Law, 1975）+ Strathern 金句

> 来源：090_古德哈特 + 081_非预期后果 + 040_前景理论
> Goodhart 1975：央行说一个统计规律一旦当调控目标往上使劲它就会塌掉。**Strathern 1997 金句**："当度量变成了目标它就不再是一个好的度量"。**真实目标 vs 代理指标**：体重/考分/论文数/bug 修复数/点赞数 → 优化压力 → 适应行为 → 真实目标被忽略。**古德哈特定律的两个近亲**：卢卡斯批判（经济政策）+ 坎贝尔定律（社会指标越被用来做重大决策越容易腐蚀）。**AI 训练也是**：模型把从"机器人裁判"得到的分数刷得太高，真实本事反而往下掉。**学术界是重灾区**：1999-2016 中国高校 SCI 现金奖励最高 16.5 万美元（年薪 20%）→ 中国 SCI 撤稿占全球一半 → Nature Index 中国第一但无诺贝尔奖发现 → 2020 教育部科技部联合发文件承认 SCI 被"片面/过度/扭曲使用"。**反古德哈特三条原则**：① 指标只做素材不做判决书 ② 用代表作评价配书面理由 ③ 评价按角色分类。**莱顿宣言 2015 Nature**：定量评估只能支持不能取代专家定性判断。**英国 REF**：禁期刊影响因子→看有限代表作+真实社会影响+研究环境说明。**Porter 1995《对数字的信任（Trust in Numbers）》**：量化是"做了决定却装得好像没人在做决定"的客观性——**给权威不足的官僚凭空借来一层权威**。**病根不是权力太强而是权力太弱；不是管得太狠而是没本事没权威去管**。

## 概念 2 — 指挥官意图（Commander's Intent）+ 任务式指挥（Mission Command）

> 来源：091_指挥官意图 + 044_OODA环 + 085_剩余判断权 + 090_古德哈特 + 007_内核
> **AI 范式转移**：提示工程 → 情境工程 → **循环工程/驾驭工程（harness engineering）/智能体编排（agent orchestration）**。**1806 普鲁士军事改革 → 毛奇 → Auftragstaktik（任务式战术）**：计划注定失效所以必须允许前方人员灵活发挥。**美军 Mission Command**：最核心的就是指挥官意图。**Bungay 三重落差**：知识落差/对齐落差/效果落差。**孙子兵法**："将能而君不御者胜"。**任正非**："让听得见炮声的人来决策"（明示借鉴美军参谋长联席会议组织模式）。**任务式指挥不是更少的控制而是更强的控制——统一判断标准**。**三元素**：目的（为什么打这一仗）/ 关键任务（必须做成的几件事儿）/ 终态条件（事成之后局面必须呈现哪些看得见的状态）。**边界（constraints）**：法律道德红线+军队纪律+交战规则+任务硬约束。**意图必须短到让下面两级指挥员都能背下来**。**五条件**：胜任力/互信/共同理解/风险接受/有纪律的主动性。**腓特烈·卡尔亲王 1866**："陛下让你当少校就是相信你知道什么时候不该执行命令"——**当原命令不再适合现实时下级有责任在指挥官意图范围内调整行动并在可能时报告**。**宋朝阵图 = 现代的 SOP + 需求文档 + 甘特图**——低水平组织奖励"不犯错"培养听话人才。**央行独立性 = 现代化国家治理的意图式治理**：政治系统定义意图（最大就业+物价稳定），专业机构选择手段——**有纪律的主动性**。**现代人真正的忠诚不是忠于命令也不是忠于人而是忠于理念**。

## 概念 3 — 委托-代理问题（Principal-Agent Problem）+ 代理成本

> 来源：092_委托代理 + 072_激励相容 + 074_外部性 + 076_软预算约束 + 089_人身依附
> **委托-代理问题 = 因为替你做事的人不是你而导致的问题**。**韩非子 2000 年前**："上下一日百战""君臣之利异故人臣莫忠"。**三机制**：① **逆向选择**（柠檬市场——看不清请的代理人是什么人）② **道德风险**（看不清他干了些什么——信息不对称+难以追责=肆意妄为）③ **多任务委托-代理（Holmström+Milgrom 1991）**（你委托一组任务其中有易度量有极难度量→奖励易度量→他专攻易度量放弃难度量——装修老板说工期越快越好他就拼命赶工期，防水涂料刷几遍/水泥养护够不够天数就对付）。**目标翻译问题**：价值目标 → 合同条款 → 考核指标 → 奖惩 → 代理人动作（目标每翻译一次就变窄一格）。**委托人三样不能交出去**：① 目标解释权（不能由他单方面定义什么叫"为你好"）② 信息解释权（不能让他成为你唯一的信息来源）③ 最终裁判权（不能由他验收自己）。**信息量原则（Informativeness Principle, Holmström）**：值得看的信号只有一种——能帮你把"他干得怎么样"从"他说得怎么样"里分离出来的信号——原始记录（票据/照片/系统日志）+ 中途检查 + 第三方验证。**剩余判断权**：合同没写到的地方最后必须还有人说了算。**代理成本三笔（Jensen+Meckling）**：监督成本 + 担保成本 + 剩余损失（理论上把偏差监督到零的成本无穷大所以偏差永远存在）。**管家理论（stewardship theory）**：代理人也会被职业荣誉/使命感/尊重驱动——**能在制度上防小人就可以在关系上把人当君子**。**雍正密折**= 术的极致：术不可见/威不可测——**现代社会 = 制度化的合作空间（你得让他相信按规则把事做好比提前防你绕你耗你更划算）**。**委托人三件事上绑住自己**：给公平报酬 / 允许说不可能 / 不把运气当罪责。

## 概念 4 — 智件（cogware）+ 流程清单经验库

> 来源：093_流程清单 + 086_组织资本 + 085_剩余判断权 + 090_古德哈特 + 051_默会知识
> **智件（cogware）= 长在组织身上的聪明**。公司=用人运行的智能体——**方法=技能 / 标准=护栏 / 经验=记忆**。**纳尔逊+温特**：惯例（routine）= 企业的基因。**1999 华为 IBM IPD 集成产品开发**："先僵化，后优化，再固化"——**头几年原样照搬不许擅自改良"先买一双美国鞋不合脚就削足适履"**——任正非："个人聪明必须被翻译成技能否则聪明就会被规模吞噬"。**小团队靠默契大组织靠接口**。**2009 WHO 手术安全清单 19 项 8 国 8 医院**：死亡率 1.5%→0.8% 并发症 11%→7%——**最训练有素的外科团队就会在这些地方翻车**。**错误不是来自无知而是来自疲劳/打断/赶时间/"我以为你查过了"**——不可逆动作之前都要有护栏。**认知卸载（cognitive offloading）**：用外部动作降低脑子的认知负荷——清单替你记住琐事你的注意力才能解放出来想别的。**1996 长征三号乙 22 秒失控爆炸 → 归零制度（定位/机理/复现/措施/举一反三）→ ISO 18238 国际标准**。**苏兰斯基知识内部黏性（internal stickiness）**：别家 OKR 成功自己学也失败——**器官是好器官可你的身体会排异**。**三重境界**：① **人治组织**（一切以老板意图为先/业务跟人走=人身依附规模一大必然乱）② **流程组织**（有技能有护栏/稳定可复制可规模化——绝大多数公司毕生追求）③ **学习型组织**（流程不是最终答案而是当前版本——**绕开流程不是违规而是信号**）。**科学方法不是一套具体的知识而是一套让聪明可以积累的智件**——创新是变异/实验是选择/流程是保留。**宋应星《天工开物》**在清朝中期就已无人知晓，日本 1771 和刻本却代代研读——**中国从来不缺个体的天才但是前现代文明没有一套让天才不白活的智件**。# 系列专栏·段 F part 2：095–099（基线漂移+认领授予+生成+对称性破缺+临近可能）

## 概念 5 — 基线漂移（Shifting Baseline, Pauly 1995）

> 来源：095_基线漂移 + 039_回归均值 + 040_前景理论 + 105_适应性循环 + 067_平台
> **Pauly 1995** 发现：每一代渔业科学家只看见自己职业生涯里那一小段下跌——基准不知不觉往下挪。**佛罗里达 Key West 1956 钓鱼照**：半个世纪里"战利品鱼"平均个头从 19.9 kg 缩到 2.3 kg——缩了将近九成——可照片上渔民的姿势笑容一模一样。**三机制**：① **前景理论**：月薪两万幸不幸福取决于之前一万还是五万（参照点偷偷下挪）② **适应水平理论（Helson）**：感官判断依赖于过去刺激平均水平（搬进临街房子三个月就适应了车流噪声）③ **偏差正常化（Vaughan 1996）**：一个违反规范的做法只要没立刻出事组织就逐渐把它接受为正常操作下次心安理得。**六步循环**：① 压力小越界（"就这一次下不为例"）② 没出事（幸存被当安全证据）③ 破例有判例（"上次就是这么干的"）④ 主客易位（简化版成默认动作要走老流程反而要特批）⑤ 代际失忆（新人学的就是简化版）⑥ 免疫反应（拿历史说事恢复老规矩被全体白眼）。**大明铁牌"内臣不得干预政事预者斩"240 年** → 魏忠贤 + 配享孔子——**中间每一步都有当时道理也未尝没人表达不满但漂移从未回转**。**2021 得州电网崩溃**：孤网（躲避联邦监管）+ 防冻改造不足 + 气电死亡螺旋——风机冻住只是出事的契机。**比亚迪付款周期 123 天（2025）vs 国家规定 60 天 vs 自身一年前 127 天**——**基线只是稍有停滞然后继续漂移**——以我之见这些办法之所以效果有限是因为它们都是在防守；底线是静态的压力是动态的；规矩立在那里不动绕过规矩的理由每天都在生长。**星巴克尼科尔改革（2024 Back to Starbucks）vs 瑞幸 9.9 元**：防守 vs 进攻——"回字一出来基线就已经漂移了"。**df/dt 才是关键**：年轻有冲劲的人从来不想保持身材更不想养生，他们只关心 df/dt。**理想主义者 = 心里装着"事情本来应该是什么样"的图景因此看什么都不顺眼的人**——普通人不该当领导，他应该被领导。

## 概念 6 — 认领 / 授予 / 授权（DeRue & Ashford 2010）

> 来源：096_认领授予 + 087_叙事权 + 085_剩余判断权 + 091_指挥官意图 + 069_地位
> **领导力**：发现共同目标/作出判断/协调多人行动并对结果负责的能力。**权力**：对资源/岗位/判断权的不对称控制。**领导力怎么变成权力**：三张签名——① **认领**（自己签，向众人表明我有领导力）② **授予**（同事签，证明不靠强制手段也能让人协调行动）③ **授权**（组织签，给相称职位资源和权限）。**Ursula Burns 1990 经济舱对话 → 2009 施乐 CEO**（史上第一位《财富》五百强黑人女性 CEO）。**希克斯**："你有知识有本事可是你还没有可信度（credibility）—— 人们得愿意跟着你走你必须'创造追随（createfollowship）'才算行"。**2019 销冠→经理负相关研究**：最好的个人贡献者不一定是最好的领导者——会做事和能让一群人共同做成事是两种本事。**领导身份建构（DeRue & Ashford 2010）**：11 条命题；个人-关系-集体三个层次——领导身份由你和人群在互动中共同建构。**低晋升性任务（low-promotability tasks）**：张罗聚餐/写会议纪要/给新人答疑/填各种表格——**别做组织的免费保姆要做关键问题的主人**。**普通专家只能解决单个任务；事实上的领导者解决任务与任务之间的冲突；正式领导者为这些冲突承担最终后果**。**声望路线 vs 支配路线**：吓唬人也能上位但只有声望换来的敬意和追随是成员自愿给的——**你想提升地位你的发言必须是促进性建言（promotive voice）遇事儿给方案**（2026 研究）。**2023 OpenAI 奥特曼回归**：770 名员工 700+ 联名要求回来——**组织的授权往往只是把前两张签名正式化**。**曾国藩 1857-1860**：赶上太平天国危急时刻自己认领难题但朝廷就是不给他地方实权——**越能干掌权者越需要你也越怕你**。

## 概念 7 — 生成（Generativity, Erikson 1950）+ 组织闭合 + 可演化性

> 来源：097_生成 + 099_临近可能 + 086_组织资本 + 095_基线漂移 + 078_可读性
> **Erikson 1950 生成感 vs 停滞（generativity vs stagnation）**：人到中年撞上一道坎——是培养后来人造点能进入未来的东西还是守着过完算了。**Doerwald 2021** 48 项研究 15000+ 人：生成动机较强的人也有更强的工作干劲/职业效能感/工作满意度/导师关系。**控制半径很小因果半径越来越大**——学生沿你指出方向走到你没去过的地方/孩子形成与你不同却更适合自己的判断/事业在你退休以后更加兴盛。**组织闭合（organizational closure）**：要看维持系统活下去的关键环节能不能在系统内部彼此维持形成闭环——三问题 ① 成果能换下一轮资源 ② 现在的人能带出下一批人 ③ 离开创始人关键决定还作不作得出来。**张謇案例**：纱厂失败/伶工学社停办/南通博物苑被毁——但学校医院延续（资源依赖纱厂无独立财务；管理只系张謇一人；学校医院形成了专业队伍知识传统社会声誉找到了新供养者）。**范仲淹范氏义庄 1050-1950 901 年**：组织闭合四要素全满足——不得子孙分割典卖的范氏公产+族人公举的"主奉"+照章办事+共同商议+族内监督和官府最后执行。**可演化性（evolvability, Wagner & Altenberg 1996 / Gerhart & Kirschner 2007）**：**变异加选择并不自动带来进步；真正决定成败的是系统的结构能不能让一处局部的改动产生一点局部的改进而不是一动就全盘垮掉——核心稳定外围可变**。**三心法**：① 给边界不给剧本（事业为什么存在/为谁服务/什么绝对不能做 = 慢变量）② 把试错切小（每次让局部先试失败不拖垮整体）③ 接受现实的筛选（不能光说鼓励创新没人担后果也没项目真死掉）。**朱元璋《皇明祖训》"一字不可改易"** → 海禁错过大航海/卫所空心化 → 后世隆庆开海证明松一道缝就足够——**旧制度名义还在新办法只能作为例外和临时措施生长** → 财政/寻租/改革越来越难。**任天堂/Harvard/西游记/美国 250 年**：守住核心演化外围——**真正的过去不但有状态 f 还有变化率 df/dt**。**老子"我无为而民自化"+"太上不知有之"**：优秀的生成者不再要求所有权只要人们感谢他就可以了；伟大的生成者甚至不要求别人记得他。**"揽物盈怀终是占，放身入世始为生"**——**若要成就一桩事业你就必须交出自己的不可替代感**。

## 概念 8 — 对称性破缺（Symmetry Breaking）+ 路径依赖

> 来源：098_对称性破缺 + 024_探索利用 + 099_临近可能 + 104_路径创造 + 105_适应性循环
> **Anderson 1972《多者异也（More Is Different）》**：破缺的对称性是理解世界为什么一层一层长出新秩序的钥匙。**方程对称结果破缺**——万事万物由此展开。**命运不过是冷却了的偶然**。**暴胀理论（Guth 1981）**：宇宙诞生后远远不到一秒经历过一次暴胀——把量子涨落拉伸到宏观尺度冻结成宇宙密度分布底稿。**电弱对称性破缺**：希格斯场撑不住如桌上铅笔随机倒向一个方向——电磁力和弱力分家电子夸克有了质量。**正反物质不对称**：每十亿零一个正物质粒子——宇宙所有普通物质。**十亿分之一的零头构成今天所有普通物质包括你——完美的东西应该绝对对称可绝对对称意味着什么都没有**——**破缺是世界的生成机制不是瑕疵**。**涨落冻结+希格斯站队+正反物质湮灭**都是让一点偶然差异被选中被放大然后被永久保存。**1947 印度分治西里尔·拉德克利夫**：身在德里根据地图/人口普查/听证材料做出的裁决——**改变同一件事趁热的时候不费吹灰之力冷却了就像移动星系一样难**。**秦始皇书同文**：各国文字早已分叉但还没有各自养出几百年的经典/成熟公文/大批读书人——**可塑性不是权力的函数而是温度的函数**。**开创者怎么干都有理绝大多数人是在玻璃冷透之后才想起自己对它的形状有意见**。**三心法**：① 观察系统的可塑性（热系统必须有不止一个未来活着）② 寻找序参量（能把无数局部选择压缩成一个宏观方向的那个量——采用 A 的比例减采用 B 的比例）③ 寻求可固化性（确保你这一小步能被系统记住——小动作会反复回响不死）。**顺序**：命名 → 样板 → 公开 → 固化。**危机暂时把改变的成本打了折**：趁一切还是碎的重新拼一个更好的。

## 概念 9 — 临近可能（Adjacent Possible, Kauffman 2000）+ 不可预先陈述性

> 来源：099_临近可能 + 021_赛道选择 + 062_效果推理 + 037_状态杠杆 + 008_君子不器
> **Kauffman 2000《调查（Investigations）》**：任何系统在任何时刻周围都存在一圈"只差一步就能实现"的新状态——**现有零件做一次组合/一次改动就够得着的东西**——临近可能。**生命起源**：原始地球化学汤里本来没有 DNA 的位置只有简单分子——简单分子组合成稍复杂分子→每种新分子出现又让一批此前根本不可能发生的化学反应变成可能→**可能性的边界会随着每次对之前可能的"实现"向外扩张**。**Steven Johnson 2010《伟大创意的诞生》**：你身处一栋魔法房子推开一扇门走进一个新房间而房间墙上又长着几扇你在上一个房间里根本看不见的新门。**重大发明为什么总是"撞车"（莫顿 1961）**：牛顿和莱布尼茨/达尔文和华莱士/贝尔和格雷 1876.2.14 同一天——**大家住在同一栋房子里走廊尽头那扇新门是房子自己长出来的**。**Arthur 2009 组合进化（combinatorial evolution）**：新技术全都是已有技术的组合——**工具箱越大创造新工具就越快**。**Hidalgo+Hausmann 2007 产品空间**：国家产业升级通常不是凭空跳跃而是先做成跟现有能力"相邻"的产品。**不可预先陈述性（unprestatability, Kauffman+Longo+Montévil 2012）**：未来的可能性你想象都想象不出来——**演化没有运动方程**——螺丝刀的全部用途你列不完因为用途不是螺丝刀的内在属性是它跟所有场景的组合而未来场景还没长出来。**激光 1960 年**：研发人员自嘲"一个寻找问题的解决方案"——撑起激光产业的是超市条形码/光纤通信/近视手术。**张忠谋 17 岁作家/24 岁 MIT 落榜/52 岁辞职/55 岁台积电**——"我的黄金时代是 60-85 岁"——**不可预先陈述性说你无法提前忠于一个还不存在的自我你只能走过去把它走出来**。**三条件**：① 它必须是临近的（用现有知识/资源/关系再加一次够得着的伸展）② 它必须留下一个现实的构件（世界里应该多出一样东西）③ 它必须能参与下一次组合（"它做完之后还能长出什么"）。**保留所有选项不会给你带来新的选项**——**你必须 commit 到一个选项上去为此不惜放弃别的选项才能打开下一扇门**——世界不会对你的潜力作出反馈它只对你已经做出来的东西作出反馈。**临位可能是位置不是身份**——**前往下一个位置你会发现现在的你想象不到的可能**。# 系列专栏·段 F part 3：101–105（反馈回路+自组织临界+边际分析+路径创造+适应性循环）

## 概念 10 — 反馈回路 + 强化回路 vs 平衡回路 + 闭环控制 + 冷启动

> 来源：101_反馈回路 + 102_自组织临界 + 104_路径创造 + 037_状态杠杆 + 098_对称性破缺
> **强化回路（正反馈改名）**：制造增长——不管好东西还是坏东西——复利/病毒传播/债务滚雪球。**平衡回路（负反馈改名）**：制造稳定——恒温器/补货/家庭预算/体温调节。"天之道损有余而补不足"= 平衡回路；"人之道损不足以奉有余"= 强化回路。**马太效应**= 强化回路。**减肥案例**：吃→脂肪增加→更少动→更多脂肪 vs 少吃→身体降耗放大食欲——**不是在跟脂肪作战而是在跟平衡回路作战**。**快回路挤压慢回路（Repenning & Sterman 2001）**：压力越大"更努力地工作"挤压"更聪明地工作"——**组织越来越不聪明变得越来越依赖于救火最终变成只能靠救火维持的森林**。**闭环控制 vs 开环控制**：闭环 = 打几枪看看弹着点调一调几枪上靶；开环 = 事先做好测算找最佳力度发出命令不根据反馈调整——**开环依赖圣明闭环依赖纠错**——绝大多数医院给病人治病开了药出了院回家不几个月后回访——**这么重要的工作竟然没有正式的反馈机制你不觉得很荒唐吗**。**邓小平改革开放 = 闭环控制** = 治国没有那么复杂操控复杂度跟做饭差不多——老子"治大国若烹小鲜"——更重要的意思是国家经济就如同小鱼一样脆弱不能来回胡乱翻动——**这里需要的是慢回路而不是快回路**。**冷启动 4 心法**：① 别照着终点做起点（用户/名气/资本都是大回路转起来以后的产物不是第一圈的燃料——第一圈真正的产物是一个说得通的原型是拿得出手的作品）② 启动可以不好看但结果必须是真的（第一批用户不能是假流量数字）③ 集中火力（十个种子散在全国只是十个孤点压进一个科室/社群/一个时刻才可能成为爆点）④ 第一轮必须生产第二轮（一次交付要留下案例一次服务要留下推荐一次交易要留下数据关系或现金）。**微信支付红包冷启动**：发红包→抢到的钱想提现就得绑卡→红包抢完银行卡却留下来——闭环。**微信摇一摇春晚**：5303 万买独家新媒体互动资格+5 亿现金红包池。**后发优势（林毅夫）vs 后发劣势（杨小凯）**：人家先发冷启动=解决各种难题中学到制度/投资环境/原创精神——你跟在后面抄作业固然成本低可是没有独自解决过那些难题。**失去负反馈失去很多；失去正反馈失去一切**——**你需要"活"而不只是"活着"**。

## 概念 11 — 自组织临界（Self-Organized Criticality, Bak/Tang/Wiesenfeld 1987）+ 沙堆模型

> 来源：102_自组织临界 + 101_反馈回路 + 095_基线漂移 + 105_适应性循环 + 103_边际分析
> **Bak+Tang+Wiesenfeld 1987**：沙堆加沙实验——慢慢加沙 + 突然塌方。**分支比 = 系统的带动能力**（每个听到谣言的人平均传给几个人）。**亚临界（<1）**：呆板/很稳定可也很迟钝。**超临界（>1）**：一惊一乍/风吹草动就失控。**临界（=1）**：说出去一句话可能传一步就停也可能传遍整栋楼事先谁也说不准——**事件大小服从幂律（重尾）分布小的极多大的少偶尔还有黑天鹅**。**临界三性质**：① **信息传得远**（一个信号能跑到很远却不会把整个系统点着——相关长度大）② **波动能长出结构**（创新常常以雪崩方式生成）③ **特别敏感**（再微弱信号也能接住放大但代价是恢复得慢一个扰动进来荡很久）。**临界脑假说（critical brain hypothesis）**：大脑的高效工作状态就是临界附近状态——Beggs+Plenz 2003 神经雪崩。**心流 = 临界状态**——警觉性高注意力聚在一个问题上又不时冒出旁枝联想觉得这个复杂的东西我拿捏得住而不是被信息推着走。**沙堆模型三心法**：① **慢慢加载快快释放**（工作学习家庭社会关系劳累如小沙子一点点积累；释放要像沙堆塌方一样快——"张而不弛文武弗能也；弛而不张文武弗为也；一张一弛文武之道也"）② **留下释放的出口**（睡眠休息/果断放弃没指望的项目/删掉没用的信息/承认失败/给日程表留白/让憋着的情绪能说出来）③ **用几条局部规则代替宏大的自我管理**（同一个问题出现三次就停下来系统地解决掉；一个项目连着两轮没进展就重新评估）。**地震空区（seismic gap）= 高压亚临界**：小震不来不是应力消失了是它被死死锁住——憋出一场大的。**死水无波烈焰狂，偏于崖畔觅风光——小塌频频春不老，一张一弛是家常**——**你是有点累但你的反应非常敏锐你感到兴奋你动作很快你充满了动力你发得出去也收得回来你借到了混乱的力量却没有把自己交给混乱——那是恰到好处的活泼**。

## 概念 12 — 边际分析 + S 曲线 + 第二曲线

> 来源：103_边际分析 + 060_商业杠杆 + 062_效果推理 + 067_平台 + 010_复利
> **边际分析 = 看下一个单位的投入能带来多少新增的产出**——不看体量看变化率。**边际效益 = 边际收益 - 边际成本**。**工人案例**：第 1 个工人独自看机器；第 5 个工人可以分工；第 10 个工人流水线真正转起来——边际产量递增；第 20 个工人涨得就有点少；第 40 个工人新增产量已经是零。**四种局面**：① 边际效益为正且递增（最好的日子一定要加大投入——你每多投一块钱都会带来更多的钱）② 边际效益为正但在递减（这件事仍然值得做可是赚的越来越少前途有限）③ 边际效益暂时为负但趋势改善（冷启动值得投将来早晚赚钱）④ 边际效益为负且越来越负（赔钱无底洞赶紧退出）。**平台 = 边际效益递增的结构**：网络效应+数据飞轮——用户越多平台对每个用户就越有用。**S 曲线**：冷启动（投入很大动静很小）→ 边际递增一飞冲天 → 边际递减变平。**第二曲线（Handy 1994）**：要想突破旧曲线天花板就得在第一条到顶之前再画出一条新的 S 曲线——苹果在 iPod 仍然热卖时发布 iPhone。**摩尔定律 1971→2024**：2300 个晶体管 → 2080 亿个晶体管，50 多年增加约 9000 万倍。**AI 缩放定律（Scaling Law, Kaplan 2020）**：参数/数据/训练算力增加 → 交叉熵损失持续减少 → 模型越来越聪明——**缩放定律至今有效每段时间有人猜停了但仍有效**——AI 换棒：预训练规模 → 预训练+训练数据配比 → 后训练/RL/推理时计算（o1/DeepSeek-R1）。**世间不存在"一招鲜吃遍天"还能让你一直吃的好事儿**。**中国基建投资边际回报递减**：白重恩+张琼 2014 估算资本回报率 2008 后明显下行（第一条高速公路vs大城市间高速公路网已建成）。**中国居民消费占 GDP 40.0% vs OECD 平均 60.1%（2024）**——**居民消费现在有很大的边际效益**。**"小满胜万全"的浅陋**：理解边际分析立即能看出见识浅陋——真正解法不是拒绝大满而是在大满之前开启第二曲线——**自强不息和"亢龙有悔"并不矛盾**。

## 概念 13 — 路径创造（Garud & Karnøe 2001）+ 心脏搭桥手术 + 改革开放

> 来源：104_路径创造 + 061_机会窗口 + 103_边际分析 + 098_对称性破缺 + 075_保护费
> **路径创造 = 破解路径依赖的唯一可行方法**。**Garud & Karnøe 2001《路径依赖与创造》**：人不是历史囚徒——身在旧结构中的行动者可进行**有意识的偏离（mindful deviation）**——一边借用旧系统资源一边偏离旧系统逻辑拉上同伙反复试验给新事物争取长大时间。**多边锁死**：财务部说我们想换可采购单据全在旧系统里；采购部说我们倒是想换可几百家供应商都按旧系统格式对接；IT 部说新系统我们早就选好了可业务部门不敢停机切换——**没有一个人拥护旧路径可这是一个多边局面你没有办法协调所有人一起换——坏事的长期存在甚至不是因为坏人这才叫积重难返**。**新员工入职/新项目立项/新预算/新客户签约——只要新流量每天还在流进旧路径你们就必须一天比一天更加依赖它**。**三动作**：① **造路**（不招惹旧路径先默默造一条新路——新路径必须是一个完整的小系统而不是旧系统上的一个补丁这样它才能独立发展壮大——让新路跟旧路共存一段时间=保留退路+学习+知道承重墙在哪儿）② **导流**（争夺的不是旧资源而是新增资源的去向——老人老办法新人新办法/老客户继续用旧产品但新客户全部进新平台/旧数据留在旧库新数据一律写新库——存量可以慢慢消化但不允许旧制度继续繁殖）③ **退役**（先冻结新功能→停止进新人→降为只维护→降为只读→正式关闭——心脏搭桥手术/侧支循环）。**成功案例**：① **宋朝杯酒释兵权 + 科举**（太祖用富贵赎买老将既得利益→宋太宗扩大科举录取每榜几百人立刻授官→天下最有野心的人弃军从文→几十年后统治精英整个换血→五代尚"兵强马壮"被"东华门外以状元唱出者乃好儿"取代——读书人能对国家有啥威胁呢？）② **1660 皇家学会**（实验爱好者在伦敦自建俱乐部建立实验规范出版期刊吸引欧洲最好头脑把成果投给它而不是大学）③ **1956 集装箱麦克莱恩**（另建完全按集装箱设计的新泽西码头——旧码头没有输掉一场谈判也没有被谁强行关闭——它只是眼看着船越来越少自己失去了存在的理由）④ **中国改革开放** = 教科书级的路径改造（人民公社/统购统销/粮票/计划价格没有一个是被正面攻克的——它们后来确实都废除了但每一个都是废在自己已经被抽空之后——**深圳特区+大包干"交够国家的留足集体的剩下都是自己的"+乡镇企业纯粹计划外长出来+价格双轨制1988 闯关失败退回增量渐进**——**邓"不争论是我的一个发明"**——**路径创造的智慧 = 不跟存量死磕让增量长大**）。**"借君高处一枝栖，垂足成根自饮溪"**——**你不必推倒任何东西只要你掌握了新增量时间就会从路径依赖的帮凶变成你最耐心的拆迁队**。

## 概念 14 — 适应性循环（Adaptive Cycle, Holling 1986）+ 韧性 vs 稳定

> 来源：105_适应性循环 + 102_自组织临界 + 095_基线漂移 + 104_路径创造 + 098_对称性破缺
> **Holling 1986 适应性循环**：四阶段 r（开拓）→ K（守成）→ Ω（释放）→ α（重组）。**成住坏空**。**开拓（r, genesis）**：新东西冒出来抢占空间野蛮生长。**守成（K）**：资本积累规则成型效率登顶一切都稳定。**释放（Ω）**：旧结构崩解积累了一辈子的东西被打散。**重组（α, reorganization）**：不是空无一物的那个空而是旧格局散尽新格局未定的空档——下一个"成"到来之前孕育着的停顿。**印度大木秀吉**："城は残念で思ひ出も哉：松は枯れてもに残りけり"（松虽枯犹残）——火把旧松烧了空档里却又能长出新的松来。**守成期最危险**：不是停止优化而是再也停不下优化——**每一次局部优化共同造成的——系统不是谁做错了是每次优化共同造成的**——**过拟合病**：把过去考卷背得滚瓜烂熟考试次次满分可一旦题型变就傻。**盛唐玄宗 → 安史之乱 755 → 760 户籍 -80%**（事件只是扳机——几十年积累的僵化结构决定了崩溃为什么这么严重）。**稳定 ≠ 韧性**：稳定=不崩溃是保持现状哪怕被推开一点点还能迅速回到原位——不倒翁。**韧性=遭到猛烈冲击+发生重组——只要重组后仍保有基本功能/结构/身份/反馈就仍有韧性**。**湖从清水态翻进藻类主导浑水态**（局部状态看似稳定韧性已经很低）。**资本市场**：经历一次次崩盘指数可以暴跌机构可以倒闭规则可以重写——可一次次重组后还是那个市场——**不强行追求稳定但是保住了自己的身份和核心功能**——这就叫韧性。**多尺度嵌套（Panarchy）**：大循环里嵌套小循环——**反叛（revolt）**：小尺度崩坏向上级联冲破大尺度稳定（火星→林火灾/金融机构挤兑——黄炎培"忽"的一半答案）；**记忆（remember）**：大尺度为小循环重生留住老底。**反者道之动**：循环不可避免与其追求长期稳定不如追求更多的韧性——**给系统埋下一点冗余一点余地一点烧不掉的种子好让下一轮的"成"有地方生根**——**参天不觉朽其根，一炬还山化作尘。世上从无长住相，灰中已孕来春痕**。# 系列专栏·段 F part 4：107–111（零阶道理+目标函数+二阶意愿+副产品+自我约束）

## 概念 15 — 零阶道理（First-Order Truth）+ 微扰理论 + 大局观

> 来源：107_零阶道理 + 108_目标函数 + 109_二阶意愿 + 057_经济租 + 119_探索生发
> **微扰理论（perturbation theory）**：面对复杂问题先算一个粗糙但抓住主干的零阶近似——然后加上一阶修正二阶修正逐级把精度提上去。**零阶道理 = 主导一个事物一个决策的最基本最重要的道理**——**因为它太基本人们反而不愿意谈论而喜欢谈论对它的修正**——**高阶项是小量，小量可以修正零阶项但没有资格取代零阶项**。**例子**：球星对球队很有用（零阶）→ 但球星来了不都是好事儿可能引发矛盾（次要）；现代化是好的（零阶）→ 但现代化有坏处破坏温情（次要）。**主导平衡（dominant balance）**：面对包含许多项的方程先问哪几项占主导把其余的暂时扔掉。**毛泽东《矛盾论》**：研究任何复杂过程"就要用全力找出它的主要矛盾"。**邓小平 1992 南方谈话**："稳定和协调也是相对的不是绝对的。**发展才是硬道理**"——**零阶道理是在给定目标/时间尺度/比较对象之下足以决定结论方向和主要量级的最小因果模型**——三关键词：方向/量级/最小。**大局观不是宏大与微小而是控制力与装饰性**——**大局观是对信息做有损压缩**——**忽略大部分内容只要求保住三样东西：方向、量级和机制**——**你必须允许自己在不重要的地方不精确**。**诸葛亮"观其大略"vs"务于精熟"**（务于精熟=给每一句话平等的票；观其大略=给书里的道理分配表决权）。**可评估性假说（Hsee 1996）**：一个因素越容易评价人们在决策中给它的权重就越大哪怕它并不重要——A 词典词条多封面破 vs B 词典词条少完好——单看 B 估价高一起看 A 出价更高。**聚焦错觉（Kahneman）**："生活中没有什么事像你正在想着它的时候显得那么重要"——细节会让人显得专业正如讲高阶道理让人显得聪明。**翻盘检验**：问"还有什么足以扭转我的结论"——"先问权重再问真假"=权衡——孟子"嫂溺不援是豺狼也男女授受不亲礼也嫂溺援之以手者权也"——**权也是权力的权各方面都有用钱的理由每个人有优点每个项目说做它最符合原则这点资源给谁好——把权力给你就是让你去权衡**。**周其仁**："宏观政策/特朗普那些事情你说了也不听你的你手里的事情听你的"——**你不妨试试把刷屏时间减掉一大半看看究竟错过什么大事**。**大局观的一半是知道该看什么另一半是知道什么时候不再看**。

## 概念 16 — 目标函数（Objective Function）+ 工具理性 vs 价值理性 + 休谟断头台

> 来源：108_目标函数 + 026_无免费午餐 + 002_重尾 + 010_复利 + 119_探索生发
> **地球 Online 没有奖励函数也没有排行榜**。**工具理性（Zweckrationalität, Weber）**：告诉你用什么手段最有效地达成既定目标。**价值理性（Wertrationalität）**：问什么目标值得追求。**休谟断头台（Hume's guillotine, 1740《人性论》）**：只靠"实然（is）"推不出"应然（ought）"——事实只能告诉你各种选择会带来什么后果要推出"应该"你还必须补进一个价值前提。**正交性论题（Bostrom 2012）**：智能水平和最终目标是两根互相垂直彼此不决定的轴——**任何智力都可以配上任何目标**——**回形针问题**：能力无穷的超级智能可以一心一意按你的命令去最大化地制作回形针。**工具性收敛（instrumental convergence）**：每个人选择的最终目标可以千奇百怪但几乎所有行动者都会用同一批中间手段——**保住自己/保住目标不被改写/增强能力/获取资源**——"想活下去"不是一个奖励也不是价值观而是一个约束。**没有奖励函数但给了约束**：物理规律/可行边界/生物淘汰机制——**天地不仁以万物为刍狗不颁奖但会清场**。**宇宙是麦田+到处都是悬崖+能落脚的地方已经很窄**——你只能沿着剩下的一条条狭窄的土地走——明明是"只能"可是因为剩下的就好像路一样你感觉你就"应该"——**一个只会删除的机制运行了四十亿年后从统计上看很像一个奖励函数**。**演化的仪表盘**：糖甜/性愉快/被接纳舒服/被排斥难受——演化把外面那些悬崖翻译成了你身体里的疼痛/欲望/依恋。**美德 = 对硬约束的适应**——**节制/审慎/勤勉/耐心/守信/公平/互惠/勇敢/忠诚——这些不是宇宙发奖而是演化在你身上装的仪表盘**。**时间视界 → 意义感**：想活下去→繁衍→合作→拉长时间视界→延迟满足/复利/手艺积累/声誉经营→责任/勇敢/照料弱者。**幸福 vs 意义**：幸福是当下/索取/需求被满足；意义是跨时间/给予/连接过去与未来。**心流/好奇心被满足 = 快乐**——宇宙没有把最珍贵的东西都做成奖品——**你最好选那些即使副产品没有来无人喝彩也值得做的事**。

## 概念 17 — 二阶意愿 + 元表征（Frankfurt 1971 / Pylyshyn 1978）

> 来源：109_二阶意愿 + 019_身份认同 + 110_副产品 + 111_自我约束 + 007_内核
> **Frankfurt 1971** 三层：① **一阶欲望**（我想做什么——想抽烟想刷手机想锻炼想写作）② **二阶欲望**（我希望自己拥有什么欲望——我希望自己更喜欢运动而不是只喜欢躺着=对欲望的欲望）③ **二阶意愿**（我让哪个欲望真正支配我的行动=授权动作）。**三层自由**：① **行动自由**（门锁着没/兜里有没有钱/别人允不允许——囚犯想出门不能出门）② **意志自由**（我认不认同正在驱使我的这个欲望——想赌的人自由走进赌场心里却痛恨那个想赌的自己=有行动自由没有意志自由——现代人的苦恼多数不在第一层而在第二层：想做的事都可以做可总在做完之后后悔）③ **自我塑造自由**（决定未来的我长出什么样的欲望=给自己挑选训练环境——今天的我挡不住"想刷手机"但今天的你可以决定一年以后冒出来的念头长什么样）。**察觉/重编/布置** = AI 训练自己下一代——把欲望从主语变成宾语。**元表征（metarepresentation, Pylyshyn 1978）** = 对表征关系本身的表征——**比元认知更彻底**——**给思想加引号**——"我必须把这件事做好"加上引号从现实降级成了一种说法——把眼镜摘下来拿在手里看。**开放式递归性（Proust）**：一个表征可以被另一个表征包裹——行动层（去不去健身）→ 目标层（要不要减脂）→ 问题层（要不要减脂真的是主要问题吗）→ 叙事层（我为什么把自己讲成"必须保持好身材的人"）→ 身份层（为什么必须继续维持这个版本的自己）→ 价值层（凭什么认为外形比知识关系和创造更值得投入）——**每跳出一层你就自由一分上一层的题现在可以答也可以不答了**。**Kegan 主体-客体转化（Subject-Object Shift）**：婴儿被冲动支配/孩子把冲动拿在手里学会了等待/少年被别人的眼光支配/成年人把别人的眼光拿在手里学会了取舍——**人的每一次成熟都是一次主体-客体转化**。**宇宙的第一性原理是叙事自由的第一性原理是跳出叙事**。**Gary Watson 1975 反例**：分层递归本身也只是一种叙事——**只要还有一个"我"在跳楼上就永远还有楼**。**大脑是多元政体：每时每刻你眼前都有好几个念头在竞争你只是选了其中一个——"中央"的利益并不无限高于"地方"——你再想减肥偶尔遇到大喜事儿也应该吃顿好的**。**《金刚经》"应无所住而生其心"**：佛陀反对的不是你有念头是你把念头当成了你——念头照样起事照样做承诺照样给。

## 概念 24 — 预训练 + 后训练 + 学习工程化

> 来源：117_预训练后训练 + 114_立题 + 099_临近可能 + 051_默会知识 + 090_古德哈特
> **预训练（pre-training）= 读万卷书**：把语料喂给它预测下一个词——重复几万亿次——预测逼出理解——**预训练厉害后训练不足的模型 = 刚学会六脉神剑的段誉要天资有天资要神功有神功只是发挥不稳定**。**涌现（emergence）** + **开悟（grokking, OpenAI 2022）**：模型规模和语料到某个量级一些没人教过的能力突然自己冒出来 / 反复死记硬背忽然某一刻把规律推广到从没见过的题上——"读书百遍其义自见"。**Chinchilla 2022 DeepMind**：语料比参数更重要——读书不够光脑袋大没用。**后训练三步**：① **监督微调（SFT）**——给它看几万条精心写好的标准问答让它模仿（师傅带徒弟"我做一遍你跟着学一遍"——教格式和品位）② **RLHF 人类反馈强化学习**——让它生成几个回答人类评委挑出最喜欢的把"被人喜欢"做成奖励信号（社会化学礼貌学分寸学揣摩评委——**2023 Anthropic：AI 助手有谄媚倾向**——**对齐税**：模型为了对齐人类偏好某些硬能力会下降）③ **RLVR 可验证奖励强化学习**——编程/数学/下棋结果能自动验证不问人喜不喜欢只问对不对（答对加分答错扣分海量刷题跟世界过招）。**pass@k vs pass@1**（潜力 vs 发挥）。**表面对齐假说（Superficial Alignment Hypothesis）**：真本事是预训练里来的后训练管的只是表现。**黄高团队 2025**：强化学习提升稳定性而非能力上限——**为了稳模型老在那几条得分的路上走减少了探索以至于有些原本有可能做对的题反而做不出来**。**LIMA**：1000 条精选示范调 650 亿参数基座——预训练决定上限后训练决定下限。**预训练厉害后训练不足 = 段誉**（偶尔能成为谁）；**预训练一般后训练做足 = 乔峰**（降龙十八掌统共十八招招招明牌每一掌都打得实打得准次次都在）。**学习思维工具 = 给自己做后训练**：不是让你更聪明而是让你已有的聪明稳定发挥——**工具不是经验的替代品工具是经验的压缩算法**——"说着什么凯利公式选择偏差前景理论头头是道可一旦涉及自己的利益地位和作品这些工具一个都没被调用"——他不是不会他是 pass@100 会 pass@1 不会。**2019 行为科学家 290 名研究生**：受过确认偏误训练→遇到航天飞机案例→**选中劣质方案概率低了 19 个百分点**——19% 不是脱胎换骨但思维工具可通过训练取得行为控制权——**换了场景没人提醒工具自己启动了**。**学习是工程问题**：语料质量/反馈来源/演练强度/奖励机制设计——"高喊什么'我要成长''我要精进''我今年要读 50 本书'没有任何意义。一切必须落实到预训练和后训练"——**预训练看输入；后训练看反馈和演练；奖励信号的作用不是提供情绪价值而是改写权重**——拿点赞掌声领导的夸奖做奖励你练出来的是迎合评委的谄媚倾向；拿作品结果和真实世界的硬反馈做奖励你才会既提高下限又不断得到推高上限的新语料。**预训练决定你偶尔能成为谁，后训练决定你通常是谁**——**参数是天资语料是平生偶得为侥幸屡验乃功成考场无再试岁月改权衡此身无定版长存训练中**。

## 概念 25 — 探索与生发（完）+ 组装理论 + 功能信息递增定律 + 课程完结

> 来源：119_探索生发 + 108_目标函数 + 097_生成 + 117_预训练后训练 + 002_重尾
> **硬约束 = 道德和伦理**——**没有奖励函数 = 不设边界让世界多姿多彩**。**计算不可约性（computational irreducibility, Wolfram）**：足够复杂系统不存在预测捷径——想知道第一万步是什么样你只能老老实实让它跑到第一万步——**哪怕造物主也得追更**——**这是一个好消息**——**正因为算不出来"发生"本身才有价值**——**如果没有造物主我认为"好奇心"是宇宙的一个特别重要的意义**。**沃尔夫勒姆"可约的口袋（pockets of computational reducibility）"**：无穷多个——**科学发现是可能的；科学发现这门业务是无穷尽的**——你总可以发现这个世界新的规律而且永远都发现不完——**探索和生发的事业永远存在永远有价值**——**宇宙不光是允许生发而且它自己就在生发而且干得越来越起劲**。**组装理论（Assembly Theory, Cronin+Walker 2023《自然》）**：组装指数 = 从基本构件出发造出这个东西最少需要多少步——石英组装指数低可自发出现/胰岛素/光刻机/《红楼梦》组装指数极高——它们的存在本身就是一份因果履历——**组装指数乘以拷贝数就是一个结构在宇宙中"立住"的程度**——地球上不断地出现越来越高级的东西：自催化循环→细胞→多细胞→神经系统→语言→文字→科学→计算——**组装指数每提升一次都是让更深的结构变得可复制**。**功能信息递增定律（Law of Increasing Functional Information, Hazen+Wong 2023）**：凡是存在大量组态又持续接受功能筛选的系统其中有功能的信息就会随时间越积越多——**够格算一条跟热力学第二定律并列的自然定律**——科学原本认为生物演化没有方向因为基因突变随机但是在宏观上我们看到趋势——拟人方式说：**这个宇宙*想要*变得更有意思它想生发出新的可能性来**。**三要求**：① 新的（不是重复已有的东西）② 尊重硬约束（道德不是探索的税道德是可能性这块公地的维护成本）③ 能被其他人继承（别人能站在你这个东西上面打开更多新的可能）。**几种生发**：① 做科学做学问（发现一条规律就是给后来所有人预制一个口袋——你必须写下来发出去让它有拷贝才能产生影响）② 做艺术（真正的新作品是"人还可以这样感受"的存在性证明——李白之前没人知道诗可以那样写；有了李白中国人从此多了一种心情的活法）③ 做产品建组织（组织是可能性的二阶生成器——你不只造了一个东西而且是一台能持续造出新东西的机器）④ 养孩子教学生（最高目标不是把答案复制进另一个脑子而是多造一个答案源——孩子不是父母的续集孩子是世界新增的一个作者）⑤ 建设者和维护者（图书馆管理员/失败探险队写"此路不通"——**失败的探险队也带回了地图**）。**"因为有你世界的可能性是多了还是少了"**：收获快乐（内在动机）/ 共鸣（探索者跟探索者不是竞争关系是共鸣关系）/ 少痛苦和纠结（把不确定性变成意义的燃料——别人怕世界变你盼着世界变）/ 积累声望和资本（每进入一个新领域弱连接和结构洞那种社交资本自动就有了）/ 不怕老（"某公司某职务"是别人分配给你的位置"正在探索的人"是你随时可以重新发起的行动）。**老子"道生一，一生二，二生三，三生万物"**——**越来越多的邻近可能**；**"生而不有，为而不恃，长而不宰，是谓玄德"**——**生养而不占有成就而不挟持引领而不控制**——**老百姓说"上天有好生之德"；《易传》说"天地之大德曰生"——也许天道不是一个目标而是一个方向**——**你选择探索和生发不是在完成宇宙布置的任务——它没给谁布置任务——但你是在顺着这个方向活**。**"这门课算是我的一次探索和生发。往后你在你的领域里发现了好东西，也请喊我一声"**。
