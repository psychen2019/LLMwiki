## 主要论点与论据

### 核心论点一：人们对激励做出反应，而非对意图做出反应

**支持论据**：
- 1994 旧金山房租管制 → 房东退市、供给下降 15%、租金反升 5%
- 1973 美国《濒危物种法》→ 土地所有者主动砍伐潜在栖息地
- 2014 加州禁塑令 → 改用更厚"可重复使用"袋，填埋垃圾从 15.7 万吨涨到 23.1 万吨
- 2009 美国"旧车换现金" → 销量暂时上升，补贴停后立即回落（仅是时间提前）
- 以色列幼儿园罚款实验 → 迟到率反升；罚款取消后迟到率也未降回

**关键洞见**（原文）：
> "你所能改变的也不是结果本身，而是局面。人们会根据这个局面重新行动。"

---

### 核心论点二：政策传导路径必然变形

**链条模型**（原文）：
```
意图 → 政策 → 激励变化 + 预期变化 + 执行变形 → 人的行为再优化 → 系统反应 → 非预期结果
```

**支持论据**：
- 王安石青苗法：本意救农民于高利贷（民间利率 70%，官府提供 40%），但因还款风险被官府忽视，考核"放贷额"使地方官将指标硬摊到每户
- 2021 中国"能耗双控"：企业买柴油发电机自发电，报表达标但污染更重
- 中国医院职称论文制度（1986 起）→ 层层加码 → SCI 论文刚需 → 论文工厂泛滥

---

### 核心论点三：街头官僚理论——一线执行者才是政策的实质

引用 Lipsky：政策真正落地靠一线人员，他们有资源限制、考核压力、自由裁量与自保动机。
- 上级要政绩 → 中层压缩为指标 → 基层翻译为动作
- 公共目标层层传导后变为"组织自保目标"
- **没有一个人觉得自己在作恶**

---

### 核心论点四：道德责任不可上移——平庸之恶的警告

引用 Arendt：系统把巨大恶果拆解为无数"完全尽职"的小动作。
- 执行者将"人"语言化为"案例/指标/对象"，降低良心摩擦
- "我只是做好我的本职工作"成为道德卸责模板

**结尾锚点**（电影《V 字仇杀队》）：
> "我不是为你想做什么而来，我是为你做了什么而来。意图属于你自己，可是后果属于世界。你不是你的意图，你是你的后果。"

---

### 核心论点五：克制优先于行动

- **切斯特顿的篱笆**：不理解旧制度就别动它
- **司马光困境**（谌旭彬）：秦制下改革者必遭遇——利朝廷利官，难利民，甚至更糟
- 对策建议：
  1. 红队推演（预演变形路径）
  2. 补偿机制（先保别让好人吃亏）
  3. 小步试点 + 跟踪反馈 + 允许纠错（中国改革开放经验）
  4. 政策制定者预想执行者行为；执行者回溯真实意图

## 矛盾与张力

1. **"切斯特顿篱笆" vs "司马光困境"的张力**：切斯特顿温和地说"先理解再动"，司马光困境激进地说"秦制下动了也白动"。两者在实操层面有冲突——完全不动 = 维护旧恶；动 = 可能制造新恶。原文未给出最终裁决。
   
2. **街头官僚的"积极空间" vs "平庸之恶"**：文章一方面说基层有自由裁量和米提斯可调用，另一方面又警告基层最易陷入平庸之恶。这两者是否矛盾？文章倾向的解决方案是"看见异常→记录→反馈→留解释余地"，但并未说明激励来源（基层自己本来就在"避责激励"中）。

3. **古德哈特定律的视角差异**：古德哈特强调"被测量的即被优化"；本文扩展为"考核层层加码 → 形式主义取代实质"。两者构成递进而非矛盾，但 Wiki 若同时收录应注明层次差异。

4. **改革开放"小步试点"经验的边界**：原文高度肯定中国式试点，但未指出该经验的前提（地方有自主权、中央允许试错），在当下未必普遍适用。
