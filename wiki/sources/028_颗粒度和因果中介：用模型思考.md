# 028_颗粒度和因果中介：用模型思考

本课是万维钢《现代思维工具 100 讲》的第 28 讲，主题是用模型思考事物的两个核心要求：颗粒度恰当 + 因果关系清楚，并通过中介变量（mediator）找到真正的干预着力点。

## 核心论点

1. **模型是事物在你头脑中的一个结构镜像**——能帮你看清楚它运行的底层机制。没有模型就只能对输入信号做冲动反应；有了模型，你才知道按钮在哪儿。
2. **好模型的第一个要求**：颗粒度（Granularity）必须恰到好处。
3. **好模型的第二个要求**：其中必须包含因果关系，才能讲清楚事情的机制。
4. **任何模型都不可能穷尽所有因果关系**，多了也不好少了也不好，达到最小描述长度才好。
5. **别盯终点，盯中介**——复杂决策的关键是找到一两个最关键的中介变量进行干预。

## 关键公式与结构化数据

### 最小描述长度（MDL）准则

```
最佳模型 = argmin( 模型长度 + 数据补丁长度 )

其中：
  模型长度     = 描述模型本身所需的比特数（模型有多复杂）
  数据补丁长度 = 用此模型解释现实时，还要补充多少例外说明
```

> 最好的模型，是那个能用最短的代码长度，解释最多数据的模型。

### "生气 → 癌症"的精确因果链

```
生气 → 不良生活习惯（暴饮暴食、不运动、吸烟、酗酒）→ 癌症
       └──── 中介变量 ────┘
```

- 排除中介因素后，"生气 → 癌症"这一**直接因果链**在多项大型研究中不成立。
- NCI、ACS 均明确否认"情绪直接致癌"。
- 关键操控点：中介变量（不良生活习惯），而非情绪本身。

### Moneyball：上垒率作为关键中介

```
（击球 + 选球眼光）→ 上垒 → 得分 → 赢球
                    └─── 中介变量 ───┘
```

- 传统球探模型：球星（全垒打 + 外形）→ 赢球（颗粒度过粗，价格昂贵）
- 比恩的新模型：上垒 → 赢球（找到被忽视的中介变量，买入被低估的"能蹭上垒"球员）
- 战绩：以极低的薪资总额创下 20 连胜纪录

### 足球中的"期望威胁"（xT）

```
低威胁区域  ──(撕开防线的传球/突破)──>  高威胁区域
                                            ↓
                                     进球概率 2% → 30%
```

- "期望威胁"不是射门，也不是最后一脚助攻，而是**倒数第二脚、第三脚传球或带球突破**。
- 这种传球本质上提升了"期望威胁"（Expected Threat, xT），是足球版的"上垒"。

### 天气描述：颗粒度的三种水平

| 颗粒度 | 描述 | 评价 |
|---|---|---|
| 过拟合 | 把过去一年每天的天气都列举一遍 | 无压缩，欠理解 |
| 欠拟合 | "这地方总下雨" | 太粗，丢失关键信息 |
| 恰当颗粒度 | "温带海洋性气候，受西风带控制，全年温和湿润，阴雨多但少暴雨" | 高压缩，揭示机制 |

## 关键引文与格言

> 系统的每一个好调节器，都必须是该系统的一个模型。（好调节器定理，Conant & Ashby, 1970）

> 理解即压缩（Understanding is Compression）。

> 地图不是疆域（The map is not the territory）。

> 别盯终点，盯中介。

## 三步压缩的应用案例

### 案例 1：买手机
```
（需求：拍娃 / 拍夜景 / 游戏 / 看视频）→ 关键参数选择 → 购买决策
```
- 短模型："买最贵的 / 买便宜的"——过短，颗粒度不足
- 长模型：研究所有参数再比价——过长，容易陷入决策瘫痪

### 案例 2：孩子学习成绩差
```
（时间 + 注意力）→ 记忆编码 → 提取 → 成绩
                    └── 中介变量 ──┘
```
- 盯着"学习时间"——只看到最浅层因果
- 真正需要诊断哪个中介环节出问题：投入？编码？提取？

### 案例 3：公司管理
```
团队协作 / 信息流 / 决策效率 → 留存 / 转化率 / 渠道质量 / 产品体验 → 收入
   └── 中介层 ──┘                  └── 中介层 ──┘
```
- 只盯收入 → 过度依赖短期促销（欠拟合）
- 盯所有中介每天做日报 → 无所适从（过拟合）
- MDL 要求找到一两个最关键中介进行干预

## 反例：宿管员模型

```
无模型（听见噪音就喊）：    噪音 → 反应（无能狂怒）
有模型（知道是低音炮/游戏/水泵）：噪音类型 → 精准干预（305/117/二楼水泵）
```

## 与现有知识网络的连接

- **与 [[concepts/因果范式]]**：本文进一步把因果链拆解为"中介变量 → 终点"，与"效应化"思维（手段驱动而非目标驱动）方法论一致。
- **与 [[concepts/注意力经济]]**：颗粒度的本质是注意力配置问题——选择最值得关注的少数中介变量。
- **与 [[concepts/叙事]]**：叙事可以视为一种高度压缩的因果模型，"理解即压缩"的能力支撑叙事建构。
- **与 [[concepts/稳态生存逻辑]]**：本文强调通过建模与中介干预来主动控制事物，与稳态生存逻辑的张力在于——能动必须建立在正确的因果模型之上，而非凭本能反应。
- **与 [[concepts/赛道选择]]**：Moneyball 的成功本质上是"找到被忽视的关键中介变量"，与赛道选择中的"找到被低估的游戏结构"在方法论上同构。

## 局限与提醒

1. **没有绝对标准的颗粒度**——到底模型要细致到什么程度，由主观需求决定。
2. **地图不是疆域**——任何模型都是对真实世界的简化与压缩，都有危险。
3. **MDL 是计算准则但不是绝对标准**——文章承认"没有绝对标准"，削弱了 MDL 的客观性。
4. **生气 → 癌症这一论断的边界**：本文论断仅限于"情绪不会直接导致癌症"，不可迁移为"压力对健康无害"。
