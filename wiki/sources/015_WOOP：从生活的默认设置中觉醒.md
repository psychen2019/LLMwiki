# 015 WOOP：从生活的默认设置中觉醒

## 课程基本信息

- **讲次**：015
- **课程名**：现代精英的思维工具100讲（万维钢）
- **知识类型**：思维工具
- **原始文件**：015_WOOP：从生活的默认设置中觉醒.md
- **核心议题**：WOOP（Wish-Outcome-Obstacle-Plan）四步心智策略，以及"漂流"这种默认生存状态

## 主要内容摘要

本讲先以拿破仑·希尔《智胜恶魔》中魔鬼的访谈为引子，提出"漂流（Drifting）"是 98% 人类生活的默认设定：没有明确目标或缺乏精确计划，让环境、运气和身边的人替自己决定。然后用奥地利与德国器官捐献同意率的对照，说明现代社会通过"默认选项（Default Options）"大规模制造漂流。

承接第 003 讲《能动》对"稳态生存"的批判，本讲主张行动力问题本质上是精确性问题（引埃隆·马斯克语），并提出 WOOP 作为精确化的实施工具。

WOOP 由心理学家加布里埃尔·厄廷根推广，由四个步骤组成：

1. **Wish（愿望）**：明确想达成的目标
2. **Outcome（结果）**：目标达成时的好结果，具体到画面与感受
3. **Obstacle（障碍）**：阻碍愿望达成的**内心障碍**（不是外部环境，是自己的反应模式）
4. **Plan（计划）**：障碍出现时执行的可触发动作，格式为「如果（If）……那么（Then）……」

WOOP 整合两个心理学武器：

- **心理比对（Mental Contrasting）** —— 厄廷根提出：先想象理想 Outcome，再立刻拉回到现实 Obstacle，制造认知张力。若不可行，则体面退出；可行则提升承诺与能量。
- **执行意图（Implementation Intentions）** —— 彼得·戈尔维策（厄廷根的丈夫）提出：「如果……那么……」格式的情境-动作绑定计划，将决策从现场移到事前。

文中提到的证据基础：

- 低收入社区中学生成绩、出勤与日常行为的改善
- 中年女性身体活动水平的提升
- 住院医师随机对照实验：WOOP 组朝目标学习投入时间显著多于"仅设定目标"组
- 痴呆症照护者随机对照研究：压力水平显著降低、生活质量提高、抑郁指标改善

日常应用案例（控制消费、职场表现）展示 WOOP 把"恐惧"重编码为"行动触发器"。

最后用蔡加尼克效应（Zeigarnik Effect）与注意力残留（Attention Residue）解释"漂流者的心累"——未完成且未计划的任务持续占用工作记忆；而 WOOP 通过 If-Then 把任务从工作记忆卸载，让人进入"心如止水"状态。

## 课程金句

- 魔鬼说：我不需要复杂的阴谋，我只需要让人保持"漂流"。
- 所有的行动力问题，其实都来源于精确性的不足。—— 埃隆·马斯克
- 自律不如习惯，习惯出自系统。
- 漂流者的生活逻辑是：情境来了 → 我随便反应。WOOP 的生活逻辑是：情境来了 → 我执行预案。
- WOOP 不要求你立即变成一个不一样的人，它只要求你在那一秒钟别漂流。
- 大脑是用来思考的，不是用来惦记事儿的。
