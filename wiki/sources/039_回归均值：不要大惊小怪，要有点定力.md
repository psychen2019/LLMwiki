# 039 回归均值：不要大惊小怪，要有点定力

## 课程元信息

- **所属系列**：万维钢·现代思维工具100讲
- **讲次**：039
- **核心主题**：思维工具 / 统计陷阱
- **配套课程**：027 概率分布、030 贝叶斯先验、031 信息价值、032 凯利公式、033 非遍历性、034 脆弱和反脆弱、037 状态杠杆、038 选择偏差、052 可取的困难、108 目标函数

## 核心论点

1. **极端表现后必然回归均值**：特别好或特别坏的表现包含"真实水平 + 随机运气"，极端运气不可持续，因此下一次观测自然向均值靠拢，这是统计学的必然，不是管理学的因果。
2. **人类大脑偏好归因**：人很难理解回归均值，常犯两种错误——错把波动当因果、错把运气当实力，统称"回归谬误"。
3. **管理学是回归谬误重灾区**：换教练、新官上任三把火、"不让一个孩子掉队"等干预看似立竿见影，往往只是回归均值带来的错觉。
4. **漏斗实验的四种规则**：什么都不做（规则一）方差最小；基于上次偏差反向补偿（规则二）方差扩大一倍；基于靶心反向补偿（规则三）系统振荡加剧；上一颗落点即下一颗起点（规则四）无标准靠感觉越走越偏。
5. **邓宁-克鲁格效应部分由回归均值解释**：自我评价趋近平时均值，与现场发挥错位，自动制造"低分者高估自己、高分者低估自己"的假象。
6. **判断真趋势靠贝叶斯逐步更新**：单点极端值无简单办法，需看更多更全的数据，逐步更新先验。

## 四个自检问题（判断"真趋势还是随机波动"）

1. 我是不是因为一个极端值才开始注意这件事？
2. 我看到的是一个点，还是多期数据？
3. 如果我什么都不做，它会不会自己缓回来一点？
4. 系统的生成机制有没有真的改变？

## 关键引文

- **数学形式**：`观测结果 = 事物的真实水平 + 随机运气`
- **老子式收束**："飘风不终朝，骤雨不终日。极端不是常态，有见识的人不会事事都管。"
- **核心教训**："这一讲最重要的教训是决策定力。"

## 漏斗实验四种规则

| 规则 | 描述 | 管理隐喻 | 方差表现 |
|------|------|----------|----------|
| 规则一 | 什么都不动 | 定力管理：先把系统调好，不追每个点 | 方差最小（最优） |
| 规则二 | 基于上次偏差反向补偿 | 跟着结果跑：顾客嫌咸就少放盐 | 方差扩大一倍 |
| 规则三 | 基于靶心反向补偿 | 运动式治理：管得不够严就打价格战 | 系统振荡加剧 |
| 规则四 | 漏斗挪到上一颗落点 | 没标准靠感觉：师傅带徒弟口耳相传 | 越走越偏 |
