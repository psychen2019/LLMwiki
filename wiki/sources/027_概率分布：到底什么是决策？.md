# 027 概率分布：到底什么是决策？

本讲是万维钢《现代思维工具100讲》的第 027 讲，承接第 026 讲[[sources/026_无免费午餐定理|无免费午餐定理]]，主张"决策"这一行为的真正对象不是单次结果，而是一个[[概念/概率分布|概率分布]]。课程围绕决策科学、结果偏误、风险管理、长期系统等主题展开。

## 主要内容

### 引子：赤马红羊劫的统计验证

民间谶纬认为逢"赤马红羊"两年必有大乱。GPT 在过去两千年间采得 34 组赤马红羊年，其中 13 组（38%）落在主流教科书所列的重大动荡期（如八王之乱、安史之乱、靖康之耻等）。但从同跨度内随机抽取 34 组连续两年做对照，落在重大动荡期的比例约为 37%——两者无显著差异，说明所谓"赤马红羊劫"不具备统计显著性。

这番 GPT 采样验证是入门级决策者思维：评估决策不能只看单次结果，必须看统计。

### 决策的对立面：结果偏误（Resulting）

- [[概念/结果偏误|结果偏误（Outcome Bias）]]是心理学通用术语；前职业扑克冠军[[实体/安妮·杜克|安妮·杜克（Annie Duke）]]在其著作《对赌》（*Thinking in Bets*）中称之为 **Resulting（结果论）**。
- 杜克主张"生活更像扑克而不是国际象棋"：单次结果由牌运决定，策略好坏必须由多次样本的统计来评估。
- 老百姓因为缺乏算力和长期记忆，倾向于以眼前可见的结果评价策略，造成"爱瞎搞赶上大环境好的老板被封神"、"严谨推演却遇偶然惨败的人被牺牲"等荒谬局面。

### 决策是放弃，是剪枝平行宇宙

- "Decision" 词根来自拉丁语 *decidere*（切断/杀掉）。
- 决策不是挑选"正确答案"，而是杀掉同样诱人甚至更优的选项，押注在一个并不确定的选项上——本质是暴力剪枝。
- 由此引出[[概念/机会成本|机会成本]]视角：每做一个选择，都放弃了若干平行宇宙的可能性。

### 概率分布的六个参数

评估一项决策，至少需要考察以下六个参数：

| 参数 | 含义 |
|------|------|
| 均值（数学期望） | 平均而言能赢多少 |
| 方差 | 局面波动性大不大 |
| 上限 / 下限 | 最好与最坏的可能结果 |
| 偏度 | 赢的概率大还是输的概率大 |
| 峰度 | 是否为[[概念/重尾分布|重尾分布]]，极端事件概率 |
| 稳健性（Robustness） | 环境变化时系统是否崩溃 |

### "先为不可胜"的三角验证

- 孙子：「昔之善战者，先为不可胜，以待敌之可胜。不可胜在己，可胜在敌。」
- [[实体/查理·芒格|查理·芒格（Charlie Munger）]]：「我只想知道我会死在哪里，这样我就永远不去那个地方。」
- [[entities/纳西姆·塔勒布|纳西姆·塔勒布（Nassim Nicholas Taleb）]]：「永远不要因为一条河"平均"只有四英尺深，就涉水而过。」
- [[entities/乔治·索罗斯|乔治·索罗斯（George Soros）]]：「你看对还是看错并不重要，重要的是你看对时赚了多少，看错时亏了多少。」

四者合起来构成风险管理共识：先确保能接受最坏结果，再看最好结果值不值得付出；管理[[概念/尾部风险管理|尾部风险]]与对错之间的不对称性。

### 善战者无赫赫之功

理想情况下，高手应尽量避免频繁进入高方差赌局，多用低波动、可重复的过程积累胜利。决策气质好的人不计一城一池之得失：过程对了，输一两次无所谓；过程错了，赢了也只是侥幸。

### 系统优于目标

[[实体/斯科特·亚当斯|斯科特·亚当斯（Scott Adams）]]提出：长期做事不应追求具体目标，而应追求**系统**。系统是连续变化的事物（技能、关系），可以从中生长出多个项目；最该关心的是系统本身是否在发展壮大，而非单个项目的成败。

例如亚当斯的写作就是一个系统：下一篇在哪发表、赚多少钱都不重要，重要的是输出概率分布是否越来越好。

### 三个演练

1. **肿瘤治疗**：保守治疗分布窄、可再活 5 年但质量中等；手术呈双峰分布（30% 立刻离世 vs 70% 彻底治愈）。80 岁选保守、20 岁选手术——看年龄如何改变最优分布。
2. **两份工作 offer**：大厂高薪稳薪但左尾风险（技能单一化）；创业公司低薪但右尾暴富机会。背房贷选大厂、一人吃饱选创业——看个人风险承受能力。
3. **保险**：保险公司赚钱意味着保费数学期望高于赔付期望。但仍建议购买房屋保险、大病医疗险，因为单次损失是否承担得起，才是真问题。

### 高水平决策者气质：斯多葛射箭手

- 不因一次侥幸胜利而狂喜，也不因一次正确策略的偶然失败而崩溃。
- 拥抱[[概念/不确定性|不确定性]]，但对毁灭性尾部风险避之唯恐不及。
- 极度重视制度和规则——制度是保证概率分布稳健的唯一工具，人治充满随机性。
- 相信程序正义是长期最优解，情绪稳定。

收尾比喻：**斯多葛射箭手**——尽全力拉弓、瞄准（你能控制的过程），对箭离弦后的命中保持冷静的漠然（那是风向与噪声的抽样）。

## 关键术语表

- 概率分布、期望值、方差、上下限、偏度、峰度、稳健性
- 结果偏误（Outcome Bias）、Resulting
- 机会成本、平行宇宙剪枝
- 善战者无赫赫之功
- 系统优于目标
- 程序正义、大数定律

## 课程摘要（来源原文）

1. 决策，决的不是单次结果，而是一个「概率分布」。
2. 你真正能决定的其实是一个过程，而不是结果。或者更严格地说，你决定的其实是*放弃*哪些东西。
3. 考虑一个决策，我们至少需要考虑以下这几个参数：均值（数学期望）；方差：上限和下限；偏度；峰度；稳健性。
