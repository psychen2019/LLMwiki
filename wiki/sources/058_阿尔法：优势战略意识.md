## 主要论点与发现

### 核心命题
1. **Beta ≠ Alpha**：Beta 是搭市场顺风车的被动回报，Alpha 是"超出市场共识、靠更高一层的认知、判断和动作"硬生生多拿到的部分。
2. **市场永远不均衡**：哈耶克 → 柯兹纳一脉奥地利学派论证，市场充满错配，企业家的功能是发现并纠正错配，赚钱本身因此是正当且高尚的。
3. **运营效益 ≠ 战略**：迈克尔·波特 1996 年《What Is Strategy?》核心区分。运营效益可被模仿，战略定位不能。
4. **战略的本质是取舍**：不取舍就无战略；取舍的痛正是模仿壁垒的来源。
5. **Alpha → 经济租的五步路径**：错配 → 认知 → 执行 → 占有 → 重构。第二步（凭什么是你）是关键。

### 支撑证据

**反面教材（守住 Beta 而衰败）**：
- 柯达：早发明数码相机却把资源继续投在胶卷降本增效上
- Kmart + Sears：试图通过合并削减管理费用，无新体验/无新技术 → 一个衰败、一个破产
- 诺基亚：iPhone 改变竞争维度时仍强调硬件效率与价格优势

**正面教材（主动寻找 Alpha）**：
- ASML：已是 DUV 赢家，仍主动押注 EUV，进一步推进 High NA EUV
- NVIDIA：打不过 Intel/AMD 时搞 CUDA，用十几年纯投入锁定学术与工业生态
- Airbnb：在酒店业高度成熟的市场中，发现"信任"才是私人住宅闲置匹配的核心瓶颈，用创始人亲自敲门 + 互评体系人为创造标准化信任
- 西南航空：单一机型 + 简化服务 + 短途高频，整套系统围绕"快速周转"重新设计

### 证据强度评估
- 理论引用扎实：哈耶克（1968）、柯兹纳、波特（1996）均为学术史中可核实的源
- 案例选择典型且对比鲜明（柯达/ASML、Kmart-Sears/NVIDIA、诺基亚/Airbnb），说服力强
- "三本账"比喻属于作者原创表达，需标注为教学性比喻而非学术术语

### 重要警示（值得作为结论保留）
> 降本增效不是进攻而是防守。低利润率是一种耻辱。同质化竞争 → 价格战 → 利润蒸发 → 无力研发新 Alpha → 廉价品牌资产 → 失去创新能力。

> Alpha 是动能，经济租是势能。Alpha 是动作，经济租是凝固的防御堡垒。
