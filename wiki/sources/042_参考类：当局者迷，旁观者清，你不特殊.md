# 042 参考类预测：当局者迷，旁观者清，你不特殊

本课介绍一种名为「参考类预测」（Reference Class Forecasting, RCF）的预测工具，源文称其更像是一个「反自恋装置」。主轴是：用同类案例的统计分布预测自己，而不是用关于自己的内部故事预测自己。

## 核心命题

> 「具体做事，不妨用内部叙事给自己打气；决策，却必须用外部参考类给自己泼冷水。」

这是本课的金句，对应两条认知纪律：

1. 行动层面：内部叙事提供动机与意义。
2. 决策层面：必须借助同类已结束事件的统计基线。

## 主要内容

### 一、规划谬误

源文以心理学家 [[罗杰·比勒]] 的毕业论文学期预测实验开场：学生平均自评 33.9 天完成，强制悲观预测 48.6 天，实际 55.5 天——现实比最悲观的估计还要悲观。

[[本特·弗吕博杰尔]] 调研 258 个交通基础设施项目，结论是大型项目系统性超支与延期：铁路 45%、桥梁隧道 34%、公路 20%。最著名反例是悉尼歌剧院：预算 700 万→1.02 亿美元，工期 4 年→14 年。

规划谬误由大脑里一组「幻觉生成器」联合造就：

| 偏差 | 作用 |
|------|------|
| [[乐观偏差]] | 「这次一定顺」 |
| 确认偏误 | 只搜集利好证据 |
| [[控制错觉]] | 高估对世界的掌控 |
| [[自利归因]] | 把失败甩给外部 |
| [[幸存者偏差]] | 只看见成功故事 |
| [[可得性偏差]] | 凭想得到多少例子估计概率 |
| [[叙事谬误]] | 把碎片拼成热血剧本 |

### 二、内外视角

| | 内部视角 (Inside View) | 外部视角 (Outside View) |
|------|------|------|
| 信息类型 | 个案信息 (singular information) | 分布信息 (distributional information) |
| 关注对象 | 这一件事的细节、你的努力与诚意 | 同类项目的平均水平与失败率 |
| 主体身份 | 主角 | 样本 |

「当局者迷旁观者清」的现代认知科学版本：旁观者不一定更聪明，但旁观者没有自恋情结。

### 三、卡尼曼教科书案例

1970 年代卡尼曼带队编决策学教材，团队预估两年。卡尼曼转向外部视角问教育专家：同类团队通常几年？回答：7–10 年，40% 团队最后放弃。结果：8 年完成，且彼时课程已被取消。

### 四、RCF 三步法（弗吕博杰尔标准化）

| 步骤 | 动作 |
|------|------|
| 1 | 找一组与你相似且**已结束**的案例作为参考类 |
| 2 | 查阅分布：基线、失败率、尾部风险 |
| 3 | 将自身项目放入对比；最简做法是直接取参考类中位数 |

纪律：若声称「我与别人不一样」，必须出示强证据，否则只是把偏见悄悄放回来。

### 五、应用案例

| 领域 | 实证 | 关键数字 |
|------|------|----------|
| 大型交通工程 | 弗吕博杰尔 258 项目 | 铁路超支 45% / 桥梁隧道 34% / 公路 20% |
| 香港道路工程 (2012) | 25 本地项目 vs 863 国际项目，P80 控制下 | 成本上调 44%，工期上调 75% |
| 企业并购 | 平均来看收购方业绩并不因并购改善 | 现代做法：用 ML 自动化 RCF |
| 电影票房 | 2008–2012 美国电影超半数未盈利；前 10% 吃 70% 票房 | 2023 随机森林模型预测准确度提到 90% |
| 核聚变 | 无现成参考类，用相似高复杂度项目替代 | 上调 118%；用国际级大型科研基础设施可达 220% |

### 六、Helion 与马斯克案例

- [[山姆·奥特曼]] 投资的 Helion：2021 宣称 2024 发电 → 2023 与微软签约推迟到 2028 → 2025 才建厂址 → 2026 才声称「新里程碑」。
- [[埃隆·马斯克]] 的规划谬误案例：
  - 特斯拉 FSD：约十年「明年实现」承诺。
  - SpaceX：1 亿美元预算、3 次发射——前 3 次全炸，第 4 次勉强成功。
  - xAI：再次声称即将大幅领先所有 AI 公司。

### 七、日常生活迁移

- 求职薪资：参考类应是「像我这样的学历/技能/城市」的样本中位数。
- 婚恋：靠谱的婚介服务本质就是 RCF；「我这么优秀必须配 X」是内部叙事。
- 学习/搬家/装修：先看同类事情的真实分布，而不是凭热情画曲线。

## 核心张力：与已有概念的对话

- 与 [[叙事谬误]] 的内在对照：叙事给意义，RCF 给预测。
- 与 [[幸存者偏差]] 的应用场景：RCF 显式要求对抗幸存者偏差。
- 与 [[选择偏差]] 的互补：参考类必须是「已结束的案例」，避免选择偏差污染样本。
- 与 [[贝叶斯主义]] 的方法论互补：RCF 提供的同类基线本质上是一种经验先验。
- 与 [[反脆弱]] / [[非对称风险]] 在大型项目场景下的潜在冲突：RCF 给中位数，反脆弱要求做凸性组合。

## 开放问题

1. RCF 在「参考类缺失」或「赢家通吃」型分布（电影票房 10% 吃 70%）下，给中位数是否仍有效？
2. RCF 与 [[WOOP]] 的「心理比对」结合时，先用 RCF 看基线还是先用 WOOP 找动机？
3. 「声称例外需硬证据」这条纪律本身是否会筛掉真正的反常者？是否存在「过度 RCF 化」风险？
