## 主要论点与发现

### 1. 凯利公式的本质：不是投资公式，而是认知变现机
**核心主张**：凯利公式解决的不是"怎么赢"，而是"怎么一直赢"。它把"你掌握多少有效信息"翻译成"你应该投入多少资本"，因此是认知优势到下注规模的转换器。

**证据**：凯利 1956 年原始论文证明——在有噪声的内幕信息场景下，最优长期对数增长率在数学上等于信道的信息传输率。

**强度**：强。这是源论文的严格数学结论，本文忠实转述。

### 2. 决定下注的不是赔率，而是 edge
**核心主张**：odds（分母）是市场共识，反映风险；edge（分子，bp − q）才是你高出市场的那部分认知。凯利赚的是 edge 的钱，不能更多。

**证据**：公式代数——f* = edge / odds；edge ≤ 0 时 f* ≤ 0（不下注）。

**强度**：强，数学恒等。

### 3. 永远不该 all-in
**核心主张**：只要 p < 1，凯利公式就要求保留未下注部分。这是因为最大化的是**几何均值**而非算术均值，破产一次的损害是永久性的（清零）。

**证据**：公式中 p=1 之外的所有情况下 f* < 1；文中以袁绍"all-in 错过的窗口"为反面案例。

**强度**：强，结论稳健。

### 4. 生物学独立发明了"凯利仓位"
**核心主张**：表型赌注对冲（Phenotypic Bet-Hedging）——让克隆族群的一部分进入休眠、其余去繁殖——其休眠比例在数学上等价于凯利公式中的"未下注比例"。

**证据**：原文援引沙门氏菌与枯草芽孢杆菌的实验观察；这是被引用为研究结论的实证。

**强度**：中——原文说是"研究者发现"，但未给出具体论文，建议标为"被引用的跨学科佐证，需追溯原始研究"。

### 5. 三个行动哲学
- **别清零**：留着留在牌桌上；
- **认知先行**：先估 edge 再定仓位，不是反过来；
- **追求复利**：单次输赢不重要，系统的几何增长率才重要。

**强度**：中等——属于本讲作者对凯利公式的行动化解读，不是凯利论文本身的结论，但逻辑自洽。

### 6. 应用场景的四向拓展
- **职业规划**：换赛道 = 多轮下注；用 half-Kelly 做副业试水；
- **精力与健康**：每项活动是一次下注；时间管理的凯利策略是"少出手、集中在能复利的少数变量"；
- **信任**：人际关系 = 乘法资产；从小事小注、加仓看表现、永留止损；
- **勇敢的定义**：按凯利比例出手才是真正的勇敢，勇敢是对本能的克服。

**强度**：中——属于作者的应用哲学延伸，不在凯利论文范围，但与公式结构兼容。

### 凯利公式原文

$$f^* = \frac{bp - q}{b}$$

其中 $p$ = 赢率，$q = 1-p$ = 输率，$b$ = 赔率（赢时净赚倍数）。

当 $b=1$（等额赌注）时简化为：

$$f^* = p - q = 2p - 1$$

例如文中例子：$p=0.6, b=1$ → $f^* = 0.2$（押 20%）。

## 矛盾与张力

1. **凯利公式的"过度自信"悖论**：本讲说"认知先行"，但凯利公式对 p 的估计误差高度敏感——p 估高一点就可能导致 half-Kelly 仍然破产。本文未深入讨论"如何处理凯利对参数的脆弱性"。

2. **与"反脆弱"的关系**：本讲提到 [[concepts/反脆弱]]（在 related_notes 中），但凯利公式在严格意义上是"最优"而非"反脆弱"——凯利追求的是长期增长最大化，反脆弱追求的是从波动中获益。两者方向一致但目标函数不同。建议在反脆弱页中注明这一区分。

3. **与 [[queries/君子不器的边界]] 的潜在张力**：本讲主张"职业是乘法资产，应该多轮下注、敢于加仓"——这与"君子不器"那种"拒绝被专业化、保持多面性"的理念在表层上有张力。凯利并不反对专业化，专业化反而是 edge 的来源之一；张力其实是表面的。

4. **表型赌注对冲的因果方向**：文中说"生物多样性是系统为应对不确定性而支付的凯利仓位"——这是凯利公式的**描述性应用**，不是因果机制。休眠比例是否真的"等价于"凯利最优，需要查原文研究确认。本分析应标记为"被引用的跨学科类比，未独立验证"。
