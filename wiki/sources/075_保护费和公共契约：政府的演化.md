# 075 保护费和公共契约：政府的演化

## 核心命题

> 政府起源于强盗。政府的历史，就是把保护费改造成税收，把统治者改造成代理人，把臣民改造成公民的历史。

整篇讲稿以奥尔森（Mancur Olson）的"流寇—坐寇"模型为骨架，把霍布斯、韦伯、蒂利、斯科特几条主线串成一条演化链：政府起源于暴力 → 被战争逼成国家机器 → 在谷物农业心脏区演化为大一统帝国 → 在前现代形态下陷入家产制 + 黄宗羲定律死循环 → 在西欧经《大宪章》→ 光荣革命 → 美国制宪三个节点脱胎为现代国家。

## 现代国家演化的三个节点

| 节点 | 时间 | 性质 | 关键条款 / 机制 | 主要人物 |
|---|---|---|---|---|
| 《大宪章》 | 1215 | 贵族武力逼国王签字 | 第 61 条：贵族选 25 人监督国王，违约可扣押城堡、土地、财产 | 英王约翰；后续法学家爱德华·科克 |
| 光荣革命 | 1688 | 上层精英联手换国王 | 《权利法案》：国王未经议会同意不得征税、不得维持常备军、不得停止法律施行 | 约翰·洛克（叙事合法化） |
| 美国制宪 | 1787 | 制宪者顶层设计 + 权力分布使然 | 横向三权分立 + 纵向联邦/州分权；"用野心对抗野心" | 孟德斯鸠（理论来源）；詹姆斯·麦迪逊 |

关键观察：

> 从《大宪章》签字到议会真的能限制住国王，用了整整 473 年。

思想家（科克、洛克、卢梭）更多是把已发生的变局**通过叙事合法化**，而非直接推动变局。

## 关键论点

### 论点 1：政府起源于强盗，时间偏好是跃迁变量

从"流寇"到"坐寇"不是道德改善，而是**时间偏好降低**——学会长期主义、细水长流。当代案例：真主党、意大利黑手党、墨西哥毒贩、张作霖从"赵家庙保险队队长"→"东三省保安总司令"。

### 论点 2：战争制造国家，国家制造战争（蒂利 1985）

春秋仪式化战争 → 战国变法、编户齐民、郡县、统一税收 → 秦 = 武装到牙齿的国家机器。坐寇之间的战争逼出正规军队 → 多收税 → 养官僚 → 更强战争能力 → 吞并弱者，正反馈。

### 论点 3：谷物是大一统帝国的关键燃料（斯科特）

谷物四项优势：可观测（长在地里）、可量化（几斗就是几斗）、可储存（耐运输）、可绑缚（农民跑不了）。对比：游牧/葡萄/橄榄/贸易 → 征税困难 → 统一太贵 → 大一统不发生。

> 用计算机模拟「历史动力学（cliodynamics）」，农业核心区统一战争必然发生。

### 论点 4：前现代国家是家产制，老百姓是被汲取资源

- 《商君书》："民弱国强，国强民弱。有道之国，务在弱民。"
- 《韩非子》："君上之于民也，有难则用其死，安平则尽其力。"
- 张宏杰统计：中国 611 位皇帝中非正常死亡率 44%，平均寿命仅 39.2 岁。

家产制把不受外部约束的巨大权力交给普通肉身 → 越有权越猜忌 → 越依赖私人忠诚 → 制度越坏，是死循环。

### 论点 5：黄宗羲定律是结构性死循环

```
王朝初建 → 轻徭薄赋
  ↓
官僚自我扩张 + 皇上好大喜功 → 财政吃紧
  ↓
正税难涨 → 发明附加费 / 摊派 / 火耗 / 折银
  ↓
改革者（张居正型）并税 → 财政再紧 → 新杂税
  ↓
"积累莫返之害" → 农民逃亡 → 流民 → 民变 → 王朝崩溃
```

秦晖判断：明君清官无关紧要，秦制两千年下只要家产制和汲取机制不变，循环必然重演。

### 论点 6：政府的核心是"最终强制权"

> 公司可以开除你，但不能关押你。平台可以收费，但不能征税。学校可以教课，但不能规定哪个学说是正统。教会可以逐出教籍，但不能绞死异端。

政府跟所有其他组织的本质区别不是服务更好、更仁慈或更"为人民"，而是它拥有**最终强制权**。

### 论点 7：现代化 = 把坐寇工程化

> 现代人必须学会从问"这个人好不好""这个政府好不好"，改为问"我们这个制度行不行"。前现代政府是统治者的政府；现代政府是制度化的政府。

华盛顿不称帝既是思想先进，也是权力不够——大陆会议和各州掌握财政，军官效忠的不是华盛顿个人。

### 论点 8：思想家改变观念结构，而非历史变局

- 爱德华·科克：把《大宪章》从封建文件翻译成"英国自古以来国王不能凌驾于普通法"。
- 约翰·洛克：政府权力是受托权力（fiduciary power），违背托付人民有权推翻。洛克《政府论》写于光荣革命之前、出版于光荣革命之后。
- 卢梭《社会契约论》（1762）已是事后叙事。

> 限制权力不是写在纸上，而是写在权力分布里。

## 警句收尾

> 即便是现代政府，即便它提供了很多正外部性，它也是最大的负外部性制造者。
