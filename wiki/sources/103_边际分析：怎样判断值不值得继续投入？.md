# 103 边际分析：怎样判断值不值得继续投入？

本讲出自万维钢《现代思维工具100讲》第103讲，主题是经济学中被很多经济学家认为"最重要"的智慧——[[concepts/边际分析]]。课程主张边际分析是面向未来的决策框架，决策者真正应当关注的不是体量也不是平均值，而是"下一个单位的投入能带来多少新增产出"。

## 主要论点

### 1. 边际分析：面向未来的决策框架

体量与平均值只能描述过去和现在；决策必须看"边际"——下一个单位投入带来的新增产出。工厂招工案例（1→5→10→20→40个工人）演示了**边际产量递增 → 边际产量递减 → 边际产量为零 → 边际产量为负**的完整演变。

### 2. 四象限决策矩阵

| 边际效益符号 | 趋势 | 决策含义 |
|---|---|---|
| 正 | 递增 | 加大投入（最佳局面） |
| 正 | 递减 | 仍值得做，但前途有限 |
| 负 | 改善中 | 可能是冷启动，值得投入等待拐点 |
| 负 | 递减 | 赔钱无底洞，立即退出 |

### 3. 边际效益递增：飞轮的数学基础

平台、数据飞轮、规模制造、学习曲线共享"边际效益递增"的底层结构：
- **平台**：用户越多 → 平台对每个用户越有用 → 下一个用户来得越容易
- **数据飞轮**：用户越多 → 数据越多 → 产品越聪明 → 更多用户
- **规模制造**：固定成本不变 → 多产一件则分摊更少 → 收益递增

当边际效益不降低时，事业具备**[[concepts/可扩展性]]**，应使用商业杠杆不断放大，复利驱动产生**指数增长**。

### 4. 没有永恒的边际效益递增

每个[[concepts/强化回路]]都被更大系统中的[[concepts/平衡回路]]限制，天花板来自：竞争者进场、个体生理极限、市场总量上限。

**共享单车案例**：超过有效密度后，新增车辆带来的便利趋近于零，调度、维修、丢损成本却继续上升——最终变成"单车坟场"。

### 5. S曲线 + 第二曲线：穿越周期的范式

世间任何产品/事业的故事一般是一条 [[concepts/s曲线]]：
- 前期冷启动（投入大、动静小）
- 中期飞轮转起（边际递增，一飞冲天）
- 后期饱和（边际递减，曲线变平）

突破天花板的方法：[[concepts/第二曲线]]（Charles Handy, 1994）——在第一条曲线到顶**之前**启动新S曲线。第二曲线启动需要**人、钱、士气**三要素，这三样只有在旧曲线仍上升时才有。

**关键案例**：
- **苹果**：iPod热卖时发布iPhone，主动让新产品侵蚀明星业务
- **摩尔定律接力**：平面晶体管 → FinFET → GAA
- **AI缩放定律接力**：纯预训练加码 → 调整模型/数据配比 → 后训练/RL/推理时计算（o1、DeepSeek-R1）

### 6. 实证数据点

**晶体管数量增长**：
- Intel 4004（1971）：2,300 个晶体管
- Nvidia Blackwell GPU（2024）：2,080 亿个晶体管
- 五十多年约增长 **九千万倍**

**AI缩放定律**（2020, Kaplan 等）：大语言模型交叉熵损失随参数、数据、训练算力增加而持续减少——投入越多，模型越聪明。

### 7. 中国经济增长：边际回报递减的实例

过去四十年高速增长很大程度上是**投资拉动曲线**：修路、建厂、盖楼，资本砸下去增长就出来。但投资会遇到[[concepts/边际效益递减]]。

- **白重恩、张琼（2014）** 多口径估算：中国资本回报率自2008年以后明显下行
- **世界银行 2026《中国经济简报》**：公共投资"在许多领域"面临收益递减，应把支出再配置到回报更高的用途
- **居民消费/GDP**（关键数据）：
  - 中国（2025）：**40.0%**
  - OECD 成员平均（2024 可比）：**60.1%**
  - 差距约 20 个百分点

### 8. 努力也需要边际分析

遇到瓶颈时，多数人本能"加量"，正确动作是**换变量**：
- 深夜复习：再多一小时边际提升已极小、坏处增大
- 家居整洁：再多打扫只是在搬运杂物，瓶颈是物品总量（应少买、扔掉、重新设计收纳）

### 9. 批评"小满胜万全"的民间智慧

"小满胜万全"是事后感叹式浅见。真正的解法是**在大满之前开启第二曲线**。**自强不息**与**亢龙有悔**并不矛盾——后者提醒换棒，不是停下。

**反例**：马斯克早就是世界首富，现在还在接二连三干大事。
