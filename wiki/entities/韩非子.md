# 韩非子

战国末期韩国贵族出身的思想家（约公元前 280—前 233 年），法家集大成者，《韩非子》一书的署名作者。

## 在本讲中的角色

本讲将韩非子定位为**最先系统描述委托—代理问题的古代思想家**，并将其"术"的解法作为反面参照系。

## 关键引文

> 韩非子两千多年前就看明白了："上下一日百战。"——君臣之间一天之中都要暗中较量一百回。
> "君臣之利异，故人臣莫忠。"——利益不一样，忠诚怎么能靠得住呢？

## 韩非的解药：术

韩非给委托—代理问题开出的药方是「术」，权术的术：
- 君主要深藏不露
- 要用亲信互相监视
- 要放出假消息试探臣下

韩非自己也说透了术的本质：

> "法莫如显，而术不欲见"——术的要诀是暗，把尺子藏起来让人猜。

## 术的根本局限

| 维度 | 说明 |
|------|------|
| 位置 | 在暗处 |
| 载体 | 长在君主一人身上 |
| 推广性 | 不可推广、不可继承（雍正子孙不一定有同等精力） |
| 约束对象 | 只约束代理人，不约束委托人 |

## 与现代解法的对比

| 韩非的"术" | 现代的"制度" |
|------------|------------|
| 在暗处 | 在明处 |
| 人格化 | 制度化 |
| 不可推广 | 可推广 |
| 只能防小人 | 能让君子也愿做君子（[[concepts/管家理论]]） |

## 历史继承

术在中国帝制的极致形态是[[concepts/秘密奏折]]制度（康熙→雍正），但术的局限同样在雍正身上得到戏剧性展示：把全国信息汇集给一人，最终让雍正"批成了史上最劳累的皇帝"。
