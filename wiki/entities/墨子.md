# 墨子（约公元前 470–约前 391）

## 身份

先秦诸子之一，墨家学派创始人。代表作为《墨子》。

## 核心主张

**兼爱**：视人之国若视其国，视人之家若视其家——**爱无差等**。

## 在本讲中的角色——失败的尺度方案

墨家看出了[[孟子|儒家]]仁政的不可扩展问题，但解决方案（兼爱）违反人性：
- 近乎宗教精神，弟子真能赴汤蹈火。
- 但**不可持久**。

[[孟子]]骂墨子"无父"（"无父无君，是禽兽也"），与两千多年后[[曾国藩]]骂太平天国"凡民之父，皆兄弟也；凡民之母，皆姊妹也"用的是同一条罪名。

## 与 [[商鞅]] 的对比

- 墨家：精神层面取消差等 → 违反人性 → 不可持久。
- 法家：制度层面取消差等（赏罚分明） → 符合人性弱点 → 可复制、可扩展 → 统一天下。

**关键启示**：解决"爱不可扩展"问题不能靠提升精神境界（违反人性），只能靠**切换尺度上的货币**（爱→责→法）。
