# 任正非

华为公司创始人，中国当代企业家。"让听得见炮声的人决策"思想的提出者。

## 关键主张

来源原文：

> "任正非有个说法叫「让听得见炮声的人来决策」——这不是巧合：他在相关讲话里明说，华为'借用了美军参谋长联席会议的组织模式'。"

## 思想结构

任正非的"炮声决策"由三层组成：

| 层级 | 主张 |
|---|---|
| 哲学层 | 决策权应交给离现实最近的人 |
| 组织层 | 华为借鉴美军参谋长联席会议的组织模式 |
| 操作层 | 一线听得见炮声的人拥有现场决策权 |

## 与 [[指挥官意图commander-s-intent|指挥官意图]] 的对应

"让听得见炮声的人决策"是任务式指挥思想在中国企业界的**最早也是最有影响力的应用之一**。它与 [[指挥官意图commander-s-intent|指挥官意图]] 的对应：

| 任务式指挥（美军） | 华为版 |
|---|---|
| 指挥官意图 | 公司战略意图 |
| 下级分散选择手段 | 一线炮声决策 |
| 五执行条件 | 胜任力 + 互信 + 共同理解 + 风险接受 + 有纪律的主动性 |

## 思想源头

任正非在相关讲话中明确：华为借鉴了美军参谋长联席会议的组织模式。这就把 **19 世纪普鲁士任务式战术 → 当代美军条令 → 华为组织模式** 的思想链完整连接起来。
