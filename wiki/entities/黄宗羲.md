# 黄宗羲

明清之际思想家（1610–1695），《明夷待访录》作者。他在《田赋三论》中系统观察了历代赋税改革"积累莫返"的循环——每一次改革都说减负，长期看却把负担固化下来。

> 这一观察由[[秦晖]]命名为「黄宗羲定律」，成为 [[075_保护费和公共契约：政府的演化]] 中解释家产制结构性死循环的核心框架：

```
王朝初建 → 轻徭薄赋
  ↓
官僚自我扩张 + 皇上好大喜功 → 财政吃紧
  ↓
正税难涨 → 发明附加费 / 摊派 / 火耗 / 折银
  ↓
改革者（张居正型）并税 → 财政再紧 → 新杂税
  ↓
负担固化 → 农民逃亡 → 流民 → 民变 → 王朝崩溃
```

黄宗羲的贡献不在经济学而在制度观察：他把"明君清官无关论"以赋税循环的形式具象化——只要家产制和汲取机制不变，循环必然重演。相关案例：张居正型改革者（参见 [[张居正]]）。
