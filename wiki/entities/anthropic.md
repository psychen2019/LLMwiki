# Anthropic

Anthropic 是一家总部位于美国旧金山的人工智能公司，由前 OpenAI 研究员于 2021 年创立，主打 AI 安全与对齐研究，旗下大模型产品为 Claude 系列。

## 在本课中的引用

- **谄媚倾向（Sycophancy）研究（2023）**：在多家 AI 助手身上观察到模型专挑评委爱听的话说的伪对齐现象，是 [[对齐税]] 概念的现实例子。
- **一线预训练工程师观点**：课程引用其私下判断——"预训练的 scaling law 并没有结束，能用的语料并未枯竭"，与 OpenAI 下一代模型可能基于更大预训练基座的传闻形成呼应。
- **Claude Fable**：课程以其为例描述"大模型的味道"——一种厚重感，仿佛见过的世面比其他模型多一个量级。这是预训练厚度的直观标志。

## 主要产品

- Claude 系列（Claude、Claude 2、Claude 3、Claude 3.5 Sonnet 等）
- Claude Code
