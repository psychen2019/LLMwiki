# 蔚小理（蔚来/小鹏/理想）

## 在本讲中的角色

蔚来（NIO）、小鹏（XPeng）、理想（Li Auto）三家中国造车新势力，被万维钢在第 061 讲中作为**电动汽车主导设计已锁定的跟随者**提及——与 [[特斯拉]] 一同构成"小米造车时主导设计基本定型"的对照。

## 在机会窗口叙事中的位置

| 维度 | 状态 |
|------|------|
| 主导类别 | "电动汽车"早已稳定 ✓ |
| 主导设计 | 特斯拉 + 蔚小理共同锁定主要维度 |
| 与小米的关系 | 蔚小理是小米造车时必须面对的既有玩家 |
| 局部差异化 | 蔚来（换电）、小鹏（智能驾驶）、理想（增程 SUV）——这些细分维度仍有未锁死部分 |

## 与 [[小米]] 的对照

- 蔚小理：在主导类别形成后的窗口期入场，吃到主导设计锁定义之前的红利
- 小米：窗口接近关闭时入场，只能赌未锁死的局部维度（软件定义汽车、人车家生态、智能座舱）
