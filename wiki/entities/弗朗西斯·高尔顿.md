# 弗朗西斯·高尔顿（Francis Galton）

## 基本信息

- **身份**：英国科学家、统计学家、优生学家
- **与达尔文的关系**：查尔斯·达尔文的表弟
- **活跃年代**：19 世纪

## 核心贡献

**1886 年首次提出 [[concepts/回归均值]] 现象**。

他在研究身高遗传时发现：

- 高个父母的孩子平均没有父母那么高
- 矮个父母的孩子平均没有父母那么矮

起初他困惑：难道上帝喜欢公平，专门把极端者往中间拽？

他想了十多年才想明白真相：

```
观测结果 = 事物的真实水平 + 随机运气
```

极端表现包含运气成分，运气不可持续，因此下一次观测自然向均值靠拢。这是纯粹的统计规律，不存在"让极端者回归"的神秘力量。

## 历史地位

- 回归均值概念的发现者
- 现代统计学的早期奠基人之一
- 在优生学、心理学、气象学等多领域有开创性贡献

## 引用本讲时的注意事项

- 高尔顿是最早用数学语言描述"回归"现象的人
- 本讲的核心概念 [[concepts/回归均值]] 直接源自他的研究
