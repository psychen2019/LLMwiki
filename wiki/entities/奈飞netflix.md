# 奈飞（Netflix）

奈飞（Netflix）是全球最大的流媒体服务商之一。在 [[concepts/反脆弱|反脆弱]] 语境中，奈飞最著名的贡献是发明了 [[concepts/混沌猴子|Chaos Monkey]] 工具——一个会在工作时间随机停掉服务器、主动制造故障的程序。

奈飞把混沌猴子作为常规运维的一部分，迫使工程师彻底抛弃"单点依赖"的侥幸心理，把系统重塑为极度去中心化、能天然容忍微失败的分布式架构。当亚马逊 AWS 发生史诗级大面积宕机时，多数互联网公司瘫痪，奈飞却照常运行。

奈飞是"主动注入微不确定性 → 系统变得反脆弱"的工业级案例典范。
